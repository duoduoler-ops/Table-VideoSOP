# 总装、验收与封面

在系列根目录的总控对话使用。分段对话只交接本段，不擅自总装。

## 接入与锁画

```text
读取 AGENTS.md、docs/04_验收与返修.md 与本期制作大段表。
本期：[路径]
本次已决定采用的分段成果：[准确接入说明及版本]

核对源码、参数、素材、首尾状态、时基、原声策略与验证证据，接入登记的唯一主工程或总装入口。
只采用我明确选定的版本；未明确采用的成果先列候选。公共改动由你统一处理。
生成全片审片版本，检查语义、真实材料可读性、段间衔接、转场、遮挡、空帧与画幅，并更新制作大段表和 QA 各自负责的字段。
实际无法审看的项目写未验证。交付审片和具体待决定问题，等我确认锁画范围。
```

## 最终声音、字幕与交付

```text
画面已确认：[准确版本与确认范围]。
本次可选声音处理：[采用既有确认声音／选用声音制作及范围／不新增 SFX 和 BGM]。
字幕与交付要求：[填写或引用本期说明]。
请按 docs/04_验收与返修.md、experience/字幕与封面.md 完成最终合成和验收。只有选用声音制作时再读其 SOP。
按最终实际画面校准声音点，核对定稿、配音与字幕，检查原声去重、清晰度、遮挡、规格、完整解码和来源。
以最终合成文件完成 1× 全片审看、审听；做不到的项目如实标未验证，不用测量或抽帧代替。
交付成片、适用的 clean 母版、字幕、可编辑工程与参数、复现说明及 QA 状态；说明剩余问题，不自动发布。
```

## 封面与发布材料

```text
请按 experience/字幕与封面.md 准备封面和发布材料。
实际成片及主题：[路径／主题]
发布位置：[具体平台与用途]
画风参考：[路径及职责]
构图参考：[路径及职责]
角色参考：[路径／不使用]
希望保留的标题信息：[填写]

核对当前所需画幅与官方规格，先给主题准确、可读的方案。方向确认后，写好各画幅完整生成提示词、上传参考分工、文字策略和后期说明，交我手动生图。
候选收回后做检查和已获准后期。整理标题、简介、必要署名和实际公开链接，不写尚未实现的效果或尚未公开的状态。
对完整发布材料做事实、隐私、来源和承诺一致性检查，标待确认项；输出文件不代表授权对外发布。
```

成功标志：正式文件可定位、可复现，实际检查与未验证项清楚；封面与文案准确对应成片。
