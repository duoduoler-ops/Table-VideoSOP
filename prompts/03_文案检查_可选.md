# 文案检查提示词（可选）

完整稿写好后按需选用。没有选用时可直接确认自己的稿件进入配音。

## 检查

```text
我选择本次使用可选文案检查。读取 docs/05_文案检查_可选.md 和 templates/审稿建议.template.md。
稿件：[路径或正文]
受众与看完应得到什么：[填写]
事实来源、必须保留的观点与语气：[填写；没有额外材料写无]
检查范围：[默认完整模式；只查局部时明确范围]
个人写作偏好：[可留空]

原稿只读，只输出一份九部分审稿建议，覆盖划走、五项建议、五病根、十一项语言内部检查和适用的长文检查。每条定位原句或段落，说明具体问题和建议，区分影响正确性的问题与可选优化，并列出应保留内容。
缺少事实依据的地方标待确认，不补造经历、案例、数字或来源。固定句式和关键词只能定位候选，不能据此直接宣布全文有问题。
建议保存到本期 01_稿件/审稿建议.md；已有同名报告先保留旧版。等我选择采纳项后再处理正文。
```

## 选定后修改

```text
本轮采用：[审稿建议中的编号及范围]。
必须保持：[填写；没有新增要求就沿用原记录]。
请只修改这些部分，保留其他观点、案例、事实和语气，另出修订候选，不覆盖原稿。
复查受影响的事实、逻辑和口播，简要说明改了什么、仍缺什么。不要仅凭输出完成就登记为定稿；等我确认后再更新当前定稿指针。
```

成功标志：检查只有一份建议，原稿未被静默修改；修订范围符合作者选择，定稿有明确确认。
