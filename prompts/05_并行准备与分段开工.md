# 并行准备与分段开工

通常在大段表确认后自动执行。已有确认但尚未准备材料时，用下面的补充入口。

## 给总控

```text
读取 AGENTS.md、docs/03_目录与并行协作.md，以及本期制作大段表。
本期：[路径]
已确认的大段表：[路径、版本与确认范围]
本次准备：[全部已确认段／指定段ID]

核对采用输入、时基、允许阶段和依赖，按规则自动创建各段专属设计、素材、源码与局部证据目录，只补缺项，不覆盖已有成果。
使用 templates/开工任务.template.md 填写每段任务书，绑定当前表版本、准确素材、允许阶段、写入范围、首尾接点和检查重点。
在本期 00_本期控制/分段开工指令.md 写好逐段三行开工文本。所有真实路径由你解析并填成绝对路径，正式指令不能留占位符。
验证输入存在、写入范围不重叠、转场归属明确、缺项只阻塞相关工作。不建重复依赖工程、不自动开启对话或渲染。
按 templates/镜头剧本.template.md 一次写完 03_视觉设计/正文镜头剧本.md，各段写对标片或新类型；任务书引用对应小节。
交付指令文件和镜头剧本，逐段说明能开始什么、还有什么阻塞；镜头剧本等我审过再出设计图。
```

## 用户开启分段任务

从系列根目录新开对话，把总控已经填好的对应段指令完整粘贴。不要把本页中的模板占位符当成正式任务书。

成功标志：分段任务能直接定位所有必要依据；只写专属目录；先交允许阶段的产物和接入说明。

## 设计确认后继续

在原分段对话粘贴：

```text
总控已记录本段视觉确认：[大段表版本与确认范围]。
请核对任务书和当前依据，继续已获准的制作阶段。已有确认且条件未变时保持有效；按 docs/04_验收与返修.md 的“完整过程预演与精修”，同类型且相关风险已解决时引用具体范例，在首版完整预览核实适配，再精修。新类型或未解高返工风险先做覆盖完整过程的代表样片，不增加审批轮次。
交给我之前先跑 tools/motion-check.ps1 看总览、静止区间和关键动作帧，修掉已发现的问题。
程序化动画检查独立求值、共享对象与连接连续性；实质改变主动作或取景时，只在专属范围更新设计；中央剧本、采用指针及 QA 只交修订建议。保留可编辑源码、参数、预览与实际动作标记，完成后更新本段接入说明，中央表和共享工程仍交总控处理。
```

仅确认设计不能冒充风险样片已通过；设计期局部风险预演可提前进行，正式批量动画仍按总控核对后的本批授权范围进行。没有未解风险时直接按获准范围制作，不额外设样片审批。

任务书按当前环节填输入、允许动作、本批范围、专属路径和交付责任。准备完成不等于放行；首批实际结果交用户看过并落实反馈后，总控才放行后批，具体按目录正文“分批放行”。
