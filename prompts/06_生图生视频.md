# 生图生视频提示词准备与收片

工具内的生图、生视频提示词由 Agent 根据本段材料填写完整，使用者再手动粘贴。下面两段是给 Agent 的工作指令。

## 准备生成材料

```text
读取 AGENTS.md、experience/手动生图生视频.md、当前 DESIGN 与本段任务书。
本期与大段：[路径／ID]
已采用的生成候选：[大段表条目]
目标工具及我实际可用的输入模式：[填写；不知道则先查当前官方说明并列待核实项]
参考图：[准确路径及身份／画风／构图／场景职责；不需要的类别留空]
需要的文字与声音：[逐字文字或后期叠字；原生拟音／无声等]

根据实际配音窗口准备完整生图提示词、生视频提示词、逐图上传顺序与职责、可用参数、动作计划、验收点和失败后的处理办法。
无实际配音时不猜正式时长；示范计划要明确标示范。每镜从 00:00.000 记录主要动作及需要的 SFX 点，选片后再按实际结果校准。
有角色时完整写出可见身份约束，不只写名字。底图先检查主体、语义、文字和风格，合格后再准备依赖它的视频输入。
把材料保存到任务书指定的本段素材目录，交给我手动生成，不代提交或重抽。
```

## 收片检查

```text
收到候选素材：[准确文件路径]
所属任务：[本段任务书路径]
请按当前生成要求检查主体一致性、画面语义、文字、场景风格、动作因果、镜头与声音，先说明可用区间和具体缺口。
区分底图问题、视频动作问题、声音问题和入出点问题；能用获准的后期解决时保留合格部分。还需生成时只更新提示词和参考要求，交我操作。
候选不自动成为采用版。若我已明确采用，按权限登记准确路径和版本；并行分段只在接入说明给总控建议更新。
以实际选片重新标动作和声音，裁切或变速后重校准，保留源文件、参数和未验证项。
```

成功标志：用户拿到无省略项的生成提示词；收到素材后有明确候选／采用区别、真实区间和声音策略。完整示例见[生成示例](../examples/02_生图生视频提示词示例.md)。
