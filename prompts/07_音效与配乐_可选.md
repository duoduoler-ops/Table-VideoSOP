# 音效与配乐提示词（可选）

只选择当前需要的入口。补齐方括号，先说明任务范围；已有确认输入不用重复选择。

## 规划声音

```text
我选择为以下范围规划声音。读取 docs/06_音效与配乐_可选.md。
范围：[本期与大段／区间]
确认内容、画面或运动方案：[路径]
希望表达的变化：[填写]
已有配音、原声和音乐：[路径／无]

先确定段落从什么状态到什么状态，选择必要声音事件与让位区间，不逐动作强制配声。
在现有运动标注中记录意图、同步依据、素材方向、与其他声音的关系、退出方式和验证重点。
没有实际画面时只写计划，不猜正式声音对点，不把未制作声音写成已经提供。
本次只做方案，不下载新素材、不改工程；交付可执行计划与真正需要我决定的选项。
```

## 制作声音

```text
我选择按以下范围制作音效／配乐。读取 docs/06_音效与配乐_可选.md。
任务范围：[明确 SFX／BGM／原声及区间]
当前采用画面与工程：[准确路径、版本]
采用配音与项目时基：[路径、fps、时间依据]
声音方案：[路径；没有则先补必要事件编排]
原声策略：[保留／静音／区间混音]
可用素材与授权记录：[路径；缺失时先列候选来源和许可，不产生未获准费用]
选曲方向与自主决定范围：[填写；不选 BGM 则不适用]

按实际画面事件或配音锚点定位处理后素材的可闻点，先做好主声，再按缺口逐层加入、处理包络与混音。
复用已确认方案与素材。新增 BGM 且方向需选择时做少量真实小样；已委托你选择时直接说明依据，不重复请求同一决定。
保留独立音轨、可编辑参数、声音标记和来源；不重复叠加容器原声。先测采用配音，不凭参考音量重做它。
分别完成技术检查与实际合看审听，未完成项写未验证，结果交中央 QA；本段无中央写权限时写接入说明。
```

## 局部返修

```text
请按 docs/06_音效与配乐_可选.md 返修：[具体声音问题与区间]。
当前采用文件／工程：[路径与版本]
必须保持：[配音、画面、已有曲目或其他要求]

先定位源头：声音贴不住动作、额外击打、密度过高、背景竞争还是素材本身不合适。只改问题及必要接点，不重选全片 BGM。
对比时尽量固定其他条件，记录位置、包络、层次或音量到底改了什么；不要用整体变响冒充表达改善。
保留候选和原版。回查问题已解决、保持项未损坏，分别报告测量与实际审听，无法听辨则明确未验证。
```

成功标志：声音事件有明确作用，实际对点可追溯，修改范围受控；参数命中没有被写成听感通过。
