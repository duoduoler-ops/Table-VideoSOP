# 正文镜头剧本

> 大段方案确认后、出设计图前，把每个制作大段“观众怎么看”写成简明配音对照，让用户一次审完；详细制作依据在同一小节折叠。每期一份，放在 `03_视觉设计/正文镜头剧本.md`。它不替代制作大段表、设计图、运动标注或动作标记。

## 谁写、何时审

- 总控在大段方案确认后一次写完需要画面设计的全部大段；单独打磨的段落（如开场）可按系列约定除外。用户审一次，分段任务书引用对应小节。
- 分段开工时本段还没有小节：任务书写明允许本段只补写自己一节，先交用户确认，再出设计图。
- 动态实作若实质改变主动作、取景、揭示或交接，须同步受影响小节、状态图／标注及采用指针；旧图不继续冒充当前依据。仅调曲线或材质且过程不变时不重画全套，复查范围按验收规则执行。不另建版本台账。

## 写法

- 只写观众能看到的：谁在动、怎么动，什么依据何时出现、哪个部件因而怎样变、由此多懂了什么；镜头怎样带人看、下一个动作何时接上、哪里停下读字。每一行都写“镜头怎么走”，镜头固定也要写清画面里什么在推进。组件参数和帧号留在制作依据与动作标记。
- 以完整配音为单位，一句或一组相邻语义一行。检查实际状态带来的理解，不要求画面独立复述整句；删解释性标签用于诊断，必要文字、证据与情绪按其职责保留。
- **对标须落实到局部完整关系**：涉及程序化 MG 时，先按[源码索引](../examples/05_完整过程源码.md)匹配接收、处理、交接、比较等关系，再读取命中区间的实际实现；不以整段题材不同跳过。写明来源函数／区间、本段对应对象与实现方式；无适用关系或新做法只记录具体未解风险，按验收规则决定是否样片，不把“新类型”扩大到整段已验证部分。非程序化部分按实际素材区间与剪辑／处理过程对标，不要求源码函数。
- 需要正反诊断时，按任务读取[连续 MG 正反过程](../examples/04_连续MG正反过程.md)对应案例；写出采用的机制与本段差异。静态风格统一只规定视觉语言，不把全段锁成同一完整正面构图。

## 图旁的配音与审阅重点

- 每组设计图／运动标注的图旁或页边直接显示：段号与当前图版本、采用配音版本、覆盖的完整原文；每张图高亮对应词句，标明经过态或停留态及用途。跨句共享状态就列明覆盖句，不用段号、SRT 编号或文件名代替原文。
- 已核对对齐时给段内时间范围，已知全片入点时同时提供全片定位；尚未对齐只用句子锚点并注明未对点，不从字幕显示时间猜逐词起音。无配音任务注明无配音，按已确认叙事任务或声音事件定位。
- 运动标注把“说到哪个词／发生哪个事件 → 谁怎样变 → 何时交给下一动作”写在对应图旁。进入制作前，精确动作与音效秒点仍按原标记要求记录；不能以简明图注代替动作合同。
- 每组只提出与实际状态有关的具体判断问题，例如“是否看懂只取第一步”，不写泛泛的“检查效果”。原声可用时提供对应区间播放入口；尚无可播放配音就明示，不能暗示已听过或已验证节奏。
- 图注及箭头只属于审阅层；保留干净设计图，不进入成片。图数按关键变化覆盖，状态可共享，不规定一句一镜或每句三图；静图不证明速度曲线、接力和 1× 观感通过。

设计阶段在本节已有运动标注写一行：**空间适配：候选／采用／不用＋观看收益、阅读或比较代价、素材条件**。信息层级或场景物理纵深均须判断，详见[空间镜头](../experience/镜头推进与转场.md#空间镜头)。进入动画前按[最小动作依据](../experience/视觉叙事与连续MG.md#进入动画前的最小动作依据)补部件关系、职责曲线来源、进退／替换过程与事件时点，不另建逐镜表。

## 关键状态覆盖

**设计阶段只为新理解、新关系、难交接和关键阅读准备够用的状态证据，不按秒补图，也不设图数上限。** 在原小节关联稳定状态 ID 或真实素材区间，说明它解决哪个理解问题；共享状态复用，不另建逐镜表。

| 需要看清的事 | 够用的证据与检查 |
| --- | --- |
| 新理解、新关系 | 变化前后及必要的机制过程态；轻移、换色不自动补一组图 |
| 难交接、关键接触或遮挡 | 来源、接收方和交接机制可辨；同一状态可服务前后过程 |
| 关键阅读、比较 | 真实尺度、必要内容和遮挡；阅读时间以实际过程核实 |
| 已清楚且不变的共享状态、现成素材 | 复用确认状态或准确区间，仅补新的理解缺口 |

正例：同一交接态作为上段结果和下段起点，复杂拆分补足机制。反例：按秒补图、随手截 50% 进度，或只堆终态却看不懂关系。执行者核已确认变化的证据，总控抽查难过程、接点及采用指针；分歧进入原设计审阅节点。

状态注明经过／停留及用途，过程态不等于停车或切镜。由同一可编辑源输出真实静帧，在整段动画前推演理解、焦点和阅读；不先做完动画再抽帧倒填评审。动态问题进入既有预演或首版完整预览，不以截图数或静图证明节奏通过。

## 排时间：给变化留足时间

主变化、下一步启动／接管、前一步收势与必要阅读共同排时，不能将整句配音拉成慢移。阅读从完整、清晰、无遮挡且达到可读大小时算；比较保留共同可辨窗口，被读对象和相关取景稳定，其他有作用的交接可继续。时长按实际路程、辨认需求和节奏确定，不设通用秒数。放不下先去重复动作，保护采用原声；突然或拖沓先查过程与预算，再调曲线。精确秒点引用同版本动作标记，动态问题并入[现有预演或首版完整片](../docs/04_验收与返修.md#完整过程预演与精修)，不增审批。

## 每段小节

交审默认展示段名、配音依据、本段画面增量、已知未解决问题、具体未解风险及影响本次决定的未验证项和下表；本模板的写法、覆盖规则及自查供制作者使用，不逐段复制给用户。完整内容按语义组分行，较长段落可分页，不能为一屏省略关键过程或配音原文。会改变观众所见的取景尺度、高潮和跨段首尾接棒写入可见表，制作依据与细节在同一小节折叠。审阅视图引用或由该小节生成，不另手写一份剧本；确认只覆盖实际展示并获明确同意的范围，不因文件含有折叠内容推定已确认，同一范围不重复确认。

## 写完自查

- 按[画面推导](../experience/视觉叙事与连续MG.md#把一句话变成可见关系)核对观众所知、依据、部件后果与取景排时；状态证据能检验关键变化，有用途的复看、阅读与情绪保留。
- 实现后按[验收与返修](../docs/04_验收与返修.md#完整过程预演与精修)对照承诺与实际画面，结果写原 QA；不靠加图、微动或改词放行。
- 成片文字只写给观众，版本和待验证说明留在审阅层。上屏风险提前核对：完整外链、联系方式、二维码、社媒账号；平台、品牌或 IP 按系列约定，讲解必需的名称可保留。
