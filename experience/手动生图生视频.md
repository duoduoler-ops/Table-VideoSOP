# 手动生图生视频

Agent 负责提示词、参考职责、动作计划和收片验收；用户手动提交生成与重抽。可以换工具，输入模式、时长档、音频能力与费用按当时实际界面及官方文档核对。

## 先确定画面任务

准备新画面或修改镜头时，在确定底图构图前按[镜头方法](镜头推进与转场.md#段落吸引力与镜头推进)选择观察方式，并同步准备所需空间与素材；已确认且未受影响的方案沿用。

记录所属大段、配音锚点、画面唯一结论、事实证据还是比喻、文字策略。无确认配音时只写文字范围，正式秒点待补。生成片适合隐喻、空间关系、情绪或节奏；真实操作和准确结果用真实材料。

## 参考图分工

身份图只锁角色可见特征；画风图只锁色彩、线条和材质；构图图只锁相对位置与留白；场景或道具图只锁任务关系。只用必要参考，没有角色时无需身份图。

每张参考都写“采用什么、不要继承什么”。角色名称不能替代完整外观约束，使用[角色模板](../templates/角色说明.template.md)。已通过成图可用于结果核对，不自动成为尾帧。

## 生图提示词

写完整的用途、唯一结论、参考分工、主体与道具关系、动作前后状态、构图、文字白名单、DESIGN 风格、禁止项、规格和检查方法。

需要反复改字或精确排版时，优先留出后期文字区；让模型直接生成短标签时写清逐字内容、数量和位置，并逐字验收。不要求所有底图一律无字，也不让长段文字弥补看不懂的关系。

底图先检查主体、语义、必要文字和场景风格。合格后再进入依赖它的视频生成；纯文本生视频等没有独立底图的路线，收片抽代表帧检查同样内容。

## 生视频提示词

根据当前工具能力选择首帧、首尾帧、参考图或文本输入。目标时长来自配音窗和裁切余量，不固定某个时长档。

写清主体数量、初始位置及镜头方式、作用与取舍；构图、揭示和焦点交接按所选方式记录。每镜从 `00:00.000` 标记主要动作与镜头变化的适用节点。

后期叠字先区分屏幕固定叠层与随场景运动的标注；后者须有可用跟踪依据，无则安排稳定窗口或固定机位。文字需求不自动限定整镜固定，仍须保留阅读与字幕空间。

多步动作难以维持身份或因果时拆成短镜，仍归属原制作大段。接续状态优先从实际采用视频中找稳定帧，不能按文件名或提示词预期秒点直接取帧。

声音明确选择：需要原生音效且工具支持时，要求环境声与动作拟音，排除未计划的旁白、对白、口型和配乐；有意的人物发声由本期另行确认。若工具不支持，就交后期制作。声音计划按秒点或区间书写，实际仍需重新对点。

## 收片与返修

| 问题 | 优先处理 |
| --- | --- |
| 底图主体、文字或语义已错误 | 修底图，再处理受影响视频 |
| 底图合格，动作或镜头失败 | 保留底图，处理视频层 |
| 画面合格，仅声音失败 | 保留画面，替换、静音、混音或重对点 |
| 进入或退出不合适 | 在已有余量内重新裁切，保留必要动作和阅读 |

先交候选与验收结论，用户明确采用后更新大段表。登记准确路径、版本、截取区间、文字策略、原声策略和后期要求。抽取原声后关闭容器重复音轨；变速、裁切、换入点后重校准动作与声音。

操作：按[生成提示词入口](../prompts/06_生图生视频.md)准备材料，用户在工具中选择实际可用输入模式，按职责上传参考、粘贴完整提示词、生成并保存候选，再交回收片。Flow 的界面能力见[官方说明](https://support.google.com/flow/answer/16353334?hl=en)，不在本页硬编码按钮和模型档位。

完整中性示例见[示例提示词](../examples/02_生图生视频提示词示例.md)。
