# 镜头推进与转场

本页维护镜头选择、观看推进与衔接方法。视觉风格认项目 DESIGN，内容、采用版本与时间认本期依据；示例不构成制作授权。

## 段落吸引力与镜头推进

进入画面方案、分镜或节奏返工时，在确定设计图前同时判断主体动作和镜头观察方式。结果写入已有大段表或运动标注：

1. **配音与情绪**：结合完整语义、实际重音、停顿与语气，明确观众先看哪里、随后发现什么、最后停在哪里。配音未定时可拟候选画面与镜头；正式配音确定后复核选择，再定节奏与秒点。
2. **场景条件**：检查前后景、遮挡、可跟随对象、局部与整体及区域关系。镜头、对象布局和素材一起设计，不先固定完整正面版式，再补整图缩放。
3. **镜头选择**：按下方情境规划观看顺序，再从镜头方式表选择可实现的做法。关键段落或连续构图重复时，比较可行的运动与固定安排，记录采用方式、作用和取舍，不逐镜列备选。
4. **节奏与落点**：按所选方式确定起止构图、揭示、焦点交接、速度和必要的停稳区间。运镜可在重音前启动，让关键揭示落在语义节点；需要词点触发的结论不得提前。主体与镜头的运动协同安排，不默认先后分开完成。

### 情境与候选镜头

以下情境用于启动设计判断，不直接指定运镜，也不按单个词匹配；候选动作可单独使用或分阶段组合。未列出的情境仍按配音、场景和观看顺序判断。

| 具体情境 | 优先考虑的镜头安排 | 保留信息与边界 |
| --- | --- | --- |
| 多个差异需要依次比较，配音逐项讲解 | 先建立两方身份，再横移、重构图或推近当前比较项，最后回到整体结果。 | 当前对应项尽量同屏，读数时停稳。只有一个已清楚突出的差异时，可以固定。 |
| 对象跨区域移动、传递或交接，过程与去向是重点 | 跟随对象移动；交接处调整构图保留双方，再把视线交给接收方或新区域。 | 接触、接稳、释放与去向须可见；交接未清楚前，不只追随其中一方。 |
| 反复行动却没有进展，随后发现问题或突破循环 | 可先跟随行动，再拉开或改变观察角度揭示闭环；突破后沿新路径推进。 | 保留辨认“回到同一位置”的参照。配音从一开始就在解释完整结构时，不必故意隐藏全貌。 |
| 从局部认识整体，或从表象发现原因 | 拉开、升降、侧移绕开遮挡，或在有深度条件时转移焦点，按顺序揭示关系。 | 揭示终点须有具体内容；素材不支持时换可实现的方式，不强造环绕或穿行。 |
| 配音出现明显强调、犹豫、压迫或释然 | 考虑靠近或远离主体、改变观察角度、调整速度或有意停住，配合情绪转折。 | 结合语气与前后镜头判断，不把情绪词绑定一种技法，也不把每个重音都做成推近。 |

### 选择边界

- **稳定按时段安排。** 比较、接触与结果阅读需要清楚，不等于整段固定；可以运动到位后停稳，再继续推进。
- **固定须符合段落任务。** 持续观察同一关系、等待反应或保留全貌本身就是表达重点时，可以整段固定。“有文字”“有比较”“主体已在动”不能单独决定固定。
- **运动须有对象与落点。** 说清跟谁、揭示哪里、何时停下或交接视线；节奏与情绪作用也算理由，不要求每次新增信息。
- **不凑运动数量。** 当前关注点尚需稳定观察、运动会漏掉必要证据，或只是无目的的来回缩放时，保持稳定。

素材须支持所选方式：绕行需要可展示的侧面与空间，转焦需要可区分的深度层，穿行需要沿途内容和画外余量。条件不足时写明补充素材或替代方案及表达损失，不把整图缩放冒充需要视差的穿行或绕行，也不自行扩大制作或生成授权。

制作前补齐所选运动的时间与参数；方案阶段不必填工程数值。复杂段落展开关键状态与衔接，普通段落一两句即可，不新增评分表、技法配额或逐镜审批。

## 镜头方式：按表达目的选择

下表提供候选用途，不是情绪与技法的一对一规则。相机位移／转向、变焦／对焦、观察视角分别描述；物体旋转不等于相机环绕，二维平移／旋转只能近似相应观感，不能生成不存在的侧面或透视。

| 方式 | 可考虑的表达任务 | 实施与检查 |
| --- | --- | --- |
| 推／拉镜 Dolly In / Out | 进入细节、拉开揭示环境或改变与主体的距离感 | 锁起止构图和沿途信息；空间视差需分层或三维条件。整图缩放（整个画面连同窗口框一起缩放）是推拉的二维近似，核对清晰度、裁切和阅读；框不动、只放大框内内容是界面缩放，不是镜头推拉。 |
| 横移／升降 Truck / Pedestal | 沿结构发现新区域，跟随横向或竖向行动 | 相机平移，观察方向可保持；核对屏幕实际位移、遮挡和画外余量，不与摇镜混写。 |
| 横摇／俯仰 Pan / Tilt | 从一个关注点转向另一处，沿视线揭示对象 | 改变观察方向；起落点可识别，途中不扫过无关空白。上下移动整图不当作真实俯仰。 |
| 弧线绕行／环绕 Arc / Orbit | 绕开遮挡，揭示不同侧面或对象与环境的联系 | 明确绕到哪里后多看见什么；需要支持视角变化的场景，不默认转满一圈。 |
| 摇臂式升降 Crane / Jib | 从局部动作展开规模、俯视结构或由整体进入局部 | 可配合俯仰与横向运动；高度和观察角度一起设计，关键关系建立后再离开。 |
| 跟随／主观穿行 Tracking / POV | 经历传递、进入、受阻和抵达，增强过程感 | 跟随是运动，POV 是观察视角；明确视线跟谁、途中揭示和终点。保留证明起点、接触与结果的环境，核对主体与相机合成后的屏幕位移。 |
| 视差 Parallax | 通过前中后景的相对位移建立空间层次 | 保持深度和遮挡关系，补足被遮挡区域；同一刚性对象不随机拆层。可配合绕行或穿行。 |
| 变焦／快速变焦 Zoom / Crash Zoom | 改变画面尺度；短促强调、反应或笑点 | 变焦改变焦距与视角范围，不靠相机位移；快速强调后需有明确落点。二维缩放可模拟尺度变化，不能替代真实透视变化。 |
| 焦点转移 Rack Focus | 从表面结果转向原因、从行动转向反应 | 属于对焦变化；选定前后对象及交接时机，需要深度层。二维模糊遮罩可作近似，必要证据阅读时保持清晰。 |
| 轴向滚转 Roll | 表现秩序失衡、冲击或恢复 | 绕镜头轴改变画面倾斜，区别于环绕主体；明确原因、幅度与收束，检查中途覆盖和辨认。 |
| 滑动变焦 Dolly Zoom | 表现重要的心理转折、压力变化或突然意识到问题 | 相机移动与反向变焦配合，主体大小相对稳定、背景透视变化；需纵深与背景参照，普通整图缩放不能替代。 |
| 手持感／冲击抖动 Handheld / Shake | 对具体行动、冲击或紧张作出反应 | 有触发与收束，幅度服从主焦点和可读性；不作为持续填空手段。 |

组合运动围绕同一目的组织，例如绕行揭示后转焦，或跟随受阻后升高看清整体。明确主导变化和交接时机，不叠加互相争抢焦点的旋转、缩放与抖动。

## 连续画面与镜头衔接

| 方式 | 用途与检查 |
| --- | --- |
| 共享元素连续演化 | 同一逻辑保留对象，让它移动、改变层级、连接或状态；中途身份可追踪，不先清场再造近似物体。属于对象编排，不代替镜头选择。 |
| 图形匹配 Graphic Match | 用形状、位置、尺寸或构图承接两画面；先锁视觉锚点，正常速度检查焦点跳位，不伪造真实截图文字。 |
| 动作匹配 Match on Action | 同一动作跨视角继续完成；剪点承接动作阶段与方向，检查重复、跳步及接触或结果被剪没。 |
| 遮挡过镜 | 有场景依据的前景物覆盖剪点，后镜沿匹配方向揭示；核对覆盖、速度、边缘与落点。 |
| 声音桥接 J / L Cut | 下一场声音先入或上一场声音延续，帮助空间与情绪衔接；保持已锁配音顺序和时间，不提前暗示未发生的事实。 |

甩镜可用于同场重构图，也可用于跨镜衔接；同场无需虚构剪点，跨镜按下节匹配。共享元素、焦点转移和速度变化不都属于转场，不能用“加了转场”代替段内观看设计。

## 运动匹配剪辑：共同要求只维护一次

Motion Match 指不同镜头以相近的屏幕运动承接，可以是不同对象；Match on Action 还要求同一动作的连续性。以下用于平移、甩镜、旋转和缩放衔接：

1. **先配成一对。** 确定两镜为何相接、视线跟谁、切后落到哪里。生成或录制前就准备前镜尾部和后镜头部的运动余量；已有素材按实际可用动作找剪点。
2. **匹配屏幕状态。** 看实际主体的位置、大小、方向、轨迹和动作阶段，不只比相机参数。切点两侧速度尽量连续；故意反向或跳变时明确表达目的，不冒充顺滑匹配。
3. **按一次完整运动安排速度。** 前镜进入动作，后镜承接后再减速落稳；切点处不自动停下，也不让后镜从零重新启动。Ease In / Out 要核对实际速度变化，不能仅凭曲线名称判断。
4. **剪点服从动作。** 在运动容易接续、遮挡充分或构图匹配的位置切；速度峰值附近是候选，不是所有匹配剪辑的必选点。先看清锚点，切后保留必要阅读时间。
5. **模糊与覆盖共同检查。** 高速段按运动方向安排模糊，两侧强度衔接；先修跳位，再决定模糊量。变换与模糊后仍要覆盖画布，不能套用旧片固定放大倍率，也不能用光流补帧掩盖切点问题。

制作时在已有运动标注中记录这对镜头实际需要的起止构图、切点、承接状态与停稳时间。坐标注明画布／内容区基准，位置用 px 或归一化坐标、缩放用倍率、角度用 °；比较速度时用 px/s、°/s 或缩放倍率/s。镜头局部秒点、工程帧换算、音效单点与持续区间统一按 [动作与声音标记](../templates/动作与声音标记.template.md)，不另建合同文档。没有旋转就不填角速度，没有声音就不虚构音效。

| 类型 | 在共同要求上补充的做法 | 失败时先查 |
| --- | --- | --- |
| 平移匹配 Slide / Push | 两镜主体以相近屏幕速度沿同一方向衔接，接住位置后减速；整画面推移时让前后画面共同覆盖画布。 | 方向是否写成相机方向、两镜是否独立缓入缓出、接缝是否露底。 |
| 甩镜 Whip | 先建立可识别画面，快速甩向目标方向，在运动／模糊适宜处切；后镜从相近运动状态继续，随后落稳。二维实现可用平移近似甩镜观感。 | 模糊方向和速度是否突变、后镜是否先静止一帧、落稳目标是否过早或过晚可读。 |
| 旋转匹配 Spin / Rotation Match | 先决定是画面滚转还是物体旋转；锁转轴、方向、切点角度与锚点，再对齐角速度，后镜延续并减速到明确构图。 | 同方向仍跳动时检查转轴、切点姿态和主体大小；离轴距离不同会改变屏幕扫动速度。检查旋转中间帧四角覆盖。 |
| 缩放匹配 Zoom Match | 围绕同一视线落点缩放；两镜在切点对齐锚点位置、大小和变化速度，后镜继续放大／缩小后落稳。 | 缩放中心是否跳位、素材放大是否变糊、前镜“向里”而后镜突然“向外”；二维缩放不当作真实穿越空间。 |

前后各自完整停稳后硬切，也可以是有意的节奏断点；应按正常剪切设计，不必伪装成运动匹配。素材不具备连续性时，优先重选入出点、重新安排运动或改用图形匹配／干净切换，不无限增加模糊和效果。

## 最小检查与迭代

- **对照设计判断**：运动与固定都要核实重点引导、关系表达、节奏、情绪及必要阅读；按所选方式检查揭示与焦点交接。不能只因固定画面可读或画面持续运动就判通过，读取记录与技法名称也不能代替结果。
- **正常速度连看**当前段落及相邻镜头：视线能否接住、景别与构图是否无理由重复、主变化是否推进内容、重点能否读清。静态图确认不等于运动效果确认。
- **检查实际编码帧**：抽查起止、切点两侧及明显变换中间帧，排查动作重复／跳步、焦点跳位、露底、错误裁切、文字遮挡和模糊突变。
- **合看与审听**：核对实际配音的重音、停顿、语气与揭示节奏；声音按实际可闻事件对点，阅读与情绪留白不被无关尾音填满。无法完成的项目如实记未验证。
- **改动后重校准**：裁切、变速或调整起点后，以实际采用画面更新动作／音效标记，复查受影响区间和接点；全片时基变化时扩大复查范围。

结果写入已有 QA，记录采用版本、问题、修正和实际审看片范围。通用问题修订本页，单期构图与参数留在本期。沿用现行授权、风险样片和最终验收，不因选用新技法另加审批或自动重做已锁定段落。
