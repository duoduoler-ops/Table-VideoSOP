## 如何实际使用

从分享仓库根运行：

```text
node scripts/process-locate.mjs --relation 接收,处理 --out <项目内新文件.json>
node scripts/process-locate.mjs --id ep05-d04-inspect-rewrite-handoff --sample --out <项目内新文件.json>
```

默认输出 `componentChain`、`driverFields`、`preserve`、`portableEntry` 及源码锚点；先读这条部件链，再打开实际函数。`--full` 提供更全的来源／重算信息，`--sample` 调用原函数取状态。未命中只说明本索引未覆盖，不扫私人旧工程。选择与重排步骤统一见[迁移方法](../experience/视觉叙事与连续MG.md#完整过程源码复用)。

D04、D06 的薄入口共用 `stateAt(sourceSeconds, content)`、`renderSvg(state,{idPrefix})` 与 `renderDocument(state)`：同一状态用于静帧与动画，多个 SVG 实例给不同 `idPrefix`。D04 内容为 `{title,context[4],before,after}`，原区间 10.300–17.050；D06 为 `{before[3],after[3],requirements[10]}`，原区间 32.200–33.750。以上是来源秒数，项目须映射本轮配音，不能当默认节奏。D04 的 `wave.knot` 是强度、`knotPath` 是路径；D06 保留原状态函数，把旧淡换文字改为几何擦写，四齿并为两齿。原完整源码保留，薄入口像素检查不代替整段验收。

渲染按各例 README 及[适配器](../scripts/render-motion-example.mjs) `--help`：Remotion 必须显式传 `--entry` 和 `--composition`，或选 `--example whole-result-return`；v08 与薄入口使用其 SVG 方式。只用已有环境，不安装／下载。新内容按实际配音重排与合成，不继承源例的确认。

## 第五期如何接力

以下为随附实际源码的时序关系，不是通用秒数或新的听校结果。时间均为原段局部秒点、60fps；D04 主入口时间另减 9.400 秒。

- **D04：改句、接通与交给下游相互承接。** `source-timeline.cjs`／`model.cjs` 中，旧句在 16.100–16.450 收拢，新句已于 16.250 开始写入，至 16.700 完成；结在 16.350–16.600 收拢，顺滑波形于 16.550 开始接出，相机同刻开始拉开。稿纸 17.000 开始让位，朗读轨 17.100 开始转为配音／字幕轨，均不等相机 17.850 收势后才启动。接力保留同一句、同一波形起点和结果归属；没有把每项变成“完成—全停—下一项”。
- **D06：镜头、行卡与来源线各有职责。** `src/timeline.cjs` 中，路由线 2.100 钩住行卡后，相机 2.200 启动下移，行卡 2.300 跟进，路线晚 7 帧描出。行卡 4.100 到达提示词位置时文件开始横展；纵展 4.300 启动，正文 4.600 开始写入，文件 4.750 才展完。它们由同一来源与去向接续；规则／经验高亮仍服从原词点，不因重叠提前宣布结果。

需要读清、比较或等待因果的状态仍可停留；上述起止不要求所有动作相互重叠。借用时说明哪一动作启动、何时接管观察、哪些变化仍在收势，并重排新配音下的因果和阅读。来源采用范围不扩展到摘编、占位媒体或本轮新内容；实际观看与听校仍按各目录的验证边界记录。

## 检查落到实际输出

并排起、中、终状态，指出每次新发现／因果／情绪推进；测实际主体占屏与观察任务，检查主对象变化、辅助物变化及相机的合成屏幕轨迹，再把启动／接管／收势、全停分布与整段配音并看；短于两秒或各自写有阅读用途也不能单独放行重复起停。多图、非线性相机或低静止比例均不能单独放行。规则见[视觉叙事](../experience/视觉叙事与连续MG.md)及[验收](../docs/04_验收与返修.md)。

必要阅读、复看、妥协和反问可以停稳；不可用常驻运镜填空。源码摘要、确定性测试及渲染仅证明各自技术项，实际1×观看和听校未做时明确记未验证。例子有来源，不等于新内容自动达到来源效果。
