# 目录与并行协作

## 基础目录

```text
系列根目录/
  AGENTS.md
  DESIGN.md                         # 静态和动态测试确认后建立
  docs/ experience/ prompts/ templates/ examples/
  00_系列测试/                      # 自己的静态、动态候选与确认记录
  01_公共资产/                      # 自己的角色、字体、参考、复用组件
  第01期_主题/
    00_本期控制/                    # 本期说明、制作大段表、分段开工指令
    01_稿件/                        # 原稿、可选审稿建议、确认定稿
    02_配音/                        # 原始录音、采用配音、派生字幕
    03_视觉设计/                    # 正文镜头剧本、各段设计与全片视觉总览
    04_素材/                        # 实际素材、生成提示词、来源
    05_制作工程/                    # main、分段源码、renders、_work
    06_审片与QA/                    # 唯一 QA 表、局部证据
    07_交付/                        # 成片、字幕、clean母版、复现说明
    08_发布素材/                    # 封面、标题、简介与检查记录
    90_历史归档/                    # 被替代版本
```

按实际阶段补目录，不创建空音频、空确认记录或虚构状态。`main/` 登记所选工具实际入口；Remotion 可以使用 `remotion-main/`，以本期表中的真实路径为准。

先定位已有单期目录。尚无单期且未给期名时，按内容取临时期名，例如 `本期_资料归档/`；纯审稿只需其中的 `01_稿件/`，单段方案只补对应设计或素材目录。不能因缺期号就将系列根视为本期，也不要求补齐整套目录。

## 确认大段表后自动准备

本包默认由用户开启新对话并行；用户选串行则跳过并行包。用户确认表版本、划段、路线、分工后，总控同次完成以下工作：

1. 核对当前表版本、稿件、配音和允许阶段。配音未确认时只派与时基无关的设计或素材准备。
2. 检查目标路径、已有文件与目录链接，只补缺项，保留现有成果。
3. 按选定大段创建下列专属目录，使用[任务书模板](../templates/开工任务.template.md)。
4. 把每段的实际入口写入 `00_本期控制/分段开工指令.md`，替换所有占位符。
5. 检查输入存在、写入范围互不重叠、章节转场归属明确；在聊天交付每段可开始的阶段与阻塞。
6. 按[镜头剧本模板](../templates/镜头剧本.template.md)一次写完 `03_视觉设计/正文镜头剧本.md`（单独打磨的段落可按系列约定除外），交用户审一次。任务书写明本段小节与对标片；剧本还没有本段小节时，写明允许本段只补写自己一节并先交用户确认。动态或批量制作排在全片视觉总览确认之后。

```text
03_视觉设计/D01_段名/
04_素材/分段/D01_段名/
05_制作工程/分段/D01_段名/
  开工任务.md
  src/
  scripts/
  _work/
06_审片与QA/分段/D01_段名/
  预览/
  接入说明.md
```

D02 等使用各自同级目录。主工程、公共资产与总控文件不落入任何分段专属写入范围。总控可以创建这些目录，但分段任务不因此获得总控文件写权限。

## 可复制指令

总控为每段生成下列三行，全部填入使用者电脑上的真实绝对路径；公开模板不预置作者路径。

```text
在【系列根绝对路径】工作，负责【期名／大段ID与名称】。
读取【系列AGENTS绝对路径】和【本段开工任务绝对路径】，核对当前依据，按任务书允许阶段和写入范围直接开始。
将成果路径、验证和未解决项写到任务书指定的接入说明，完成本段后停止。
```

每个新对话仍从系列根目录开启并显式读取任务书。资料准备完成后由用户开启对话，不自动派子 Agent、启动高负载渲染或安装依赖。

## 分段与总控职责

| 对象 | 分段任务 | 总控 |
| --- | --- | --- |
| 本段设计、源码、参数、私有预览 | 在专属目录内读写 | 核对与接入 |
| 制作大段表、QA 状态表 | 只读；接入说明提出更新建议 | 记录采用、进度与检查结论 |
| 共享素材、组件、依赖与正式总装 | 只读；提出所需接口 | 实施公共改动，避免冲突 |
| 渲染与交付 | 轻预览；重渲染交总控协调 | 资源调度、正式成片、最终 QA |

任务书绑定表版本。表改变后，总控只更新受影响任务，并提醒暂停依赖旧版本的工作；与改动无关的工作继续。任务书、接入说明是执行依据与局部证据，不建立第二套中央状态。

只有真实依赖冲突或风险试验需要隔离时才另建临时工程，记录原因、输入输出、回收方式和负责人。正式交付要能从登记的总装入口复现。

## 公共资产

媒体登记来源与用途；代码组件在再次复用前去掉本期文案、路径和时基，将差异做成参数并说明验证范围。候选、可复用实现与历史范例分开标记，范例不等于即插即用组件。更新公共资产不自动改写已完成单期。
