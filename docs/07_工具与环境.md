# 工具与环境

本包是文档工作流，不自带运行环境或生成账户。首次使用让 Agent 只读检查，缺什么再说明安装目标和验证方式；不需要一次安装所有候选工具。

## 一条基础路线

| 工作 | 本包中的路线 | 换工具时保留的接口 |
| --- | --- | --- |
| 规划、文件与代码 | 能读写本地文件的 Agent | 按任务读取规则、写可编辑产物、保留证据 |
| 动画与总装 | Remotion 工程 | 可编辑源码、时间参数、预览与复现命令 |
| 音视频处理与诊断 | FFmpeg / FFprobe | 准确源文件、处理参数、输出与检查日志 |
| 生图、生视频 | 使用者手动操作；视频以 Flow 为示例 | 参考职责、提示词、参数、候选与采用记录 |
| 配音与字幕 | 自备配音或自行选择工具 | 确认稿件、采用音频、派生字幕与时基 |

ChatCut 可作为配音剪辑或字幕的可选辅助，其他编辑器也可以；HyperFrames 等可作为替代制作路线。这里没有验证这些工具的完整接入，不需要为使用正文安装它们。

## 检查顺序

1. 记录操作系统、当前工作目录、实际可调用工具和权限。
2. Windows 示例先检查 PowerShell 与命令是否可用；选 Remotion 时检查 Node.js、包管理器、已有工程及其锁文件。
3. 检查 FFmpeg 和 FFprobe；能显示版本只证明命令可调用。
4. 安装方案获批后，在项目专属目录建立运行环境，记录实际版本；已有工程沿用兼容依赖，不在每段复制环境。
5. 用本地非敏感素材完成一次短预览、渲染、解码和播放，分别记录成功与未验证项。这个样本验证环境，不替代本片视觉样片。

PowerShell 只读检查示例（没有命令时记录缺失，不自动安装）：

```powershell
$PSVersionTable.PSVersion
Get-Command node,npm,ffmpeg,ffprobe -ErrorAction SilentlyContinue
node --version
npm --version
ffmpeg -version
ffprobe -version
```

若所用宿主提供内置工具，记录实际调用方式，不要求另装相同工具。字体存在性、中文路径与实际字体渲染也需要在测试片中检查。

## 当前文档入口

- [Remotion 创建项目与文档](https://www.remotion.dev/docs/)：创建方式、环境要求和命令按所选版本确认。本包不自动安装全局 Skills。
- [FFmpeg 命令文档](https://ffmpeg.org/ffmpeg.html)：媒体输入、输出和处理选项。
- [FFprobe 文档](https://ffmpeg.org/ffprobe.html)：查看流与容器信息。
- [Flow 官方使用说明](https://support.google.com/flow/answer/16353334?hl=en)：输入模式按当前账号与界面核查。

上述入口在整理时核对。模型时长档、价格、账户功能、软件要求可能变化，实际使用前再检查；不要将某次案例参数写成永久可用规格。服务和软件许可分别按供应方条款处理。

环境提示词见[初始化与环境检查](../prompts/01_初始化与环境检查.md)。
