# 音效与配乐制作（可选）

参考方法仍在持续学习和优化。可选择整段制作、只加几个必要音效、只处理原声，也可以不用 SFX/BGM。已有配音与实际采用声音的同步、清晰度和技术检查仍按最终 QA 执行。

## 先选任务入口

| 任务 | 必要输入 | 从哪里开始 |
| --- | --- | --- |
| 声音规划 | 确认内容、画面或运动方案、想表达的变化 | 先定声音意图和事件；无实际画面时只写计划 |
| 声音制作 | 已采用配音、实际画面、工程时基、声音策略与素材 | 沿用确认方案；缺方案再补事件编排 |
| 新选 BGM | 段落作用、配音、发布用途、可用来源 | 选少量代表候选，混入同一配音片段比较 |
| 局部返修 | 当前采用版本、问题区间、保持项 | 直接定位该问题及前后接点 |
| 只读检查 | 待检查画面／声音与目标 | 只报告证据和拟改动作，不改工程 |

剪配音、改字幕或调整导出规格不自动启动声音设计。已确认的输入直接复用，局部 SFX 返修不重选全片配乐。正式制作不要求先有锁画文件，但锁画后要核对最后采用画面的对点。

## 1. 确定声音要完成的变化

先回答这一段从什么状态变成什么状态，观众应听见什么变化，哪些地方要留给配音或阅读。已有原声或音乐能够承担时，不必再叠音效。

一个声音事件可以覆盖几个连续动作，也可以由几个素材共同完成。不要按画面动作逐个配声，也不要把素材数量当成事件数量。

在本期大段表的运动说明或[动作与声音标记](../templates/动作与声音标记.template.md)中记录：位置、声音意图、起止或同步依据、声源、与其他声音的关系、退出方式、检查重点。还没有制作的声音标“计划”，不能写进“声音已提供”。

## 2. 对齐实际可闻事件

动作声音按表达目的选开始、速度变化、接触、到达或停稳等实际画面事件；叙事和持续声音可以跟随配音词点或区间，不强行编造碰撞。

先听素材有效起音、重音或峰值的位置，再反推素材在时间线上的放置点。文件头可能有静默或铺垫，不能直接当成接触时刻。裁剪、反转、拉伸或包络处理后重新检查可闻锚点。

例如：画面接触发生在局部 `00:01.250`，素材处理后的有效重音位于素材内 `00:00.080`，则候选放置点为 `00:01.170`。这是定位起点，仍需合看审听；重音不是所有事件都应采用的锚点。

计划时间不能证明模型实际命中。生成片选定、变速、裁切或改入点后，以实际画面重标。需要真实接触声时，不能为了踩音乐节拍把它挪离接触；氛围和预备声按叙事需要安排。

## 3. 先做好主声，再补缺口

先确定主声的时间、长度和增益，再判断是否缺材质、重量或空间。确有缺口才逐层添加，保持每层的作用可解释。

- 尾音侵入下一句：先裁剪或处理衰减，检查是否还保留事件质感。
- 一次落地听成多次：旁路附加层，逐层恢复，找出多余起音，再调整位置、长度或包络。
- 需要预备感：按任务选择反转、渐强或其他铺垫；反转混响与整段反转不是同一种处理。
- 音色不合适：先判断源素材，音高、明暗、空间分别处理，避免靠堆效果挽救不合适的主声。
- 同一动作已有合格原声：优先保留或明确替换，避免再叠一个近似事件。

事件的内部响度走势服务于表达，不要求最快时永远最响，也不固定每次使用几层素材。一次连续运动（穿行、飞行、推拉）优先用一条连续声音，不拆成多段；要表达速度时，响度（需要时连同音高）随速度升降，运动停止时声音同时收完，不拖到静止画面上。

## 4. 找出谁在抢声音

先听当前段落，再分别旁路 SFX、BGM 和原声，定位竞争来源。无必要的事件先减少；剩下的再处理位置、长度、包络、频段与增益。

背景需要让位时写清哪些轨道退出、何时恢复。真正设计了全静音才检查相应全轨；不要默认所有轨道都静音。重点声不突出时，可以先保持重点声不变、撤掉竞争背景做比较。

有配音时可做 Ducking：由配音触发背景降低，并按句子与叙事恢复，避免每次短呼吸都让背景起伏。需要突出的关键音效（如一次连续运动声）也可以触发背景让位：随它增强逐步降低、随它收尾恢复，不一刀切地快速压低。生成片原声要明确保留、静音或只用某区间；提取到独立原声轨后关闭容器内重复声音。

音乐已经承担上升、落点或强调时，先试着拿掉额外音效。持续有音高的音效可检查与配乐关系，短噪声和点击不必机械调音高。

## 5. 按问题返修与比较

| 听到的问题 | 先做什么 | 比较时关注 |
| --- | --- | --- |
| 声音硬贴在画面上 | 保留音源，调整可闻锚点与包络 | 起伏是否跟随动作 |
| 一次动作听成多次 | 逐层旁路定位额外起音 | 事件次数是否正确 |
| 重点不突出 | 固定重点声，减少竞争背景 | 不靠整体变响取得假优势 |
| 口播被盖住 | 找抢声轨，减少不必要事件，再处理时间和频段 | 关键字清晰度 |
| 密度过高 | 合并连续事件、减少重复起音 | 节奏是否仍成立 |
| 音色始终不合适 | 对比更换主素材 | 材质与情绪是否匹配 |
| 声音轻重和画面对象对不上 | 小元素才用短促提示音，卡片、面板等较大对象换成有厚度的落声 | 轻重是否与对象大小相称 |

交用户试听前先测候选与配音的响度差，确认在完整混音里听得到；测量只防止送出听不到的候选，不代替审听。比较使用同一画面、配音和前后衔接，记录实际改动。均方根或峰值接近不代表感知响度相同；波形、响度数据不能代替听辨。无需为每次调参固定输出多份版本或新增用户审批。

## 6. BGM 与混音起点

新选 BGM 时，根据段落任务、节奏、配音空间和授权范围选候选，不把“低响度”当成“不抢话”。没有明确方向时，用同一代表段做两个有区别的氛围小样；用户已全权委托选曲时可以直接选择并说明依据。

下面是口播项目的试混参考，源于制作经验，**不是平台统一标准**。先测现有已确认配音，具体采用目标记入本期说明，不能凭默认数字擅自重做配音。

| 项目 | 可供试用的起点 | 怎样判断 |
| --- | --- | --- |
| 配音整合响度 | 约 −16 LUFS-I，试用容差 ±1 LU | 采用后按本期目标测量，并检查清晰度 |
| 配音出现时背景降低 | 从约 8 dB 试起 | 按素材调整，不与人声峰值直接相减 |
| 背景降低与恢复 | 可试提前 150 ms 降低、结束后约 400 ms 恢复；短于约 800 ms 的停顿不急于恢复 | 检查抽动、句间呼吸与叙事 |
| 口播下主音效峰值 | 可从 −18 至 −12 dBFS 试起 | 逐条检查关键词遮蔽与多余重音 |
| 最终整合响度与真峰值 | 可试 −16 至 −14 LUFS-I，真峰值不高于 −1 dBTP | 分别测量；项目或交付方另有要求时使用该要求 |

保留画面、配音、原声、SFX、BGM 的独立控制。单改声音通常只需重做相应音轨和最终封装；根据工程结构决定，无需机械重渲全部动画。画面容器静音前先确认该保留的原声已提取和校准。

## 7. 验证与交付

先听单个事件是否成立，再结合画面看同步，最后在全混音中听清配音、声音层级、尾音和段间过渡。最终按条件增加耳机、小扬声器或单声道检查，并写明实际覆盖范围。

测量与审听分别记录，无法实际听辨就写未验证。方案内记录计算结果和缺项即可；正式检查结论按[统一验收状态](04_验收与返修.md)填写，由总控汇入已有 QA 表，不为局部声音方案另立中央 QA。交付本次需要的结果、可编辑参数、素材出处和局部证据。

素材清单使用[来源模板](../templates/素材来源.template.md)。单条素材的使用许可与再分发权分别核对；不要把可用于视频的音乐直接随资料仓库打包。

入口：[声音提示词](../prompts/07_音效与配乐_可选.md)。

## 检查项目的精确边界

| 对象 | 检查要求 |
| --- | --- |
| 时间依据 | 每条正式 cue 绑定采用画面、配音和工程时基；抽查开头、纯画面、后半段及结语 |
| 原声 | 保留区间可闻、静音区间无声、共存区间不盖配音；容器与提取轨没有重复 |
| 背景进退 | 逐轨说明 fade、ducking、急停与恢复；已指定禁区内没有误放 cue |
| 音色重复 | 连听检查疲劳与事件密度；次数统计只定位，不硬性规定隔几次必须换声 |
| 否决素材 | 记录实际被否决范围；全片禁用才全片排查，单次用法失败不升级为整类禁止 |
| 单声道 | 检查人声是否抵消变薄、背景关系是否改变 |
| ASR（诊断时可选） | 用相同配置比较纯人声与混音版；新增识别差异只触发对应区间审听，不直接判 BGM 有错 |

选曲比较先校准候选素材本身，再叠加同一配音与 Ducking，避免只因一首更响就误判氛围。人声与最终输出的采用技术目标、编辑器电平参考和试混参数分开记录，不互相替代。

默认不限制使用者的音乐网站；选择来源时核对具体曲目和发布用途。需署名的原文同时交付简介。声音方法仍可选，但选用后的上述实际适用检查不因“参考模块”而省略。
