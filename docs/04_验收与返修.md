# 验收与返修

## 哪个文件决定什么

下表用于整期制作。单段文字方案只在方案内标明依据、候选状态和待验证项；已有中央表时引用，不为一次规划补齐整套控制文件。

| 事实 | 唯一记录位置 |
| --- | --- |
| 当前定稿正文 | 用户确认的稿件 |
| 采用配音、素材、设计及工程入口，制作进度 | 制作大段表 |
| 正式可编辑实现 | 表中登记的主工程或可复现总装入口 |
| 检查结论与问题 | QA 状态表 |

局部审片、接入说明和测量日志作为证据。表格可以链接这些证据，不复制另一套进度。新文件不是自动采用版，“允许制作”也不是“成片通过”。

QA 栏目只用：通过、未通过、未验证、不适用（原因）。结果绑定文件版本、范围和证据；用户确认只覆盖实际确认的方面。

**质量结论须来自实际输出、原任务与选定参考。** 交叉审查先看这些，再看作者解释；字段填齐、自评和工具测试不代替实际审看。技术证据、助手实际审看／审听、用户确认分别记录，均绑定版本与范围。用户看片确认可作为该范围的接受依据，不能写成助手已播放，也不扩展到新内容或整期。

**先核实观看通道，再承诺播放或要求上传。** 文件可访问、播放器打开或解码成功，不等于助手取得了连续视听输入；抽帧不能写成 1× 连看。无法观看时如实记录，完成可做的生产像素与工程检查，交用户审阅；不绕过工具限制，不反复要求同一无效上传。未观看的观感项不由助手标通过。

## 三个验收节点

### 风险样片：有风险才做

未解决的问题一旦扩展会导致较大返工时，挑真正覆盖难点的一段，写清问题、配音范围、通过条件，输出实际样片。用户确认后再扩展。不能用简单标题入场证明复杂接触或连续状态转换已经解决。

无此风险则记录不适用；已确认且条件未变的做法复用。风险在设计阶段出现就提前验证，不必等到所有设计精修完毕。

**同类型且相关风险已解决，复用对标；新类型或未解高返工风险，先做代表样片。** 同类型指同一视觉系统、同类对象演化与镜头方式，仍须在[镜头剧本](../templates/镜头剧本.template.md)定位范例版本、区间、借鉴特征及本段适配。尚无确认范例的镜头、空间、互动、转场、风格或技术路线属于新类型。用户已指出而未解决的问题不能借“同类型”跳过。已确认且条件未变的证据有效，不重复审批；具体顺序见[完整过程预演](#完整过程预演与精修)。

### 锁画：确认整片画面

检查实际全片审片：叙事顺序、画面语义增量、真实材料可读性、运动因果、段间衔接、构图和字幕安全区。按[镜头验收](../experience/镜头推进与转场.md#最小检查与迭代)对照设计判断，核实揭示、焦点交接、情绪与固定机位的实际作用，不以技法名称或持续运动判通过。排除意外黑帧、露底、拉伸、错误裁切或重复尾帧。用户确认后锁定这一版画面。

锁画是唯一一次默认的全片画面拍板，不拆成逐镜用户审批。总装前的版本、配音范围、时基与接点由执行者先核对；候选浏览页不另设全片批准。已有带声粗拼使用全部拟采用画面、实际时基和接点，且连续审看覆盖上述锁画项目时，可由这一轮完成锁画；尚未覆盖时保留为候选，不先要求整片批准再重复锁画。

正式总装后核实实际画面与已确认粗拼一致并记录依据；一致范围沿用该次用户确认，不自动把旧 QA 复制为新文件通过。不凭同名、同源或两张边界帧断言整片一致。差异只复查受影响区间及前后接点，涉及全片节奏或连续性时重开锁画；制作前全片视觉总览和最终混音、字幕成片的完整检查仍保留。

### 最终 QA：检查实际交付文件

- 配音对应定稿，没有缺句、重复和错版；实际采用的 SFX、BGM 与原声不盖住关键内容。
- 字幕文字与确认定稿一致，时间依实际配音核对；检查断句、错字、尺寸和遮挡，英文专名按官方写法核对大小写。
- 核对本期采用的画幅、分辨率、帧率、时长、总帧、编码及音视频流，完整解码无错误。
- 素材来源、隐私与授权记录完整，交付包含可编辑源及复现方法。
- 对首次整片交付，以 1× 完整审看、审听最终合成文件。无法完成的项目标未验证；参数、波形、抽帧或解码不代替主观检查。

没有启用可选声音制作时，SFX/BGM 可不适用，但已有配音和原声照常检查。音频与字幕合并在一次最终 QA 中，不新增两轮固定审批。

锁画候选与最终成片交用户审阅时，有字幕版与无字幕版按本次需要提供，不为播放本身另建 HTML 页面。交审先指出本轮需要用户判断的重点，每项写“对应配音原文（无配音时注明）＋实际区间＋具体观察问题”，可播放材料从必要前因播到后续接管，不只截出高光。优先给可连续播放的 MP4；使用已有或用户要求的 HTML 时，只作为导航，重点与未解决问题排前，已确认且未受影响内容及技术指标默认折叠，同时保留全片连续播放。重点跳转不替代完整审看；不为导航新增审批或另一套状态。交审入口简化不减少可编辑源、复现方法与 QA 的交付。

## 完整过程预演与精修

**程序化动画先验证完整观看过程，再精修曲线、材质与装饰。** 这条顺序并入现有风险样片／首版整段预览，不新增固定审批或全套文件。

**首个完整预览的底线**：主要变化有起势和落点；有因果职责的部件有响应、跟随或接管；速度有可辨的快慢；镜头有目的；进出场及替换按[默认动作语言](../experience/视觉叙事与连续MG.md#默认进出场与替换)有过程。后续可精修的只有数值微调、次要材质和装饰，不能把主因果动作留到用户指出后再补。刚性物件只免形变，仍须有预备、附属件响应和接收反馈；必要阅读可以保留。

| 当前情况 | 执行方式 |
| --- | --- |
| 新类型，或尚未解决且扩展代价高的问题 | 在设计阶段用简化画面配实际原声，验证起因→主变化→结果→交接的完整过程；并入原风险样片关卡，问题解决后再扩展 |
| 同类型且相关风险已解决 | 引用已确认过程的准确区间，在首版完整可播放预览核实本段适配；不额外做一轮设计前样片或审批 |
| 已有同范围、同条件的有效过程证据 | 直接复用；没有新增问题就不重复制作或重审 |

局部预演可先于全片视觉总览；正式批量动画仍在总览确认后进入。预演只简化次要材质、阴影和装饰，主对象形态、取景、文字大小与阅读时间须接近实际目标。静帧轮播、轻缩放或只有光标移动不能证明主过程成立；预演不替代真实设计图和锁画。已有风险窗口预演但未完成 1× 审看时，保留该证据并标明观感未验证；再增加预演步骤本身不能解决节奏问题。

设计图先核实剧本承诺的关键变化、观察起终点和必要过程态，指出各状态推进的发现、因果或观察任务；铺垫、复看和阅读按具体用途检查。可以从同一可编辑源取状态，但不能等完整动画写完后，只抽若干终态代替机制与取景检查。图数依变化覆盖需要，不按时长、镜头数或相机运动数量设配额；风格统一也不等于构图固定。

在现有剧本、运动标注和 QA 的对应条目中接通 **方案承诺→实现对应→实际证据**：先指出承诺的主变化、近读／拉开或交接，再定位负责它的实现与时段。最后看实际主体尺度、可见内容及相邻动作的启动／接管／收势；接力处若全体先停，核对真实依赖或具体阅读／情绪任务，不能只记录相机数值、曲线名或图数。无需新表或逐项审批。引用[正反过程](../examples/04_连续MG正反过程.md)时写清借鉴机制及适配结果，不能把案例的历史有效性当成本段已通过。

源码求值或实际帧已证明普通主体恒速、经过节点无依据共同归零、承诺缺失、近读目标仍读不清或对象无故消失时，对应项记“未通过”并先修；尚未完成的 1× 主观审看另记“未验证”。未验证不能覆盖已知失败；抽帧与代码也不能反过来证明整段观感通过。

连看前一动作减速、全停、下一动作缓入构成的体感停顿，不只统计零速度时长；核对整段哪些地方只需阅读对象稳定、哪些确需全画面停住。比较可辨不等于全场固定，非零微动、各次标“阅读”或都短于两秒也不能放行重复起停。局部提前后连查到下一处必要停顿，不能把空等推到尾部；必要阅读、妥协、反问、情绪停顿与真实依赖保留，不用常驻运镜充数。

交审前沿剧本承诺逐条反查到**对象、实际函数、时段和编码帧**，再与一个最相关的认可完整过程对照屏幕速度、动作关系、镜头收益和时间分配。屏幕速度的比较先统一预览画布、取主体中心和边缘等跟踪点，用生产的对象与相机最终变换求轨迹，比较累计屏幕路程、主变化完成时刻、低速尾段和可见范围；曲线参数进度不是屏幕路程进度。它只是定位方法，仍须核对应编码帧及 1× 连看。交审通过线认本期 DESIGN 的 `motion.gates`，不把范例速度或秒数另设成一条通过线，也不用“未验证”代替工具结果。

近静止累计较多或反复短停时，仍触发上述范例对照复看和 1× 连看。**每个窗口**都说明稳定对象、阅读／比较／情绪用途和下一动作可接管时刻，不能只解释两秒以上长窗。用途说明不能抵消 `motion.gates` 已算出的未通过。**禁止靠拉长已有动作来压低静止统计**；必要阅读有理由保留。未完成连续观看如实记未验证，但不能把门禁未通过改记未验证。

首版整段预览须覆盖本段完整采用配音范围，不能只交高光动作。可用低清降低成本；已有等效完整预览或高清成片可直接作为证据，不为“低清”名目重复转码。实际发现的闪隐、断线、版本错误、读字冲突先修受影响部分，再精修或扩大渲染。重点是过程证据和时序，不是文件规格。

## 程序化动画的确定性与连续性

仅检查本轮涉及的程序化动画，用已有工程实现；不强制新引擎、新依赖或追改历史工程。落实以下适用项，并把实现依据和少量对应帧写入现有 QA／局部证据。

- **独立求值**：任一时刻的对象与历史版本由事件或纯函数确定；不靠顺播到某帧后再向数组追加状态。先等字体和素材就绪；随机性固定种子或由帧确定。
- **单一对象状态**：共享对象每帧一份权威状态，明确来源、首现、可读／持有、退让／退场；提取／复制从可辨来源分出，展开有真实几何或遮罩过程，整组淡入不能替代。建立状态、跨镜硬切、焦点降亮及本期 DESIGN 确认的例外按[默认进出场与替换](../experience/视觉叙事与连续MG.md#默认进出场与替换)执行；纯淡变不是默认过程。动作结束或焦点转交不等于卸载；重叠窗口不能叠出两套完整场景。历史卡使用独立 ID 的固定快照，不随主卡一起升级。
- **最终位置绑定**：先求主体最终变换，再绑定光标、选框、线根及曝光区域。接收载体回接时，若候选须暂时保持世界位置，按当前帧变换补偿；附着／自由切换检查主体与相机合成后的屏幕位置、切线和速度连续，不能只核对局部坐标；不靠上一帧累加补偿。
- **稳定显现**：会变长的复合线将连接段、核心、自由端分别控制，或用等价稳定参数化。新尾部增长不能让已显现的核心退画、跳形或重描；接点无裂缝、双描边或无意折角。
- **首现、末现与内容替换**：在原事件中记录源／目标及内容版本，检查旧内容最后可见→所选机制→新内容首次可见；退场检查最后可见前、中、后及去向。同节点 ID、bbox、alpha 不变不能豁免内容替换。分出物起点须对应源物当时的最终屏幕位置，不沿用源物移动前的常量。运行[工程运动检查](../tools/README.md#工程运动检查)定位纯透明度进出与无机制内容替换，疑点再核源码和实际编码帧，不自动判观感失败。
- **首现像素**：本轮新增／返修对象用与成片相同的引擎检查入场前、首个可见帧、过程与完成态，再对照最终编码帧；复制核对同址来源，展开核对实际面积，路径核对已绘长度和端点。挂载、零进度、bbox／opacity 变化不证明几何真的逐步绘出。生产中曾出现归一化 `pathLength`／圆头 dash 首帧铺满整线；按实际像素修实现并回归，不能用声明绕过。可运行证据见[入场与跟随 v8](../assets/motion/ep07-entry-follow-v8/README.md)。
- **实际工程对照**：取真实事件前、中、后及段间边界帧，核对对象、版本、遮挡、真实 bbox 和空白边界。直接跳到比较／归档／末段，与顺序求值的同帧状态或无损帧对照；有依据地设置与对象尺度、渲染精度相符的容差，不把压缩差异当对象变化。
- **屏幕运动检查**：按[过程与屏幕审计](../tools/README.md#过程复用与屏幕运动审计)从实际渲染函数及最终变换导出主体边界、尺度、动作与交接点，检查恒速／中段巡航、经过态共同归零、接力空隙和近读目标；不能用另写一条理想轨迹代测。数据映射及必要停顿绑定真实依据，不以任意理由字符串免检。疑点对照源码与编码帧核实；参数、曲线名和静止比例不能代替。修改动作时同步原标记与对应声音点。

记录测试对象、实际帧／时间与结果；脚本未覆盖的项目明确列出，不将人工检查伪称自动检查。技术一致只排除工程缺陷，不证明表现力和节奏已通过。

## 三种画面检查

删字测试：去掉解释性标题后，主体关系仍然可见；必要标签可以保留。

静音测试：能看出对象、变化、因果或有意表达的情绪。

合看测试：画面与配音协同，触发、阅读、停稳和转场合适。录屏要以真实播放检查输入与结果能否读清，静帧只能证明内容存在。

实际片对标：按[连续 MG 经验](../experience/视觉叙事与连续MG.md#接触遮挡与章卡)核对主体变化、观看推进及整段节奏，保留必要阅读与情绪停顿。该节的“14 图／11 次镜移”失败案例说明：数量、非线性和技术通过不能抵消主体内容与观察任务长期不推进；案例时长不是通用阈值。

样片或整段交付前，程序化动画按[工具方法](../tools/README.md#过程复用与屏幕运动审计)完成对应工程审计，并用动态自检对照实际编码文件的总览、静止区间与关键过程帧。交审前再按[运动量化门禁](../tools/README.md#运动量化门禁)算出第 1–5 条，与 `motion.gates` 并排；任一条未通过先返修，不能以未验证交审。工程检查按实际动作适用：只有显现且确无位移、缩放、旋转或运镜时，不要求为过检添加这类运动；显现区间、可见对象和取景仍须由生产采样及实际帧核对，缺测或把实际运动改标签不能记不适用。输出作为原 QA 的局部证据，不再建第二套状态表；未测成不是通过，已证实缺陷先修。未完成的 1× 主观检查另记“未验证”，不能掩盖已知失败，也不能凭工具零告警宣布观感通过。

## 返修只重查受影响内容

收到用户看片意见（返修要求或确认回复）时，在写返修说明或采用登记的同一步，按原话记入 QA 状态表对应对象（写“用户原话：……”），不改写成规则语言；期末复盘直接引用。

改动前写清“本轮修改、必须保持、完成后复查”，已有明确要求直接沿用。“必须保持”只写有用户确认或明确采用记录的内容，并注明出处；旧工程里存在但未经确认的实现，写成可改的底稿，不因为存在就锁定。先记录实际时段与可见症状，再归因到方案、时间组织、参数或工程。每轮优先解决 1–2 个主要问题；明显工程缺陷及时修，不受这个数量限制，不规定返修轮数。主过程不成立就返回方案，不能只反复换曲线；三档参数都沿用同一个平淡过程，不能因三档齐全而通过。改完核对目标已解决和保持项未破坏，再决定是否采用新版。

| 变化 | 重新检查 |
| --- | --- |
| 配音内容、停顿、顺序或时长 | 受影响画面、字幕、声音点与后续时间；必要时重新锁画 |
| 配音音色或增益变化，内容和时长不变 | 音频 |
| 主动作、取景、揭示或交接实质变化 | 更新受影响剧本、状态图／标注及采用指针，重查对应画面与对点声音；时长改变时同步下游 |
| 仅曲线、材质或局部素材变化，过程不变 | 复查受影响画面与适用声音点，不重做全套设计 |
| 素材裁切、变速、入出点或段落时长变化 | 以实际画面重校动作与声音点，复查受影响画面、字幕和接点；总时基变化同步下游 |
| 仅 SFX/BGM/原声策略变化 | 音频，不要求重做画面 |
| 字幕时间、断句、样式变化 | 字幕；涉及遮挡时检查对应画面 |
| 文件仅改名，内容哈希相同 | 重绑路径，可沿用原检查证据 |
| 同路径内容变化 | 按实际变化重开相应检查，不能继承旧通过 |

总控更新采用指针后，把相关 QA 改为未验证，完成实际复查再填写结论；旧结论保留在原版本证据中。分段任务仅交建议更新，由总控写回中央表。

控制文件不越写越长：整期交付后把大段表里已结束阶段的补记移入本期历史文件，表内只留当前状态、采用版本和未决事项；接入说明每次更新改写当前一节；QA 只引用采用版本的证据，被替代版本的自检、抽帧和临时数据不再作为证据维护。移动前留回退点，删除文件前先确认。

## 规则效果与模型对照

规则升级后，在下一次适用的代表段保留与所选范例的实际完整片段对照，核实主动作、观看推进和节奏是否改善；沿用现有 QA，不新增评分表或审批。没有新产物前，只能说文档与逻辑已检查，不能说画面效果已提升。

确有模型选择需要时，可用相同输入、参考、原声、时长、约束与迭代预算做代表段对照，记录模型、工具和人工干预，比较完整动态。它不要求每次切模型都测试，不固化排名、不保证较弱模型效果相同，也不自动授权额外调用、安装或费用。

## 发布前

将最终标题、封面、字幕、简介、链接与成片一起核对：承诺是否兑现；事实与推断是否区分；商业关系与来源是否说明；是否出现隐私或未获许可的材料。画面里的外链、联系方式、二维码和社媒账号行：设计的画面文字已在镜头剧本阶段排过，这里核对成片与之一致；真实截图和录屏逐个看。当前平台规格或政策需要时查官方来源，不猜审核结果。确认发布对象和具体材料后再执行对外发布。
