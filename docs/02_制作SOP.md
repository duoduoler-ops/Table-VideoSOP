# 制作 SOP

适用：以已确认配音为时基的科普、讲解、观点与演示视频。目录按[目录与并行协作](03_目录与并行协作.md)，验收状态与返修按[验收与返修](04_验收与返修.md)。

## 开始时只确认必要输入

目标、受众、平台与画幅；采用定稿和配音；已确认的 DESIGN；现有素材；制作路线。没有的信息标待补，只阻塞真正依赖它的工作。费用、授权或内容决定不明确且影响结果时再询问。

整期文件写入该期目录；先按[目录正文](03_目录与并行协作.md)定位，尚无本期目录时按主题建立。单段文字方案按当前范围交付，不为它补建整期控制文件。

## 制作顺序

| 阶段 | 主要工作与产物 | 进入下一步的依据 |
| --- | --- | --- |
| 系列准备 | 环境核对、静态与动态测试、DESIGN | 对采用样本与范围的用户确认 |
| 输入准备 | 完整稿；可选审稿；采用配音与校对字幕 | 用户确认稿件和配音；内容与时间对应 |
| 大段规划 | 制作大段表、重点审查、生视频推荐 | 用户确认划段、路线、分工及候选取舍 |
| 并行准备 | 专属目录、任务书、可复制指令 | 默认并行或用户所选方式；标明允许阶段 |
| 镜头剧本 | 一份完整剧本：简明配音对照供审阅，制作细节同源折叠 | 用户审一次已展示范围，不另审一份摘要 |
| 视觉设计 | 关键状态证据、必要的过程预演、真实设计图与运动标注、全片视觉总览 | 风险按适用样片关卡解决；用户确认展示的版本与范围 |
| 制作 | 一个正式工程或总装入口；首版完整预览核实过程适配，再精修 | 同类型且相关风险已解决时复用对标；未解风险先解决再扩展 |
| 总装与锁画 | 实际全片审片文件 | 画面检查及用户确认 |
| 声音与字幕 | 可选 SFX/BGM，已有声音校准与字幕制作 | 最终合成与实际检查；统一进入最终 QA |
| 交付与发布准备 | 成片、源文件、封面标题简介、来源与检查 | 最终 QA；发布材料核对；用户明确发布决定 |

可选审稿没有被选用时，直接从作者确认稿继续。可选 SFX/BGM 没有被选用时，保留已确认配音和适用原声，继续字幕与验收。声音规划可在视觉设计时开始，正式对点必须认实际采用画面。

## 大段怎么划

按照叙事任务、视觉关系、技术路线或风险变化划段；一个完整关系可以覆盖多句话。不同路线的短插片可归属一个大段，不必每个镜头再建一个任务。开场可以单独成段。

每段至少回答：声音已经给了什么信息；画面新增什么关系、证据或情绪；哪些文字必须留下。选择构图和动作源码前，按[增量核实](../experience/视觉叙事与连续MG.md#设计时核实增量)承接具体上下文，并在实际关键状态中找到判断依据与可见后果。只把口播换成大字、图标或通用受阻动作时，先改承载内容和过程。

出表后自动附两张短表：

- 重点审查：具体疑点、影响、验证办法、依赖，以及可先做部分。
- 生视频推荐：配音锚点、画面增量、动作前后状态、参考职责、风险与替代路线。没有合适候选就说明原因，不按比例凑数量。

在聊天主动指出最值得先看的问题。推荐不等于采用，采用不等于已经生成。准确文字、产品结果和真实操作用可核验的材料，不用生成画面充当证明。

## 设计怎么交

出图前，总控按[镜头剧本模板](../templates/镜头剧本.template.md)写完本次范围。三列正文直接呈现 **观众起初所知 → 可见依据 → 对应部件变化 → 新理解或未解决的结果**，连同必要取景、阅读和接棒；关键触发不能藏在折叠细节。阅读、比较、情绪按自身任务写。已有适用确认直接承接，本段缺小节先补写交审，不用分段确认代替剧本确认。

干净图采用真实素材或实际可编辑图形；程序绘图可作为成品，线框占位不能冒充。关键状态从同一部件过程取证，按[覆盖表](../templates/镜头剧本.template.md#关键状态覆盖)选择能解释机制与遮挡的状态，区分经过和停留；不按图号统一补间或强制停车。按[图旁重点](../templates/镜头剧本.template.md#图旁的配音与审阅重点)显示采用原文和具体判断问题。

设计阶段共同安排主体与[观察方式](../experience/镜头推进与转场.md#段落吸引力与镜头推进)，落实空间适配；对象内部处理与传递、接触反馈分别设计，保留合理静止。实现前按[最小动作依据](../experience/视觉叙事与连续MG.md#进入动画前的最小动作依据)承接已审过程，补齐[动作标记](../templates/动作与声音标记.template.md)，按[职责曲线](../templates/DESIGN.template.md#职责曲线与校准)选择运动；搜索、指向、拖动不直接套快速传递。读取截断补缺章，同任务已读未变不重读。

新 MG 从[共用制作起点](../assets/motion/production-core/README.md)接入内容驱动部件、空间曲线路径和共同排时；已有工程按[源码目录](../examples/05_完整过程源码.md)复用局部关系。状态、绘制与审计同源，首版另存后再返修；原例结局与通过结论不继承。

全片视觉总览确认展示版本和范围；静态不证明动态。正式批量制作前核对总览授权，缺失时由用户决定；局部风险预演可先于总览。首版完整预览即核实承诺，工具与实际观看按[验收正文](04_验收与返修.md#完整过程预演与精修)执行；不新增表或审批。

## 制作与接入

每期只设一个正式工程或可复现总装入口。各段共享已确认环境，保留专属源码和参数；并行本身不要求复制依赖或独立建工程。总控处理共享组件、依赖、中央状态和最终拼接。

分段完成后先交候选与[接入说明](../templates/接入说明.template.md)。总控核对准确素材版本、首尾接点、时间范围、声音策略及检查证据，再决定采用和接入。总装后必须检查段间连续性。程序化动画落实[确定性与连续性](04_验收与返修.md#程序化动画的确定性与连续性)，只查本轮涉及的实现；主过程改动同步设计依据，不沿用失效图。

## 交付与复盘

按当前任务范围交付可编辑源、实际使用参数、素材来源、配音与派生字幕、生成提示词、复现命令及 QA。封面与简介只承诺成片真实展示的内容；含个人信息的界面先脱敏。

整期交付后按[复盘提示词](../prompts/09_复盘.md)和[复盘模板](../templates/复盘.template.md)复盘：满意的画面登记为今后的对标片，返工按“规则没写／写了没执行”分别处理，同时列出可删减项。通用方法进入经验正文，个人偏好进入 DESIGN，本期特例留在本期；不要把一次案例的秒数、构图或否决理由变成所有项目的强制规则。制作中的反馈原话记进 QA，本期问题先改本期任务书，系列规则在复盘时统一升级。

## 从输入到可用时基

本期说明先接收来源；制作大段表建立后，采用路径由该表统一维护。确认配音不仅是有文件，还要核对完整语义范围、顺序、停顿和稿件一致性。字幕显示区间可辅助定位，不能直接当作逐词起音。

素材、稿件或工程互相冲突时，先核对用户确认，仍缺依据再问从哪句到哪句或具体时间，不自行按旧字幕猜。配音尚未稳定时只做不依赖正式时基的设计。

大段执行索引必须能定位设计图计划、负责人、风险、依赖和任务书；主表不能仅有路线却找不到谁制作和交什么设计。完成片段时将实际采用素材、声音策略与源码接口写入接入说明，总控接入后同步中央状态。
