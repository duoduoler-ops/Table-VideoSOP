# 文案检查（可选）

这是一套参考检查方法。作者仍在学习文案创作；使用者可以跳过、调整检查维度或自行改稿。选用本模块只授权检查，是否让 Agent 修改还要看本次任务范围。

## 什么时候用

已有完整逐字稿，想检查事实、逻辑、口播和空话时使用。输入稿件、目标受众、必须保留的观点和已知事实来源；平台或商业约束有就提供，没有不编。

已有确认定稿时直接进入配音与制作。这里不要求重新选题、搭骨架、交多版开头，也不承诺能自动写出有个人表达的好稿。

## 检查顺序

1. **事实与承诺**：数字、引文、产品行为有无依据；推断有没有写成事实；开场和结尾承诺是否被正文兑现。
2. **逻辑与衔接**：前后是否矛盾，因果是否成立，上一段结束后能否理解下一段为何出现。
3. **信息增量**：删除某段是否仍不影响事实、判断或必要情绪；连续换说法却没有新增信息的内容能否合并。
4. **口播**：一遍能否听懂主干，有无不自然语序、长句、堆名词、书面连接词或反复同一节奏。文字检查后仍建议作者实际读一遍。
5. **作者表达**：是否保留了真实经历、立场、取舍与措辞；不能为“口语化”补造故事或人格。
6. **风险预检**：核对可见的隐私、来源、商业披露和效果承诺；涉及需要专业判断或外部核实的内容，标明依据缺口。稿件预检不代替最终发布材料检查。

输出只维护一份[审稿建议](../templates/审稿建议.template.md)：每条给出原句或位置、具体问题、修改方向和优先级。没有实际问题就简写“未发现”，不为栏目凑条目。

## 语言检查附录

完整检查模式同时检查：可验证事实、真实立场、空泛连接、过度整齐、过度宏大、单一句长、缺少具体取舍、固定句式反复、空心比喻、输入提示过于笼统、母语口播是否自然。

这些是定位线索。出现某个词或句式不自动判错，搜索只能找候选，要结合语境说明它是否损害表达。个人禁词、禁用标点与偏好放在本期说明的“可选写作偏好”，不作为所有人的强制标准。

长稿增加材料充分性检查：重要判断有没有具体事实支撑；缺少的是公开来源还是作者经历；哪些地方需要补证据或缩小论点。篇幅变长不自动要求补做写前流程，也不靠固定材料数量宣布内容可靠。

观众动机、可转述观点和立场一致性按下文五项建议检查，结果合并进同一份建议，不另发多份报告。

## 作者选定之后

作者自行修改：只复查改动及受影响的事实和衔接。

要求 Agent 代改：只处理明确采纳的编号，保留未选内容与作者表达，另出修订候选。作者确认后才登记为当前定稿；修订稿不能仅凭文件名成为定稿。

仅改措辞不重跑整套报告。改变结构、核心事实、立场或开场承诺时，扩大到受影响的逻辑与承诺检查。已进入制作后改稿，按[变更影响](04_验收与返修.md)检查配音和下游。

使用入口：[文案检查与选定后修改提示词](../prompts/03_文案检查_可选.md)。相关方法来源见[来源与许可](08_来源与许可.md)。

## 完整检查模式

选择本模块后，默认执行完整视频稿检查，下面的九部分是统一输出结构：结论、必须修改、划走检查、五项建议、五病根、风险预检、可优化、建议保留、作者处理清单。用户明确要求局部检查时才缩到相应范围。可选指是否使用模块，不等于默认只做一部分。

五项建议逐项给有效／弱／无效、原句依据和一条建议：沉默解除（是否说出观众难表达的顾虑）、满足动机（看完有什么帮助）、立场框架（判断是否明确且有依据）、传播入口（是否有可转述的具体内容）、信念结构（前后事实与价值边界是否一致）。没有对应句子就注明缺失，不伪造引文。五项全弱也不自动要求重写，作者可以不采纳。

五病根逐句定位实际命中：报告腔骨架词、行话与名词化、单一句长、缺对话感、书面连接词。语言附录的十一项同时作内部检查，结果合并进这份报告，不再交另一套回执。

长稿达到约 1200 字时增加材料充分性与长文表达检查。个人禁词、标点、材料数量和统计阈值不作为公共硬门；需要严格偏好的作者在本期说明选定。

风险预检区分平台可能识别的信号与内容实质问题：联系方式、外链、广告结构等只能说明可能性；虚假效果、未披露关系、隐私或将推断写成事实要给依据和修正方向。最终仍随标题、封面、字幕、简介与置顶评论一起复查。
