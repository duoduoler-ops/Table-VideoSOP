# 快速开始

目标：第一次使用时，先做一条短片，走通“确认风格 → 稳定配音 → 设计 → 制作 → 验收”。不必先读完所有经验。

## 1. 放好资料并检查环境

新系列使用本包根目录作为工作区，保留 `docs/`、`experience/`、`prompts/`、`templates/` 的相对位置。复制[初始化提示词](../prompts/01_初始化与环境检查.md)给 Agent，填写系列名、本期主题与工具路线。

成功标志：Agent 列出实际可用工具、缺失项和下一步；本期资料目录已建立；没有把“安装文件存在”当成“环境已验证”。需要安装时先看明确安装方案，再决定是否执行。

已有项目不要直接覆盖规则。让 Agent 将本包资料放入一个独立参考目录，列出与现有规则的冲突和需要接入的链接，确认后只改这些入口。

先用初始化提示词明确读取根目录 `AGENTS.md`，再用普通话描述任务；后续由入口选择正文，无需每次点名 SOP。宿主不会自动读取规则时，每个新对话先补一句“读取根目录 AGENTS.md，再处理下面的任务”。文件放在磁盘上本身不等于已经生效。

## 2. 做自己的 DESIGN

使用[设计提示词](../prompts/02_建立DESIGN.md)分三次推进：

1. 提供喜欢的静态参考，比较真实画面的背景、字体、构图、图形与角色。
2. 用相同视觉元素做动态测试，看形态变换、接触反馈、跟随和停稳；偏好克制运动时明确说明。
3. 两项确认后，将具体采用样本及适用范围写成根目录 `DESIGN.md`。

有 IP 就填[角色说明](../templates/角色说明.template.md)，没有则写“不使用角色”。无需继承示例配色、角色或弹簧动效。静态方案确认不代表动态方案也已确认。

成功标志：根目录存在有确认记录的 `DESIGN.md`，能找到采用的静图与动态测试。未确认的部分仍明确写待定。

## 3. 准备一份稳定输入

将完整稿放到本期 `01_稿件/`。需要建议时用[可选文案检查](../prompts/03_文案检查_可选.md)；也可以直接使用自己确认的稿件。

自己读一遍稿件，准备实际配音。确认内容、顺序、停顿和采用文件；派生字幕需核对专有名词与时间。尚无配音时，Agent 可以规划语义和设计，不能猜正式时间码或开始依赖时基的动画。

成功标志：本期说明记录确认定稿、配音及规格；后续大段表引用准确文件。还没有的文件写待补，不创建空文件冒充输入。

## 4. 出表并确认

复制[大段表提示词](../prompts/04_制作大段表.md)。重点看每段的声音已提供、画面必须新增、必要上屏文字，以及 Agent 主动列出的审查项和生视频推荐。

确认时可直接说：“确认这版大段表的划段、路线与分工；采用其中这些生成候选；按默认并行方式准备。” Agent 随即建立目录、任务书和逐段开工指令，不替你打开新对话。

## 5. 并行设计，再制作

总控交付 `分段开工指令.md` 后，从同一个系列根目录开启新对话，每个对话粘贴对应段的完整指令。分段先交真实设计图与运动标注，总控汇总成全片视觉总览，供你一次确认。

获准制作后，再让对应任务继续。未解决的高风险先做覆盖难点的代表样片；已经验证的做法不重复审批。生图、生视频提示词可同时准备，由你手动生成并交回候选文件。

## 6. 总装与验收

使用[总装提示词](../prompts/08_总装验收与封面.md)。先确认全片画面，再按需做[声音制作](../prompts/07_音效与配乐_可选.md)，完成字幕和最终检查。

最后拿到：成片、适用的 clean 母版与字幕、可编辑源码或工程、素材与授权记录、复现说明、QA 结果。实际未播放检查的部分不会因为导出成功而变成“通过”。

初次填写可对照[两段规划示范](../examples/01_两段演示.md)和[DESIGN 填写示例](../examples/03_DESIGN填写示例.md)。它们演示填写方法；正式时间、视觉参数与采用状态由自己的配音、样本和确认记录决定。
