# S04—S06 分段、剧本与设计

正式精确时间来自采用配音和经核对对齐；语义草稿可以只用句子锚点并标注未对点。任何视频画面设计开始前，包括 S03 代表静态，先读[镜头推进](experience/镜头推进与转场.md)；涉及 MG 时同时读[连续 MG](experience/视觉叙事与连续MG.md)。同一任务已读且内容未变可复用。不以“复杂动画”“画面平淡”或用户提到运镜才触发。

先完成[画面路线核对](intake.md#进入画面规划前核对路线)，再交分段与镜头方案。回显已选形式和本轮允许范围；没有明确选择时先给选项，用户只求推荐时先给路线建议。不得把待审或旧版分段表当作用户已选路线。用户要求从选型重测时，暂停旧镜头候选，回到选择入口；不重做已确认稿件或配音。

正式分段前，按[测试与复用](style-and-motion.md#测试与复用)核对已确认静态和 DESIGN；缺独立运动样本不阻塞规划。先列语义与观看过程，识别具体新类型或未解高返工风险，再在设计阶段验证对应局部过程。已有适用动态证据直接复用，不能把草稿或动态确认当成分段、剧本与关键设计状态的确认。

## 从理解目标推导画面

代表静态与正式镜头共用这条设计顺序；写在已有方案或镜头剧本，不另建审批表。效果依据按[效果基线](style-and-motion.md#效果基线与适用范围)引用实际版本、片段及借鉴能力；没有适用范例就写缺项，不虚构确认。

1. **理解目标。** 按完整语义组说明声音已提供什么、观众起初知道什么，画面还须给出哪项依据或变化；“它、再次”等指代保留可辨的前段输入。先选有真实特征的内容，再选形式。阅读、比较和情绪任务不强造处理或冲突。
2. **对象与部件过程。** 写明依据何时可见、谁据此操作、哪个部件因而改变，以及结果怎样成为下一步输入。若本步要表达尚未定位，就不能同时准确标出答案；请求、接触或约束尚未成立时，不能先给出由其触发的处理结果。主变化与附属响应分清：相关部件为何跟随、保持或让位，靠本段含义和实际连接决定，不给任意附件补轻摆充数。MG 从[共用制作起点](../assets/motion/production-core/README.md)接入实际输入、条件与部件，历史关系按[完整动作迁移](complete-motion.md)复用；其它路线用实际素材及剪辑过程。
3. **空间与镜头。** 由需要看清的部件、关系和揭示顺序决定景别、布局、遮挡及镜头职责，不先锁成一个版式。在已有标注写“空间适配：候选／采用／不用＋观看收益、阅读或比较代价、素材条件”；层级和物理纵深均按[空间镜头](experience/镜头推进与转场.md#空间镜头)判断。
4. **共同排时。** 在采用配音内安排主变化、观察尺度、下一步启动和前一步收势，保留真实依赖与词点约束；经过态不自动停车，结果不为重叠而提前。复杂处理和阅读先有窗口，再安排进退与指示动作。阅读从完整、清晰、无遮挡且达到可读尺度时算，不默认全场冻结；曲线按[观看任务](style-and-motion.md#默认动作设计基线)选择。
5. **从过程取关键状态。** 从同一可编辑源按[关键状态覆盖](../assets/templates/镜头剧本.template.md#关键状态覆盖)取能检验机制的状态：触发前结果是否仍未发生、局部怎样改变、结果是否可辨。交接看双方，近读看实际尺度，标明经过或停留用途；图号不驱动统一插值。动态问题在现有预演或首版完整片中检查。

例如表达“还说不清哪里不对”，先保留搜索和笼统反馈；提出具体要求后，才准确指向对应部件并改变它。若前面已经框准答案，或修改完成后才显示指令，顺序就改变了含义。不是所有段落都套这条链：阅读看信息是否可读，比较看差异能否同看，情绪看可辨反应与节奏。

用[可反驳的观看目标](self-diagnosis.md#制作前先定义怎样会失败)检查上述方案；未成立就改内容、揭示次序或部件过程，不留到渲染后加大位移。

## 分段先分表达任务

按叙事任务、视觉关系、路线和风险变化划大段，不按固定秒数或一句一个任务。段内短录屏或生成片仍可归属同一大段。章节空档按实际配音确定，不硬塞章卡。

每段写声音已提供、画面必须新增、最少必要文字、完整语义范围、初始／结束状态与接棒、路线及依据。真实操作和结果用实际材料，不能用生成画面冒充证据。首次出表或实质改划段、路线时主动交重点审查和生成候选；没有合适候选说明原因，不凑数。

[大段表模板](../assets/templates/制作大段表.template.md)定义规划信息结构；采用、划段和进度写 state，控制目录的大段表是生成视图。当前生成器只输出摘要，完整待审方案及重点检查写在 `03_视觉设计/制作分段方案.md`，登记并由 state 引用；它不另存当前进度或采用决定。不能因为摘要视图未提供栏目就省掉检查提醒。纯单段方案不要求初始化 state。

交表时在聊天主动点出本次最重要的 1–3 项，例如“请重点看 D02 是否只重复配音、D02 到 D03 是否接得上”。每项写具体段落、问题与判断方式，不能只说“请检查”，也不能只把提醒藏在文件里。没有推荐生视频时一句说明原因；纯 MG 不额外引导换路线。

说明确认范围：“这次确认分段与路线；确认后我会交镜头剧本的配音—画面过程简明视图，供你一次审阅。”同时按[分段协作](sop/03_目录与并行协作.md)推荐执行方式：短小或依赖紧密时当前对话完成；多段能独立推进时说明总控与分段对话各做什么，让用户选择。分段粗细、镜头密度和对话数量不是一回事，不按时长或段数自动创建新对话。

## 镜头剧本先交过程

使用[镜头剧本模板](../assets/templates/镜头剧本.template.md)，默认展示“配音原文—可见过程与新增理解—本处判断问题”的简明视图；完整语义组一行，不代表一句一切镜。主对象变化、中间过程、镜头与实际取景尺度、高潮、阅读与跨段接棒，以及已知未解决问题、未解风险和影响本次决定的未验证项保持可见。对标依据、素材与实现细节在同一份剧本内折叠，不再手写另一份可独立修改的审阅稿。折叠不省掉关键过程，也不用“有动画”或原则名称代替观看目标。

大段方案确认后，总控一次写完本期需要设计的全部大段，保存在 `03_视觉设计/正文镜头剧本.md`；交审时只展开本次范围的简明视图并指出具体判断问题；详细底稿可展开，不要求用户逐项审源码、参数与历史记录。剧本没有交审或仍待答复时，不绘制正式关键帧。分段概述不是镜头剧本；对前一份分段安排的“是”只能确认分段。整份剧本一次明确确认可以覆盖实际展示的所有小节，不逐段重复提问。只改一段时，仅重审受影响小节与接棒。

角色参与叙事时同步设计其表情、视线、姿态与互动，再按[角色表演与素材充分性](style-and-motion.md#角色表演与素材充分性)核对实际素材。只有身份图不代表这些表现已具备；新增需求有缺口时先主动引导补图选择，再制作受影响关键状态，不靠重复静态角色填满整套设计图。已有足够素材或已选解决方式直接承接。

用户审阅表达过程只确认该过程，不表示设计图或动态已通过。将实际文字文件或稳定小节登记为 `kind: storyboard`，确认绑定该对象及真实审阅交互；不得把分段 config 换一个 aspect 充当剧本。详细登记见[状态契约](state-contract.md)。尚无某段小节时先补该段并交审，不顺手重新设计全片。

## 设计交真实关键状态

**先用真实状态验证观看过程，再细化动画。** 从同一可编辑源输出关键状态，按[正反过程案例](examples/04_连续MG正反过程.md)检查观众获得的依据、部件后果与下一步输入；核心关系缺失就先改设计。既有工程返修可抽实际帧作为待改依据，不另换引擎或重画成立部分。

按[关键状态覆盖](../assets/templates/镜头剧本.template.md#关键状态覆盖)交主体构图、前后态、解释转换机制的中间态、接触／遮挡与衔接。不能用随机半程帧、光标或微移凑证据，也不能把已确认的不同变化合成“持续讲解”来规避覆盖。按[图旁的配音与审阅重点](../assets/templates/镜头剧本.template.md#图旁的配音与审阅重点)把采用配音、当前词点和判断问题放到图旁，不能只给段号或让用户回长文查找。干净图和运动标注分开，不把版本号和待验证说明印进观众画面。

设计图按[静态样本与可动部件](style-and-motion.md#静态样本与可动部件)制作。MG 关键状态从可编辑部件源输出，静态与动态沿用同一套对象；同时交源文件和审图预览。外部合成参考图单独标明职责，不用整张生图替代 MG 设计测试，也不把尚未拆分的素材登记为可独立控制。

新类型或未解高返工风险按[完整过程预演与精修](sop/04_验收与返修.md#完整过程预演与精修)做带原声局部预演，在设计阶段进行；主对象、取景、字大小与阅读时间须真实，简化只用于次要装饰。预演不替代正式设计图，正式批量动画由总控核跨段后按本批授权进行。

总控用当前关键状态核跨段统一性与重复；节奏看实际过程，关键图按需要放大，不另建总览产物。把状态放回整段时间，按[三项实查](complete-motion.md#三项实查)核对新发现、主动作完成时刻及实际主体尺度。确认分别记录外观、关键状态与已展示方案；静帧不证明阅读和动态遮挡。

主动作、取景、揭示或交接在实作中改变时，更新受影响剧本、状态图／标注及版本依赖；旧图不再作为当前依据。分段只改获准文件，中央剧本、state 采用和 QA 交总控写回；曲线／材质局部调整且过程不变时不重画全套。

实现前使用[动作与声音模板](../assets/templates/动作与声音标记.template.md)：本镜头 00:00.000、实际 fps、全片 F0，记录触发、开始、接触、状态变化、结束及停稳。计划与实际采用分开；没有真实词点时标待核对，不能填猜测精确值。
