# S07—S08 风险验证与素材接入

P0 提供流程工具、完整 MG 源码示例和现有环境输出入口；各例按其 README 选择 Remotion 或 SVG／sharp；不内置运行依赖、生成提交、自动录屏或 TTS。先核对本次已有环境与授权，缺环境不自动安装，也不声称未执行的链路已接通。

进入动画实现或主过程返工，承接[画面推导](planning.md#从理解目标推导画面)的依据、部件后果和取景排时，补真实事件及代码入口；曲线按[观看任务](style-and-motion.md#默认动作设计基线)选择。实现静态版式后逐件补动画不能代替这一步。

## 过程预演与正式制作

局部预演／局部动画分别使用 `pilot`／`animate` 检查；正式批量制作及 S08 必须使用 `batch-animate`，核对当前实际画面目标的 static／batch-animate 授权及制作依赖。风险样片保持真实方案→样片制作依赖，审看与确认后另登记绑定双方版本的 risk-proof；不用反向依赖表达验证。准确请求和旧关系转换见[状态契约](state-contract.md#设计期预演与正式制作的状态边界)。

新 MG 从[共用制作起点](../assets/motion/production-core/README.md)接入本段的对象、布局和动作。绘制与检查读取同一时刻的部件状态。附着部件跟随实际父层，连续动作承接前一动作的结束状态，跟拍读取主体当帧的位置。Agent 按观看目的选择停稳、跟随或切镜，并标明实际动作区间。独立的单对象动画可用一句话定下这些内容，直接进入实现。

出交审预览走公共工程的 `render.cjs --video`，视频、`render-manifest.json` 和 `motion-report.json` 一同交回。已有 SVG、Canvas 等工程可沿用自己的渲染器，将实际绘制入口接到[同一检查器](../scripts/motion-gates.mjs)，用本次成片出报告；接不到的属性保留缺测。程序输出的疑点按时段核实际画面，确认的硬失败先修。对应正式 QA 的登记见[MG 效果证据](state-contract.md#mg-效果证据)。

视觉设计依据与必读入口见[规划](planning.md#从理解目标推导画面)；缺章或截断先补读，已读未变不重读。

进入制作先核对[测试与复用](style-and-motion.md#测试与复用)的适用证据和[可动部件](style-and-motion.md#静态样本与可动部件)。完整静态与制作授权明确后，普通动作按经验直接实现，在实际片段中检查；不因缺独立运动样本重开测试。部件不可控、目标引擎未接通等具体实现缺口先做必要验证，只暂停依赖它的部分；角色仅作已适配的固定标识时不新增表演测试。整张静图的存在不证明内部对象可控，也不证明动画链路已接通。

角色表演接入前复核[素材充分性及已选解决方式](style-and-motion.md#角色表演与素材充分性)。未补齐的表情、姿态、视角或互动素材不能靠整图变换硬做；已有补图决定直接承接，不重启询问。角色独立素材可以按所选方式补齐，MG 场景仍沿用实际部件源；姿态图齐备后另验实际切换和衔接。

同一视觉系统、对象演化与镜头方式已有适用确认范例且相关风险已解决时复用，在首版完整带原声预览核实本段适配，再精修。新对象演化／镜头关系缺少适用过程证据，或有未解高返工风险，在设计阶段先验证局部完整过程；多句话、新开项目或缺独立参数样本不自动触发小样。具体顺序按[完整过程预演与精修](sop/04_验收与返修.md#完整过程预演与精修)，不恢复固定三档或增加审批。

写明问题、通过条件、配音范围、采用设计和验证动作；按[审查卡](../assets/templates/review-card.template.md)交审时，把对应完整配音原文、实际区间和具体判断问题放在可播放片段旁，播放保留该问题必要的前后过程。简单标题样片不能覆盖复杂互动；接收延迟、跟随等次级反馈的参数对比，也不能替代尚未成立的语义过程、主要镜头或段落节奏验证。样片窗口须保留判断该风险所需的起因、主要变化与结果；前期实际测试已经覆盖同一风险则复用其证据。通过后登记范例的有效范围，不能机械复制构图和秒数。详见[验收](sop/04_验收与返修.md)及[连续 MG](experience/视觉叙事与连续MG.md)。

首个完整预览要能看出本段承诺的变化。按实际设计核主动作的起势和落点，需要接力、跟拍或替换时再核对应过程；固定取景、必要停稳和有依据的硬切各按其用途检查。发现画面静止时先找原因，不自动添加摇镜或装饰运动，详见[首版底线](sop/04_验收与返修.md#完整过程预演与精修)。首版整段预览覆盖完整采用配音，不能只交高光窗口；已有同范围有效完整片可复用，不必另转低清。普通适配检查由执行者先做，不把每个分段预览另设为用户审批；按原风险关卡与已约定交审范围提交。主过程未成立先修过程与时间组织；已知闪隐、断线、错版本或读字冲突先修受影响部分，再精修或扩大渲染。本次需要字幕时，分段整段预览交审前，按[字幕检查](experience/字幕与封面.md#字幕)临时叠加本段已有字幕核对遮挡，无需重渲画面；尚无字幕时先核字幕安全区，实际字幕遮挡保留待验证，结果记入接入说明的实际检查。

程序化动画实现前按[确定性与连续性](sop/04_验收与返修.md#程序化动画的确定性与连续性)落实本轮对象的独立求值、唯一存活状态、历史快照、最终变换绑定和稳定线条显现；以实际对象和跳帧对照检查，不凭存在 easing 函数放行，不新增引擎或依赖。

比较／回收关系按[回接范例](complete-motion.md#比较未结束时回接)实现：载体先回接时，候选仍须可辨；需保持原世界位置的对象由最终变换补偿，再转入归位路径。检查实际屏幕位置和速度连续，以及镜头、候选、载体是否抵消了应有变化。局部提前后复查后续空等，不能只让代码里的静止区间消失。

涉及提取、复制、展开、路径揭示或跟拍时，执行[入场与跟拍实查](complete-motion.md#入场与跟拍实查)。在现有动作标注补足源物、首次可见及持有关系；检查生产像素，而非只看时间窗和 bbox。局部调速保留已有效的主体／相机关联；变更需同时回归关联，不把跟拍退化为独立坐标补间。

## 剧本承诺落到实际画面

每段实现后先按[输出优先的诊断](self-diagnosis.md#看结果时先暂时放下作者解释)看实际过程，再在原 QA／接入说明对应剧本写“承诺 → 实际时段、对象和入口 → 画面证据／结论”。核对触发以前是否偷跑结果、真正承担含义的部件是否改变、指示动作及遮挡是否连续；方案已实现但表达不足就回方案，未接入渲染就修工程。

部件与指示动作的正反实现集中在[过程案例](examples/04_连续MG正反过程.md)；检查具体作用，不用外层轨迹、轻摆或边框反馈代替主变化。

运行[动态自检与工程测量](motion-check-method.md)，采样引用当前渲染所用的状态／动作，不另填迎合检查的数据；与编码帧核对可见性、局部大小及遮挡。项目 DESIGN 的数值约束仍执行，未通过先修；通过只覆盖测量到的对象、区间和属性。内部状态恒定、关键部件不可见或未覆盖，不能由外层轨迹达标推成过程通过。

整段时间与观看推进按[三项实查](complete-motion.md#三项实查)复核。已证实的因果错误、漏做、错位或读字冲突记未通过并修受影响范围；未做的 1× 观感与听校仍记未验证。过程改变同步受影响方案，不补写通过说明或改采用配音。

## 三种外部任务

- 手动图片／视频：读[生成经验](experience/手动生图生视频.md)，填写[生成任务包](../assets/templates/manual-generation-task.template.md)。交完整可粘贴提示词、逐图职责、动作和声音计划、回传要求。只有用户提交生成和重抽；工具可用也不代提交。
- 真实录屏：读[录屏经验](experience/录屏剪辑.md)，填写[录屏任务包](../assets/templates/screen-recording-task.template.md)。真实步骤、源到成片区间、保护区间和输入／结果阅读分开；没有实际素材不伪造成功结果。
- 外部配音：填写[配音任务](../assets/templates/external-voice-task.template.md)与[对齐记录](../assets/templates/alignment-record.template.md)。试音与全文分别核对，P0 没有自动服务调用。

任务模板是待用户输入的表格，允许保留适用字段的填空；实际交给用户操作的任务必须替换当前已知值，不交一堆空字段让用户猜。确实缺失的必要决定写清阻塞和可继续部分。

## 收片与分层返修

按实际内容和哈希识别文件，文件名／高版本号不等于采用。先保留原件，登记候选、来源、参考、实际工具设置、时长、入出点、文字与原声策略。登记不等于通过；状态操作见[状态契约](state-contract.md)。

| 失败位置 | 先处理 |
| --- | --- |
| 底图身份、语义或文字错误 | 修提示词／底图，用户重生成后再处理依赖视频 |
| 底图通过、视频动作或镜头错误 | 保留底图，只处理视频层 |
| 画面通过、声音失败 | 保留画面，用获准后期替换、静音、混音或重新对点 |
| 进出点不合适 | 先看素材余量裁切，保护必要动作与阅读 |

不凭提示词计划给完成素材判通过。裁切、变速或换起点后，按实际画面重新标动作和可闻锚点；提取原声为独立轨后关闭容器重复音轨。详见[声音方法](sop/06_音效与配乐_可选.md)。

## 总控与分段接入

按已选[协作方式](sop/03_目录与并行协作.md)串行或并行。当前总控维护中央 state、QA、共享组件和正式总装入口；分段对话只在自己的范围写源码、参数、预览及局部证据，不初始化整期、不写中央采用，也不复制依赖。

正式派工时运行 `node scripts/workflow.mjs validate --project <本期目录> --action batch-animate --scope <本批对象>`。成功后将返回的 `workerInputs` 交给执行者，按其中的剧本路径、小节、输入版本和授权范围开工；缺少当前剧本时先补齐该段。设计期局部风险预演可在明确获准范围内先做；分段设计回传后由总控核对当前共享物件、实际首尾与整体风格，正式批量动画仍按本批授权范围放行。具体 action 与阶段关系见[状态契约](state-contract.md#设计期预演与正式制作的状态边界)。候选附[接入说明](../assets/templates/接入说明.template.md)，总控核对输入仍有效、首尾接点、时基、声音与真实检查后登记采用。已经明确且可核验的局部用户确认直接承接，不再让用户重复回答；生成文件本身不等于确认。总装前的版本、规格、配音范围及接点由总控内部核对；候选浏览 HTML 只作重点和跳转入口，不再要求一次独立的全片批准。带原声连续片何时承担锁画、正式总装怎样核实后复用画面决定，按[画面和最终文件分别确认](review-and-repair.md#画面和最终文件分别确认)执行；制作前的关键状态确认与跨段核对仍保留。

交用户前修复已发现的明显问题；[动态自检方法](motion-check-method.md)提供区间定位与实际帧证据，技术统计通过不等于表达和手感通过。正常速度审看／审听不能由抽帧、解码或统计替代；暂缺连续观看能力也不能成为交付已知缺陷的理由。默认选择授权不降低效果基线。
