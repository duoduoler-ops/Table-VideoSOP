# 项目规则在 Skill 模式下的职责

本文件由开源 AGENTS.md 转换为参考页；它不会被复制成用户项目的自动生效规则。主入口是 [SKILL.md](../SKILL.md)，阶段资料见[资料索引](library.md)。

- 先遵循当前任务范围和宿主约束；首次读取入口；画面设计含代表静态前必读镜头推进，MG 设计／制作／审查同时读连续 MG，其余专题按需读取。
- 规则以实际返回的正文为准；长文按章节读取，返回被截断就补读缺的章节，发出调用不算已读。同一任务已读且未变不重读，不另建阅读回执。
- 进入动画实现或主过程返工，必读[默认动作设计基线](style-and-motion.md#默认动作设计基线)与[默认节奏](style-and-motion.md#默认节奏与按需对比)，在已有标注落实[最小动作依据](experience/视觉叙事与连续MG.md#进入动画前的最小动作依据)。设计阶段必须完成[空间适配判断](experience/镜头推进与转场.md#空间镜头)，物理纵深也触发。
- 进出场与内容替换按[默认动作语言](experience/视觉叙事与连续MG.md#默认进出场与替换)有可见过程，纯淡变和无过程突现突失默认不允许；本期 DESIGN 例外须逐条确认。首版底线与交审反查认[验收](sop/04_验收与返修.md#完整过程预演与精修)。
- 纯审稿、单段方案、一次文字修正只交当前需要的结果，不建 state、QA 或整期目录。
- P0 提供流程、状态、完整 MG 源码及现有环境渲染适配器；不内置运行依赖、TTS 或生成服务。实际能力以当前工具与实测为准，示例不构成通用质量通过。MG 设计／实现按[完整动作迁移](complete-motion.md)匹配实际过程源码。
- 当前环节按[任务书](sop/03_目录与并行协作.md#环节任务书)绑定输入与允许范围；跨段核对和分批放行保留，准备完成不等于放行。任何环节审核画面先读项目 DESIGN，生成提示词与字幕制作分别走对应经验入口。
- 当前对话担任总控；短片默认本对话完成，独立大段可按用户选择多对话并行。分段对话只做任务书范围，总控统一剧本、跨段核对、中央状态与总装。创建或联系其他对话遵循当前宿主与用户授权。
- 本期采用、选择、授权、进度与确认只在 state.json；制作大段表是生成视图。QA 结论只在 QA 状态表内的结构化区，正文视图不可独立改状态。
- 图片、视频生成及重抽一律由用户手动提交；Agent 准备完整任务包、验收和获准后期。工具存在或预算批准不解除这条边界。
- 新结果先登记候选，确认绑定实际对象、方面、摘要和真实交互证据；旧确认不自动放行替换文件。
- **先核对主对象变化、观看推进与整段节奏。** 渲染成功、字段齐全或曲线合规不代替实际审看。静态确认只覆盖展示的静态方面。
- 具体的新对象演化或镜头关系缺少适用的完整过程证据，或有未解决的高返工风险时，在设计阶段做局部完整过程预演；单纯首次制作或没有独立运动样本不自动触发，静态确认后照常进入分段和剧本，不预设前置三档选样。完整过程先于参数精修，按[预演与精修](sop/04_验收与返修.md#完整过程预演与精修)执行。
- 设计前按[规划](planning.md)落实具体范例与本段借法，共同设计主动作、观看推进、接力和必要停顿；按[审查与返修](review-and-repair.md)核对实际表现，不以关键帧数量、运动占比或曲线合规代替。
- 每个已确认关键变化按[状态覆盖](../assets/templates/镜头剧本.template.md#关键状态覆盖)提供图／素材区间证据，不按固定秒数凑图。
- 程序化动画核对[独立求值与连续性](sop/04_验收与返修.md#程序化动画的确定性与连续性)；主过程变化同步设计与采用依据，技术检查不代替观感。
- 动作与声音以实际采用素材、局部零点、fps 和 F0 记录；裁切、变速或换入点后重校准。
- 局部返修只改授权范围；安装、登录、费用、删除、持久配置和发布按本次授权处理。
- 不把作者角色、配色、帧数、响度或坐标升级为新用户硬值；本包明确列出的动作默认允许按本期 DESIGN 的例外机制调整，来源参数不冒充本期已验证效果。
