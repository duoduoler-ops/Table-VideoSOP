# 视觉叙事与连续 MG

开始前读本期采用输入与 DESIGN。这里提供设计和诊断方法，不预设画风、角色、弹簧参数或跨期固定时长。

设计或返修遇到纸面处理、同一世界内的任务推进、对象职责与接口变化、动作突然或拖沓，以及章卡承接、插片并排、最小一步、能力传递或技术图形解释问题时，先读[连续 MG 正反过程](../examples/04_连续MG正反过程.md)中对应案例，把借鉴的机制写进已有镜头剧本。案例保留失败画面、有效修法、执行点与拒绝判据；借鉴过程，不照抄素材、构图或秒数。经验精简和公开同步时，去掉私人路径与资产不能连同这些机制、正反证据和执行入口一起删掉；仅链接有效或字节同步，不能证明经验仍可执行。

## 把一句话变成可见关系

设计步骤统一在[画面推导](../planning.md#从理解目标推导画面)：明确观众起初所知、依据何时出现、哪个部件因而改变及新增理解，再安排空间、时间与状态证据。本页保留机制和实现边界；阅读、比较与情绪不套统一处理流程。

“处理”要有被处理的内容：整理可见原内容重新组织，筛选可见条件与取舍，核对可见原对象与依据对应。不该改变的证据保持真实；进度条、完成勾和容器移动只承担其实际含义。

## 设计时核实增量

在真实关键状态上指出配音之外的依据；“它、再一次”等指代带上可辨上下文。暂去解释标签或换一段不同旁白，用来诊断画面是否只剩通用符号；必要命名、证据正文、类比和情绪不因此一票否决。

表达“说不清哪里不对”时，先保留搜索与笼统反馈；具体要求出现后才准确指向并改变对应部件。先框准答案或先改完再给指令都会改掉含义。未解决也可以是结果；例子不限定纸张、选框或固定构图。

## 进入动画前的最小动作依据

部件动作已合入设计时的[对象与部件过程](../planning.md#从理解目标推导画面)。实现前补齐采用配音的事件时点与代码入口，参数引用[职责曲线](../style-and-motion.md#默认动作设计基线)，精确标记按[动作模板](../../assets/templates/动作与声音标记.template.md)写局部零点、fps、F0，区分计划与实际校准；无词点不猜正式秒点。刚性部件不形变时，用同节奏的位移或倾角表达预备和受力；画面里只有正在读的字保持不动。

部件与指示动作的正反实现统一见[过程案例](../examples/04_连续MG正反过程.md)。指针按连续接近、操作、释放和离开实现，不在每个动作窗口重新显隐；无操作职责可不用。可控部件和外层轨迹不能代替实际语义后果。

部件响应计时从实际触发事件开始，标明触发、主体和附属件启动；测不到时从实际绘制共用的路径、变换和事件补测。硬要求、诊断与本段观看判据统一认[运动量化门禁](../../assets/templates/DESIGN.template.md#运动量化门禁)，不在本页复制数值。执行者核原尺寸与因果，总控核缺口和缺陷闭合；已知缺陷先修，未实际观看的整体观感写未验证。

## 默认进出场与替换

**适用边界**：D1 只约束本片设计的 MG 元素及后期叠加的包装层（标注框、放大阅读窗、章节卡、角标等）；逐句字幕按字幕规范直接显示和切换，不做进出场动画，不算 D1 违规；真实录屏、实拍、生成视频插片内部原有的显隐与切换属于素材或证据本身，不按 D1 改写，继续遵守录屏证据保真及插片不变速的现有规则；如实映射数据的计数、计时、进度百分比按数据逐帧更新，不算同节点内容硬替换。

镜头内卡片、文字、气泡、图标、连线、物件出现、消失或被替换时，必须有看得见的过程：从来源分出或复制、几何展开、遮罩／裁切揭示、路径书写／生长、沿路径进出画面、归回来源、并入接收方、形变替换，或被前景遮挡后出现。**纯透明度淡入淡出（包括只带十几像素位移的淡入），以及没有任何过程的瞬间出现或消失，默认不允许。** 同一节点 ID 内换文字／图片／版本也算替换，不能用 ID 不变绕过。

不受影响：音频渐入渐出；镜头之间按[转场规则](镜头推进与转场.md#连续画面与镜头衔接)设计的剪切（包括前后各自完整停稳后的硬切；不算镜内元素突现，但不默认用叠化）；仍留在画面上的对象降亮或褪色以退让焦点（不算消失）。开场在第一个完整画面中已经存在的对象属于建立状态，镜内后续显隐仍适用本条。

例外只能在**本期 DESIGN 中逐条列出并由用户确认**，写清对象、时段、理由、采用版本与确认范围；没有列出就按默认执行。核验首现、末现和内容替换的办法只在[确定性与连续性](../sop/04_验收与返修.md#程序化动画的确定性与连续性)维护；工具发现是疑点，不自动等于观感失败。

## 反查画面为何这样设计

“把模糊目标拆成任务”需要看见条件如何被辨明、如何形成行动；预先摆齐清楚需求再弹出任务框，只能说明结果出现。依据、过程和结果的具体载体按内容选择，不能把例子固化成卡片套路。连看时若信息提前摆完、构图与强度无理由重复，回到揭示顺序和观看任务修改。

## 建立状态链

初始状态、部件变化、交接及必要停顿沿用[画面推导](../planning.md#从理解目标推导画面)，状态图不驱动时序。接触反馈不能早于接触，受词点约束的结论不能提前；下一动作可以在前一步收势时接管，不强制逐件闭环或统一交叠。

需要回收比较对象时，可让接收载体在候选仍可辨时回接，再分批让位、归槽；实际精读对象与取景保持稳定。实现见[回接关系](../complete-motion.md#比较未结束时回接)。静态角色素材只按实际能力整体移动或倾斜，不能靠变形伪造不存在的肢体动作。

## 完整过程源码复用

**历史实现的迁移边界**：历史源码保留原样；迁移新片时，纯透明度进退或缺少过程的同节点替换按[默认进出场与替换](#默认进出场与替换)改造。已有几何、遮罩或路径过程、仍留画的降亮及附着阴影不因此重做，不把本体淡没解释为阴影豁免。

新 MG 从[共用制作起点](../../assets/motion/production-core/README.md)改内容、条件、布局和事件；实际部件、空间相机、绘制及检查共享状态。改变输入条件应改变相应部件／结果，旧版保持独立；退场随父子关系完整退出，不对子件各做碎片擦除。

历史关系按[源码索引](../examples/05_完整过程源码.md)读取完整函数，保留身份、前置依据和接收后果。先分配辨认与阅读窗口，再排主体／镜头／接收方，状态图从过程取样。来源函数、本段改法与入口仍写原剧本；无适用关系只设计缺的部分，数量、秒数与原例通过结论不成为默认。

## 给运动和画面留足时间

按[共同排时](../planning.md#从理解目标推导画面)区分主要变化完成、接管、收势及实际阅读。过程太急或拖沓先查内容与时间组织，再调曲线；距离、形变量只作参考，不固定秒数，也不改采用原声迁就效果。

[时长返工案例](../examples/04_连续MG正反过程.md)保留了只改主动作／镜头时长，以及同时改时间、曲线和部件错峰的不同修法。它们说明要按原因选择修改层，不能把所有突兀都归因于 easing 或只延长时间。

## 先验证过程，再定向精修

按[现有预演与精修](../sop/04_验收与返修.md#完整过程预演与精修)处理具体新关系或未解高返工风险，已覆盖的风险复用证据；不恢复独立前置动态测试或追加审批。首版完整片段核对主过程、内部响应、观察尺度与接棒，再精修参数和次要装饰。

实现检查用[承诺→实际画面](../production.md#剧本承诺落到实际画面)，失败按[原因层](../self-diagnosis.md#先按原因决定改哪层)返修。改变主动作、取景或接棒时同步受影响设计及版本；已成立部分保留。

## 共享对象的实现边界

**新对象先有可见来源，再进入主动作。** 在已有标注说明“来源 → 首次可见 → 可读／持有 → 退让／退场”。提取、复制须从可辨来源分出，展开须有真实几何或遮罩过程；空位整组淡入不能代替这些语义。建立状态、跨镜剪切和焦点退让按[默认进出场与替换](#默认进出场与替换)区分；镜内显隐与同节点内容替换均须有过程。

动作时段不等于存活时段；同一共享物件每帧一份最终状态，焦点转交不等于卸载，重叠动作不叠出多套完整场景。先算最终变换，再绑定线根、光标、选框及跟随相机。历史版本从独立快照求出，复合线增长不让已出现的核心退画。

对象已挂载、进度从 0 起或 bbox／opacity 变化，不证明生产像素具有正确入场。按[确定性与连续性](../sop/04_验收与返修.md#程序化动画的确定性与连续性)检查首现边界；[入场与跟随 v8](../../assets/motion/ep07-entry-follow-v8/README.md)提供有来源的复制、真实展开、路径显现及对象绑定相机的完整实现。

**前后样本保留各自内容。** 从同一动态对象提取前后样本时，在对应状态仍可见时冻结：先保留改变前状态，再从完成态取出后样本；不能让两张图都跟随当前结果变化。已有独立版本素材直接复用并核对内容，不要求重演捕获。同址分出的首帧除位置、尺寸，还核对裁切、边框、底栏和阴影，原有阴影保持连续，新增分离投影按分离过程出现；检查重复绘制是否使同址边缘突然加深。真正复制出的对象有独立身份与内容，不与“同一物件每帧一份最终状态”冲突。

**接管时安排旧载体的去处。** 新对象接过注意力后，旧载体继续参与、降为次级、退出或被遮挡，应服务当前理解任务。需要看清接收与遮挡时，不能靠两套完整场景交叉淡化掩盖层级；检查过渡中与收势后有无叠影、残片或挂在画边的旧内容。需要保留的比较对象可继续可辨，降亮退让与退场须按[默认进出场与替换](#默认进出场与替换)区分。

## 接触、遮挡与章卡

设计图使用实际素材，图标和标签成组定位。动态检查接触前、中、后帧及 1× 播放，注意遮挡、文字重叠和转场露底。折叠、展开或形变还须核对输出尺寸下的中间态轮廓与印字，不能用终态完整掩盖碎字。

章节转场需等末句与结论画面都完成，再按本期记录停稳、进章卡和接下段。前段尾部与后段头部由谁负责，在任务书中明确，避免双方重复制作或无人补缝。

**交付看实际片的语义与表现力。** 按删字、静音、合看三项检查，并在实际预览尺度以 1× 对照选定范例的具体区间：主对象变化是否可感知、观察顺序与所需尺度反差是否成立、动作与停顿是否有主次。再连看受影响段落及相邻镜头，检查焦点是否接得住、构图和动作组织是否无理由重复。比较可辨不等于全场固定；连看减速、全停与下一动作缓入，局部提前不能把空等推到尾部。具体判定按[验收与返修](../sop/04_验收与返修.md#完整过程预演与精修)，保留必要阅读、情绪与真实依赖，不用非零微动充数。

未达所选目标时，先调整对象过程、取景与时间分配，再复查受影响片段，写入原 QA。技术无缺陷、事件／关键帧数量、运动占比或曲线合规不能代替判断。不要求所有镜头大幅运动或形变；空间采用与不用统一按[空间选择边界](镜头推进与转场.md#空间镜头)判断；证据画面不得伪造变化，也不借此改原声或用户锁定范围。检查须覆盖实际编码文件。

**反例：数量与曲线合规仍可能失效。** 一次开场独立测试有 14 张设计图、11 次镜头移动，其中 V3 主体内容连续约 14.79 秒不变，观看主要在同一图上转移，仍被指出增量、景别与动态不足。应检查这段时间是否真的有新的观察任务、因果发展或必要停顿，不能由图数、运镜数、非线性函数和技术通过放行。这些数值只描述该次失败，不是通用阈值。

不能 1× 观看的 Agent，在样片或整段交给用户前先跑 [动态自检](../motion-check-method.md)：看整段总览、静止区间和关键动作密集帧，逐段判断长时间不变的用途，修掉过程一闪而过、空白画面等已发现问题。自检只定位，不判通过。交审前另跑 [运动量化门禁](../motion-check-method.md#运动量化门禁)；用途说明不能抵消静止硬门禁或已知缺陷；速度、预备与占幅的诊断取舍认本段观看任务，缺测和未完成的 1× 分别记未验证。

## 复杂状态与短停顿

线路、节点名称和连接关系必须来自定稿或已确认依据。停顿很短时先建立整体结构，再推进关键路径；两条对照路线可以同步推进，不必让所有节点逐个弹出耗尽窗口。

需要关键词触发的结论不能为塞下动画提前揭示。动作预算至少容纳建立、主变化、结果确认与适用的阅读；不够时删减非关键动画或调整方案，不改已确认配音来迁就效果。

生成插片先建立语义前提，回到 MG 时明确承接对象；按实际采用片标记动作与原声，不用提示词计划代替。插片中段也核对实际播放：已确认按原速使用的窗口须保持原速；动态自检在窗口内报静止时，先检查主工程实际调用的源文件、入点与时间映射，不能只因首尾帧正确就放行。一次返工曾误用两张静图代替插片，首尾帧相符而中段没有播放；检测结果须回到实际采用文件核实，不能靠装饰微动消除告警。已明确采用定格或变速时按对应决定检查，不把本例扩成全片禁用变速。章节卡必须等末句和结论都完成后再进入，转场中间帧也检查覆盖。
