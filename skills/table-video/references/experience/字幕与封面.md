# 字幕与封面

## 字幕

文字来自确认定稿，时间来自实际采用配音。识别字幕是定位材料，专有名词、数字、断句和停顿仍需校对；稿件与实际说法不一致时先核对采用决定。出字幕时列出全部英文词（产品名、工具名、术语），按官方写法逐个核对大小写；用户另有指定的写法按用户决定。

正式旁白字幕在后期统一添加；设计阶段标出字幕安全区，辅助线不导出。按成片屏幕坐标核对关键内容，包含缩放、运镜后的最终位置和经过位置，不只看源坐标或停稳终态。

分段整段预览交审前，叠本段已有字幕核一次；可在播放器或编辑器中临时叠加，不必为此重渲画面。保留可编辑字幕文件，检查进入、退出、行长、尺寸和停留；以正常播放与目标观看尺寸确认字幕不挡操作、人物、图表或必要原文。

素材中已有烧录旁白字幕时，先明确采用何种处理，避免后期再叠一层；保留必要界面文字。不能用拉伸和随意裁切解决字幕遮挡。

声音、字幕与最终技术检查合并到统一 QA。只修改断句时检查相关区间及接点，不重跑整期视觉设计。

## 封面

先确认成片真实主题、目标发布位置和本次所需规格。画风参考与构图参考分别说明职责，有角色时再增加身份参考，无角色不强加 IP。

Agent 提供构图方案、短标题、完整生成提示词和后期文字安排。需要多个画幅时按各自视觉重心设计，不把同一张图机械裁切。平台尺寸和规则在制作时查当前官方来源，不预置所有平台一套长期有效数字。

用户确认方向后手动生成，Agent 检查主题是否准确、文字是否可读、角色和风格是否一致，并完成获准的后期。封面不能展示成片没有证明的效果。

## 发布材料

标题、简介、封面文字与视频内容保持一致。素材署名按实际授权要求写入简介，链接指向实际存在的公开页面；尚未发布的项目不写“已经开源”。

在标题、封面、字幕、简介齐备后完成一次整体检查，再由用户决定是否发布。输出发布材料不自动授权上传或发送。
