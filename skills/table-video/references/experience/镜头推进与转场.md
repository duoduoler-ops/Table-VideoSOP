# 镜头推进与转场

本页维护镜头选择、观看推进与衔接方法。视觉风格认项目 DESIGN，内容、采用版本与时间认本期依据；示例不构成制作授权。

## 段落吸引力与镜头推进

进入画面方案、分镜或节奏返工时，在确定设计图前同时判断主体动作和镜头观察方式。结果写入已有大段表或运动标注：

1. **配音与情绪**：结合完整语义、实际重音、停顿与语气，明确观众先看哪里、随后发现什么、最后停在哪里。配音未定时可拟候选画面与镜头；正式配音确定后复核选择，再定节奏与秒点。
2. **场景条件**：检查前后景、遮挡、可跟随对象、局部与整体及区域关系；信息层级或房间、桌面、街景等物理纵深均触发[空间适配判断](#空间镜头)。先决定哪些关系要逐步揭示、哪里需要尺度或主次反差，再共同设计镜头、对象布局和素材；不先固定完整正面版式，再补整图缩放。
3. **镜头选择**：按下方情境规划观看顺序，再从镜头方式表选择可实现的做法。关键段落或连续构图重复时，比较可行的运动与固定安排，记录采用方式、作用和取舍，不逐镜列备选。
4. **节奏与落点**：共同安排主体动作、观察路径、焦点交接和必要停顿，避免每次都“入场—停住—换一页”。运镜可在重音前启动，让关键揭示落在语义节点；需要词点触发的结论不得提前。中间节点可连续经过，有阅读、比较或情绪等表达需要时再停稳，不默认每个节点刹停。

### 情境与候选镜头

以下情境用于启动设计判断，不直接指定运镜，也不按单个词匹配；候选动作可单独使用或分阶段组合。未列出的情境仍按配音、场景和观看顺序判断。

| 具体情境 | 优先考虑的镜头安排 | 保留信息与边界 |
| --- | --- | --- |
| 多个差异需要依次比较，配音逐项讲解 | 先建立两方身份，再横移、重构图或推近当前比较项，最后回到整体结果。 | 当前对应项尽量同屏，读数时停稳。只有一个已清楚突出的差异时，可以固定。 |
| 对象跨区域移动、传递或交接，过程与去向是重点 | 跟随对象移动；交接处调整构图保留双方，再把视线交给接收方或新区域。 | 接触、接稳、释放与去向须可见；交接未清楚前，不只追随其中一方。 |
| 反复行动却没有进展，随后发现问题或突破循环 | 可先跟随行动，再拉开或改变观察角度揭示闭环；突破后沿新路径推进。 | 保留辨认“回到同一位置”的参照。配音从一开始就在解释完整结构时，不必故意隐藏全貌。 |
| 从局部认识整体，或从表象发现原因 | 拉开、升降、侧移绕开遮挡，或在有深度条件时转移焦点，按顺序揭示关系。 | 揭示终点须有具体内容；素材不支持时换可实现的方式，不强造环绕或穿行。 |
| 层级、依赖或跨层传递需要被看懂 | 考虑升降、斜向取景、穿行或分层重构图，让上下游与深度关系成为可见空间。 | 信息结构或物理纵深均须按[空间镜头](#空间镜头)写一行适配判断；采用与不用认该节统一边界。 |
| 配音出现明显强调、犹豫、压迫或释然 | 考虑靠近或远离主体、改变观察角度、调整速度或有意停住，配合情绪转折。 | 结合语气与前后镜头判断，不把情绪词绑定一种技法，也不把每个重音都做成推近。 |

### 选择边界

- **稳定按对象与时段安排。** 比较、接触与结果阅读要清楚；在已有标注中区分经过状态与停留状态，共同排下一动作启动、注意力接管与前一动作收势。比较对象仍可辨时，接收方可先回接、相关对象分批让位；不默认所有对象停稳后再继续，也不因提前而抢走必要阅读。
- **风格不锁死构图。** 延续配色、材质、字体和窗口语言，同时按观看任务安排局部、整体和主次关系。对照起终画面中主体的实际大小、可见内容和观察任务，不只比较相机数值。近读须读清所需细节，拉开须揭示关系；换标签、移动选框或轻缩放同一全景不能替代这些变化，有目的的复看与情绪强调仍可保留。
- **固定须符合段落任务。** 持续观察同一关系、等待反应或保留全貌本身就是表达重点时，可以整段固定。“有文字”“有比较”“主体已在动”不能单独决定固定。
- **运动须有对象与落点。** 说清跟谁、揭示哪里、何时停下或交接视线；节奏与情绪作用也算理由，不要求每次新增信息。
- **不凑运动数量。** 当前关注点尚需稳定观察、运动会漏掉必要证据，或只是无目的的来回缩放时，保持稳定。

同一场景采用统一相机，只证明变换一致：共享对象的来向、去向、承接位置和必要环境参照仍须可追踪。相机按观察任务建立独立时段，不按每张状态图重新缓入缓出；其收势可跨过对象状态节点，必要近读仍停稳。按[屏幕审计](../motion-check-method.md#过程复用与屏幕运动审计)核对实际主体边界、尺度与经过节点速度，再对照编码帧；整图同移同缩本身不证明空间连续性，空间采用与不用统一按[空间选择边界](#空间镜头)判断。

素材须支持所选方式：绕行需要可展示的侧面与空间，转焦需要可区分的深度层，穿行需要沿途内容和画外余量。条件不足时写明补充素材或替代方案及表达损失，不把整图缩放冒充需要视差的穿行或绕行，也不自行扩大制作或生成授权。

制作前补齐所选运动的时间与参数；方案阶段不必填工程数值。复杂段落展开关键状态与衔接，普通段落一两句即可，不新增评分表、技法配额或逐镜审批。

普通视觉位移、缩放、相机运动和内容过渡采用可感知的非匀速，不做全程恒速或仅两端缓动、中段恒速巡航。真实进度、计数或时间轴按其数据关系允许线性；这不扩展为装饰性移动的豁免。中间节点不默认速度归零，跨镜速度按一次完整动作承接；数学上非线性也不自动合格，须看主体与相机合成后的屏幕速度及整段主次节奏。

主动作时长不等于整句配音时长；共同排主变化、下一动作启动与接管、前一动作收势及必要阅读，不靠慢移或长减速尾段填满配音。需要读字时稳定被读对象与相关取景，不默认全画面冻结；需要持续观察变化时按其复杂度留时。曲线按动作职责和实际屏幕效果选择，不默认所有镜头使用同一条平缓曲线。

**接收按最终阅读构图落定。** 需要稳定阅读的接收，共同安排对象落点与相机收势；落位后再次补镜须带来新的观察、揭示或交接作用，只为“再动一下”的小补位应去掉。连续跟拍和有目的的取景变化仍可使用，不能把本条解释为每次接触都必须全场停稳。

### 对象绑定的跟随与拉开

返修速度时保留已成立的主体绑定与来源关系，先调整对应时间和屏幕锚点；不能为换曲线把跟拍退回独立插值。改变末段观察任务时，按用户本轮要求更新局部依据，不把旧方案的遵守误判为实现缺陷。

**跟拍先求主体最终变换，再由屏幕锚点反算相机。** 锚点服务当前取景，可固定或连续调整；不能让主体、相机各走互不关联的长缓动，再靠试数值追赶。二维投影可用“相机位置＝主体世界锚点－（目标屏幕锚点－画布中心）／缩放”，旋转／透视按相应变换求解；检查合成后的主体、来源与接收方是否可辨。

有意跟拍可固定主体的屏幕位置，须结合其世界位移、来源／接收方的相对运动和取景任务判断；单对象屏幕零速不能推断整场停顿，也不能仅填“跟随”标签豁免，未核实的疑点仍保留。

需要从跟随传递转向整体关系时，可在主体接近落位时接入拉全景，保留接触和去向，比较时再稳定；不默认先全停再重启，也不要求所有末段拉全景。被指出拖慢时，对照实际主体屏幕轨迹、主要位移完成时段及长尾，先重排时间再调曲线，不以函数名或统一秒数放行。必要近读和词点约束保持。

可运行正反证据见[入场与跟随 v8](../../assets/motion/ep07-entry-follow-v8/README.md)；其中主体、锚点与相机共用最终位置，收尾由近跟转整体比较。只迁移机制，不复制该例坐标、时长或确认结论。

## 空间镜头

### 触发与选择边界

设计阶段主动判断一次：内容有层级、引用、依赖、跨层传递或局部到整体关系，**或场景本身有可辨前景—主体—背景、遮挡或物理纵深（房间、桌面、街景、堆叠物件等）**时，在已有镜头剧本或运动标注写一行：**空间适配：候选／采用／不用＋观看收益、阅读或比较代价、素材条件**。适合且有可复用做法时优先采用，不用时写本段具体理由；不得以“用户没提”或“素材是平面”跳过判断。

本节是空间选择边界的唯一说明：允许 2.5D 分层、视差、透视平面，不自动升级真实三维，也不强制三维或常驻运镜。需正面同尺度比较、证据保真或稳定近读时可固定；建立、归档与交接可另用轻空间推进。素材不支持侧面、遮挡后区域或视角时，记录可实现的替代及表达损失，不把整图倾斜／缩放当成已经完成空间设计，不自动扩大制作或生成授权。

### 已验证做法与呈现

图层爆炸是原系列已获局部认可的做法，可按关系迁移：把分层信息做成平行叠放的板，共用一套透视；每层带着标题按几何或遮罩过程落入本层，投影随高度由虚变实，层内内容按因果依次揭示；跨层路径表达依赖或交付，底层保留真实内容作为远近参照。焦点离开的层可降亮但仍可辨，不能用纯透明度进出代替[动作过程](视觉叙事与连续MG.md#默认进出场与替换)。

板有可辨厚度与侧色，同一光向，投影的距离／软硬随层高变化；当前焦点层清楚、背景层退让，文字按实际屏幕尺度可读。优先克制透视或长焦式关系，避免夸张角度把板与字压成窄条。层内卡片和文字仍可用平面组件，图层关系、光影和遮挡共同建立纵深。该历史工程仍只作来源；包内共用空间实现已单独提炼，新内容的实际效果须重验。

**空间路径。** 有层级、遮挡或跨区关系时优先选带真实 Z 变化的弧线推进／绕行；起止构图和沿途发现先定，Z 用于靠近细节、绕开遮挡或拉出全貌，不作周期起伏。世界 XYZ、观察目标和焦距分别求值；整图 scale 不称为纵深运镜。文字近读和同尺度比较保留稳定正面窗口。

**共同排时。** 先分配依据出现、部件处理、接触、结果可辨与阅读窗口，再把主体、相机和接收方放进去。空间路径描述走哪里，时间映射描述何时走到；经过点不自动停，语义落点及时稳定。跟随由主体最终状态和固定屏幕锚点反算，接近接收处再连续交给整体取景；起点、终点和必要环境参照保持可追踪。

**速度分配。** 在最终投影中看多点轨迹、前段路程集中、峰值单帧跳距、主要路程完成时刻和低速尾段。屏幕弧长重排仅校正透视造成的路程失衡，仍叠加有主次的时间曲线，不制造匀速巡航。读不清先减动作／改预算，不把整段拉慢或统一套快速到位曲线；不从历史秒数推出新通用限速。

**实际核验。** 先查同源状态和最终编码像素，再按 1× 连续观看判断速度、注意力和节奏；投影坐标、密集帧和工具通过不能替代观看。复杂透视、裁切或遮挡未被实际证明时留未验证。已知缺陷先返修，采用与检查仍记原剧本／QA，不增表和审批。

实现使用[共用制作起点](../../assets/motion/production-core/README.md)。图层爆炸是历史局部认可；新片的参数与效果不继承该确认。

## 镜头方式：按表达目的选择

下表提供候选用途，不是情绪与技法的一对一规则。相机位移／转向、变焦／对焦、观察视角分别描述；物体旋转不等于相机环绕，二维平移／旋转只能近似相应观感，不能生成不存在的侧面或透视。

| 方式 | 可考虑的表达任务 | 实施与检查 |
| --- | --- | --- |
| 推／拉镜 Dolly In / Out | 进入细节、拉开揭示环境或改变与主体的距离感 | 锁起止构图和沿途信息；空间视差需分层或三维条件。整图缩放（整个画面连同窗口框一起缩放）是推拉的二维近似，核对清晰度、裁切和阅读；框不动、只放大框内内容是界面缩放，不是镜头推拉。 |
| 横移／升降 Truck / Pedestal | 沿结构发现新区域，跟随横向或竖向行动 | 相机平移，观察方向可保持；核对屏幕实际位移、遮挡和画外余量，不与摇镜混写。 |
| 横摇／俯仰 Pan / Tilt | 从一个关注点转向另一处，沿视线揭示对象 | 改变观察方向；起落点可识别，途中不扫过无关空白。上下移动整图不当作真实俯仰。 |
| 弧线绕行／环绕 Arc / Orbit | 绕开遮挡，揭示不同侧面或对象与环境的联系 | 明确绕到哪里后多看见什么；需要支持视角变化的场景，不默认转满一圈。 |
| 摇臂式升降 Crane / Jib | 从局部动作展开规模、俯视结构或由整体进入局部 | 可配合俯仰与横向运动；高度和观察角度一起设计，关键关系建立后再离开。 |
| 跟随／主观穿行 Tracking / POV | 经历传递、进入、受阻和抵达，增强过程感 | 跟随是运动，POV 是观察视角；明确视线跟谁、途中揭示和终点。保留证明起点、接触与结果的环境，核对主体与相机合成后的屏幕位移。 |
| 视差 Parallax | 通过前中后景的相对位移建立空间层次 | 保持深度和遮挡关系，补足被遮挡区域；同一刚性对象不随机拆层。可配合绕行或穿行。 |
| 变焦／快速变焦 Zoom / Crash Zoom | 改变画面尺度；短促强调、反应或笑点 | 变焦改变焦距与视角范围，不靠相机位移；快速强调后需有明确落点。二维缩放可模拟尺度变化，不能替代真实透视变化。 |
| 焦点转移 Rack Focus | 从表面结果转向原因、从行动转向反应 | 属于对焦变化；选定前后对象及交接时机，需要深度层。二维模糊遮罩可作近似，必要证据阅读时保持清晰。 |
| 轴向滚转 Roll | 表现秩序失衡、冲击或恢复 | 绕镜头轴改变画面倾斜，区别于环绕主体；明确原因、幅度与收束，检查中途覆盖和辨认。 |
| 滑动变焦 Dolly Zoom | 表现重要的心理转折、压力变化或突然意识到问题 | 相机移动与反向变焦配合，主体大小相对稳定、背景透视变化；需纵深与背景参照，普通整图缩放不能替代。 |
| 手持感／冲击抖动 Handheld / Shake | 对具体行动、冲击或紧张作出反应 | 有触发与收束，幅度服从主焦点和可读性；不作为持续填空手段。 |

组合运动围绕同一目的组织，例如绕行揭示后转焦，或跟随受阻后升高看清整体。明确主导变化和交接时机，不叠加互相争抢焦点的旋转、缩放与抖动。

## 镜头时间与屏幕运动校准

先锁一次完整观看过程的起点、沿途内容、落点和停稳用途，再分配建立、主变化、交接与阅读时间。变化距离、尺度、同时参与的对象和相邻动作一起考虑；觉得突然先查总时间是否够，觉得拖先查是否真的还有过程。曲线负责过程内的时间分布，不能补救总预算和运动目的缺失。

检查实际取景中可辨认的主体与场景参照点，不只检查 camera key 数值。用起点、中段、落点及疑似刹停两侧的屏幕位置和尺寸，观察位移／尺度随时间怎样变化；相机与物体运动可能抵消，平移与缩放也可能在一个锚点抵消，因此按疑点查看多个参照点。必要时记录 px/s 或尺寸变化率来定位，不规定跨画幅通用的舒适速度。对推近或拉开，还要比较主体在成片起止画面中的实际尺寸及新揭示的内容；对象自身缩放与相机运动合成后，实际放大可能远小于单个参数所示。只是移动旧构图，或在近景重复早已读完的全貌，不自动算作新的观察任务。微漂移若没有带来所承诺的取景、揭示或情绪变化，就不能充当完成运镜的证据。

同方向、同一观看任务的中间关键点，不默认速度归零；阅读、接触、转向或明确节奏断点才按目的安排停稳。先看整条轨迹的连续性，再按动作职责选择非匀速曲线；普通视觉位移与缩放不得全程恒速或中段恒速巡航，真实进度／计数的线性映射另按数据含义处理。数学非线性本身不证明速度反差与节奏成立。将实际风险窗口与基线片的可比完整运动连看，比较尺度、速度分布和停稳用途，按本片距离与复杂度重新定时。

## 连续画面与镜头衔接

| 方式 | 用途与检查 |
| --- | --- |
| 共享元素连续演化 | 同一逻辑保留对象，让它移动、改变层级、连接或状态；中途身份可追踪，不先清场再造近似物体。属于对象编排，不代替镜头选择。 |
| 图形匹配 Graphic Match | 用形状、位置、尺寸或构图承接两画面；先锁视觉锚点，正常速度检查焦点跳位，不伪造真实截图文字。 |
| 动作匹配 Match on Action | 同一动作跨视角继续完成；剪点承接动作阶段与方向，检查重复、跳步及接触或结果被剪没。 |
| 遮挡过镜 | 有场景依据的前景物覆盖剪点，后镜沿匹配方向揭示；核对覆盖、速度、边缘与落点。 |
| 声音桥接 J / L Cut | 下一场声音先入或上一场声音延续，帮助空间与情绪衔接；保持已锁配音顺序和时间，不提前暗示未发生的事实。 |

甩镜可用于同场重构图，也可用于跨镜衔接；同场无需虚构剪点，跨镜按下节匹配。共享元素、焦点转移和速度变化不都属于转场，不能用“加了转场”代替段内观看设计。

## 运动匹配剪辑：共同要求只维护一次

Motion Match 指不同镜头以相近的屏幕运动承接，可以是不同对象；Match on Action 还要求同一动作的连续性。以下用于平移、甩镜、旋转和缩放衔接：

1. **先配成一对。** 确定两镜为何相接、视线跟谁、切后落到哪里。生成或录制前就准备前镜尾部和后镜头部的运动余量；已有素材按实际可用动作找剪点。
2. **匹配屏幕状态。** 看实际主体的位置、大小、方向、轨迹和动作阶段，不只比相机参数。切点两侧速度尽量连续；故意反向或跳变时明确表达目的，不冒充顺滑匹配。
3. **按一次完整运动安排速度。** 前镜进入动作，后镜承接后再减速落稳；切点处不自动停下，也不让后镜从零重新启动。Ease In / Out 要核对实际速度变化，不能仅凭曲线名称判断。
4. **剪点服从动作。** 在运动容易接续、遮挡充分或构图匹配的位置切；速度峰值附近是候选，不是所有匹配剪辑的必选点。先看清锚点，切后保留必要阅读时间。
5. **模糊与覆盖共同检查。** 高速段按运动方向安排模糊，两侧强度衔接；先修跳位，再决定模糊量。变换与模糊后仍要覆盖画布，不能套用旧片固定放大倍率，也不能用光流补帧掩盖切点问题。

制作时在已有运动标注中记录这对镜头实际需要的起止构图、切点、承接状态与停稳时间。坐标注明画布／内容区基准，位置用 px 或归一化坐标、缩放用倍率、角度用 °；比较速度时用 px/s、°/s 或缩放倍率/s。镜头局部秒点、工程帧换算、音效单点与持续区间统一按 [动作与声音标记](../../assets/templates/动作与声音标记.template.md)，不另建合同文档。没有旋转就不填角速度，没有声音就不虚构音效。

| 类型 | 在共同要求上补充的做法 | 失败时先查 |
| --- | --- | --- |
| 平移匹配 Slide / Push | 两镜主体以相近屏幕速度沿同一方向衔接，接住位置后减速；整画面推移时让前后画面共同覆盖画布。 | 方向是否写成相机方向、两镜是否独立缓入缓出、接缝是否露底。 |
| 甩镜 Whip | 先建立可识别画面，快速甩向目标方向，在运动／模糊适宜处切；后镜从相近运动状态继续，随后落稳。二维实现可用平移近似甩镜观感。 | 模糊方向和速度是否突变、后镜是否先静止一帧、落稳目标是否过早或过晚可读。 |
| 旋转匹配 Spin / Rotation Match | 先决定是画面滚转还是物体旋转；锁转轴、方向、切点角度与锚点，再对齐角速度，后镜延续并减速到明确构图。 | 同方向仍跳动时检查转轴、切点姿态和主体大小；离轴距离不同会改变屏幕扫动速度。检查旋转中间帧四角覆盖。 |
| 缩放匹配 Zoom Match | 围绕同一视线落点缩放；两镜在切点对齐锚点位置、大小和变化速度，后镜继续放大／缩小后落稳。 | 缩放中心是否跳位、素材放大是否变糊、前镜“向里”而后镜突然“向外”；二维缩放不当作真实穿越空间。 |

前后各自完整停稳后硬切，也可以是有意的节奏断点；应按正常剪切设计，不必伪装成运动匹配。素材不具备连续性时，优先重选入出点、重新安排运动或改用图形匹配／干净切换，不无限增加模糊和效果。

## 最小检查与迭代

- **对照设计判断**：逐项核对已有剧本承诺的主变化、观察起终点和阅读尺度，定位实现与实际帧／时段，再判断重点引导、关系表达、节奏和情绪。整图推近须包含属于场景的窗口框；仅框内内容放大按界面操作判断。不能只因固定画面可读或画面持续运动就判通过，读取记录与技法名称也不能代替结果。
- **正常速度连看**当前段落及相邻镜头：视线能否接住、景别与构图是否无理由重复、主变化是否推进内容、重点能否读清。静态图确认不等于运动效果确认。
- **检查实际编码帧**：抽查起止、切点两侧及明显变换中间帧，排查动作重复／跳步、焦点跳位、露底、错误裁切、文字遮挡和模糊突变。
- **合看与审听**：核对实际配音的重音、停顿、语气与揭示节奏；声音按实际可闻事件对点，阅读与情绪留白不被无关尾音填满。无法完成的项目如实记未验证。
- **改动后重校准**：裁切、变速或调整起点后，以实际采用画面更新动作／音效标记，复查受影响区间和接点；全片时基变化时扩大复查范围。

结果写入已有 QA，记录采用版本、实际时段、可见症状、修正和审看片范围。先区分方案、时间组织、参数和工程问题，按[验收与返修](../sop/04_验收与返修.md#返修只重查受影响内容)定向迭代，不用同一平淡方案的多套参数冒充不同设计。通用问题修订本页，单期构图与参数留在本期。沿用现行授权、风险样片和最终验收，不因选用新技法另加审批或自动重做已锁定段落。
