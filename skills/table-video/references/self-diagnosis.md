# 以实际输出反查方案

这是制作判断方法，沿用当前方案、审片记录和唯一 QA，不增加评分表、阶段或用户审批。新建／实质改变画面方案、样片扩到正式制作、整段候选交审时执行；只改字、局部遮挡或剪点时只查受影响对象与接点。已读未变不重复加载。

## 制作前先定义怎样会失败

从原始请求、采用配音和指定对标推导可反驳的观看目标，写在已有方案中：观众凭什么看出本段关系，哪些依据尚未出现时不能先得到答案；表现要求则对应实际引导、揭示、反应或节奏差。最低语义成立不等于全部效果达标，也不无依据强加角色、运镜或动作数量。具体设计顺序见[画面推导](planning.md#从理解目标推导画面)。

指出最容易误当成功的替代解释，如只有载体送达、附件轻摆，主部件却未产生所承诺的后果；或标签声称不确定，精确指向却已泄露答案。阅读、比较和情绪按本身任务判断，不一律要求处理或冲突。

用户指定既有项目经验时，定向读取可比的完整采用片段及相关返工：失败现象、当时采取的修法、实际采用结果。分别提取适用机制与不可照搬的题材、镜头、秒数；不能只摘“已通过”的参数。没有真实返工材料则说明，不推测作者做过什么。包内[正反过程案例](examples/04_连续MG正反过程.md)保留失败画面、修法和检查点，供默认执行使用；它不代替用户指定的成片目标。经验继承要能在下一次设计和实现检查中避开同类失败，不能只记“增加动效／多轮打磨”。

## 看结果时先暂时放下作者解释

先看实际输出和必要上下文，再读本版实现说明、通过总结与技术统计。参考仍保留原始请求、采用配音和对标，避免审查者不知道应判断什么。已经看过作者解释时如实说明，不能自称盲审。

1. **复述眼前发生了什么。** 用“哪个对象、何时、从什么变成什么”描述，不沿用作者的“拆解／智能／连续／吸引力”等结论词。对照制作前目标，找最有可能推翻方案的一处证据；未发现反例不自动等于达标；通过还须有实际正面证据覆盖原始观看目标及适用效果要求。覆盖充分且没有反例时可通过相应范围，不必为了挑错编问题；证据不足则保留未验证。
2. **检查真正承担含义的对象。** 定位必须看清的条件、关系、关键状态或反馈，检查它在成片取景中的大小、遮挡、持续时间和注意力竞争。全画面持续移动，不能证明那个关键对象被看见；跟随参数存在，也不能证明停因和延迟可辨。抽帧只能证实其覆盖的问题，不能替代正常速度阅读与运动感知。
3. **比较相邻变化的时间。** 从实际输出记录建立、主要变化、让位／过渡、反馈、阅读占用了多少窗口；比较它们承担的内容与变化复杂度。前面长时间摆放少量信息、后面关键处理挤成零头时，即使无长静止也先重排预算。读字停稳和有依据的节奏反差应保留；长时间几乎不动以 `scripts/stillness.mjs` 为准，不能靠写用途抵消。
4. **对照可比的完整过程。** 在实际预览尺度以 1× 对照设计时选定的范例版本与片段区间，比较参考怎样让依据出现、怎样集中视线、怎样给变化和结果留时间，再检查本版做到哪一步。再连看受影响段落及相邻镜头，检查主动作与注意力是否接得住、构图与动作组织是否无理由重复。不能用局部传递样片、片段最热闹的帧或主观形容词代表全段；不要求复刻参考外观、AI 插片或当前素材做不到的角色内部动作。

最重要的诊断沿用原 QA 关联：未登记的本版报告可以汇总；已登记报告保持原文，新增诊断或局部复查另存冻结补充证据，并引用原检查 ID。记录内容为：**实际时段与对象 → 观察结果及可能的另一种解释 → 对理解目标的影响 → 返修层与验证办法**。区分语义错误、效果力度不足和证据不足；不能将“可以更好”无限扩大为必须返工。

按方案、时间组织、参数或工程确定返修层，每轮优先处理 1–2 个主要问题，明显硬缺陷及时修，不限定总轮数。完整过程成立前不先精修装饰；若参数变体都存在同一个因果或观看问题，返回共同方案，不让“三档都做了”成为通过依据。

## 先按原因决定改哪层

| 观察到的问题 | 先改什么；怎样证明改对 |
| --- | --- |
| 依据缺失、结果提前或动作改错部件 | 改可见关系、揭示顺序或内容；若方案正确而实际状态未接入，修对应部件驱动，再对照触发前、过程中与结果 |
| 关系存在，但关键对象太小、被遮挡、焦点抢夺 | 改景别、布局、出现次序或停稳；核对关键对象实际可见过程，不能只给全局差分统计 |
| 主变化／过渡比简单摆放更急，过程读不清 | 重分配完整动作与相机窗口；检查调整后相邻变化和接棒，再校准曲线 |
| 关系、阅读与预算成立，但观看组织仍明显弱于指定基线 | 找出限制表现的揭示次序、观察范围或接力方式，改变对应观看过程；用同一目标、同一基线和完整风险窗口复验，不把“更热闹”当改善 |
| 过程与预算成立，仅重量、跟随、停稳需要调整 | 依据实际片段反馈直接调参；用户主动要求比较或确需解决具体风险时才做对比，固定的剧情与构图不因此获通过 |

遇到“讲得懂但表现仍不足”，保留成立的内容、因果和阅读，找出限制效果的观察范围、揭示或接力方式，再在本轮输入与素材边界内改对应过程；只差手感就调参数。按原范围复查新旧完整过程及同一基线，不能靠换方案文字宣布改善，也不强凑多套方案。

一份样片必须能使“本轮主要风险不存在”这个判断被证实或推翻。参数样片覆盖了主要过程的时间区间，不等于检验了共同固定的表达方案。剩余风险在原方案／任务书中关联其实际受影响对象；只有 pilot 自己被标风险，不能使正式工程被当成天然无风险。已有适用证据直接复用，不机械增加三档或审批。

## 不把局部修复升格为整项通过

整项 visual-design／motion 通过前核对实际对象、时段和要求。数值门禁只证明已覆盖约束，部件作用、局部可读性和 1× 观感仍看实际输出；已证实缺失记未通过，未覆盖记未验证，沿用[现有 QA](state-contract.md#mg-效果证据)。

准备扩大制作时，若主要未解决风险是观众能否理解或表现能否达到指定基线，且当前具备独立审查能力，就先做独立观察。反复被用户否决或同一作者修了多轮仍认为通过时，也按此方法复查：交原始请求、实际候选、适用基准和必要素材边界，让审查者先找证据；首轮不提供作者自评或预设缺陷清单。先收独立观察再对读，保留分歧并按真实证据裁决，不按代理人数投票。能力不足就由作者按上述顺序自查并注明限制，不因此新增外部服务或阻塞其他获准工作。

用户否决后保留原话，回到对应原因层；未明确的细项不能全盘猜成失败。技术有效结论保留。效果仍未通过时，只能交用于定位的失败候选与诊断，不能宣称修复已解决或继续把同一失败方案扩大生产。
