# S09—S10 审查、返修与交付

先读[验收方法](sop/04_验收与返修.md)。状态与 QA 操作按[状态契约](state-contract.md)，不通过手改生成表宣布完成。

画面审查前确认已读[镜头推进](experience/镜头推进与转场.md)，涉及 MG 时同时确认已读[连续 MG](experience/视觉叙事与连续MG.md)，并定位本项目 DESIGN 的[效果基线与适用范围](style-and-motion.md#效果基线与适用范围)；同一任务已读且未变直接复用。检查实际效果，不只检查文档齐全、流程允许或技术参数。

## 画面和最终文件分别确认

先执行[输出优先的自我诊断](self-diagnosis.md)：从原始理解目标找实际反例，检查承载语义的对象和相邻时间分配，再核对作者计划。反复返工仍失败时按该页做独立观察，不先把作者通过总结提供给审查者。诊断沿用已有 QA 关联；已登记证据保持原文，新增诊断另存冻结补充记录，不增加审批或第二套 QA。

交审使用[审查卡](../assets/templates/review-card.template.md)：默认先展示本轮要判断的具体问题，每项带完整配音原文、当前词点、实际图或连续片区间；已确认且未受影响的内容和技术明细折叠；动态审查保留完整连续播放，静态只展示所覆盖状态。重点导航不能替代全片连续审看，已知未解决问题不能藏在折叠区。

审查同时回答三件事，分别记录证据范围：

| 判断 | 看什么；失败后改哪层 |
| --- | --- |
| 配音语义是否成为可读画面 | 按[画面推导](planning.md#从理解目标推导画面)对照实际起、中、终过程，检查上下文、判断依据、内部变化及前后输入。删字、静音、合看用于定位；必要命名和证据正文保留。只有标签、外层移动或完成符号却缺核心关系时，退回对象过程与设计。 |
| 承诺是否实际实现 | 按[承诺核对](production.md#剧本承诺落到实际画面)定位对象、函数、时段和编码帧。承诺展开须见内部展开，承诺近读须让目标达到可读尺度；缺失实现先修，不能用配置名或轨迹通过替代。首末现、替换及跟拍边界按[专项实查](complete-motion.md#入场与跟拍实查)核生产像素，采样与像素不一致先撤回对应结论。 |
| 完整过程是否达到效果基线 | 按[三项实查](complete-motion.md#三项实查)在实际尺度以 1× 对照适用完整范例，再连看相邻段，判断主动作、观看推进、阅读及接棒。局部参数样片只能支持其覆盖的风险；信息过早摆完、复杂处理被挤短或反复全停，按实际原因返修。 |

[动态检查](motion-check-method.md)输出近静止疑点、工程采样和项目数值约束。静止硬门禁或已知视觉缺陷须修，不能改记未验证；镜头速度、预备和占幅只作诊断，不能凭数值判观感通过。检查关键对象实际可见范围与内部状态，不能用全画面 bbox、跟随数量或辅助物持续运动代表它。近静止累计或反复短停按适用完整过程复看，不拉长旧动作或加漂浮消除统计。

必要阅读、比较、情绪停顿及固定镜头保留；空间判断按[统一边界](experience/镜头推进与转场.md#空间镜头)，不强制形变或常动。无法 1× 连看时写明未验证范围；已由帧、区间或工程证实的缺陷仍记未通过并先修。用户“默认同意／第一方案／由你决定”只授权对应选择，不降低要求，也不代表已观看认可。

用户明确否决某版效果时，将该版被否决的效果范围记为未通过，保留原话并定位受影响方案；尚未完成的观看或听辨仍分别记未验证。技术检查只认技术证据，已有效通过的技术项不因效果被否而改成未通过；效果也不能因技术通过而获通过。使用现有 QA 和用户反馈记录，不另建质量结论源。

锁画是唯一一次默认的全片画面拍板，绑定实际视频对象、视觉方面和有效摘要。带原配音粗拼已覆盖全部拟采用版本、实际时基与接点，并完成锁画项的连续检查时，可承担这一次确认；尚需改主过程、节奏或接点时先作内部候选，不先让用户批准一次“整片”，随后再批准几乎相同的锁画版。正式总装核对实际画面、时基及接点一致后复用该画面决定；实质变化只重开受影响范围。Skill 保留原粗拼锁画对象，正式总装另登记最终候选；等价核对作为新对象的真实 QA 证据，不能跨摘要搬运旧 QA 或伪造新对象已获 picture 确认，最终文件仍完成当前 final 确认与全部适用 QA。声音意图可提前规划，正式对点以实际采用画面为准。声音偏好已确定就沿用，缺项才询问；选用音效／配乐时读[声音 SOP](sop/06_音效与配乐_可选.md)。字幕按项目选择烧录、独立文件或不需要，只有明确不需要才记不适用。

承诺播放或要求上传前，先核实当前输入／工具确能提供连续视频和所需声音；文件引用、点击播放成功或截图接口不等于已连续感知。受限时完成可做的检查，明确感知缺项，不反复索要同一文件。用户明确观看后认可，单独绑定其原话、版本摘要与范围；不倒写助手已1×审看，也不扩为全片或新版本通过。

最终检查实际导出文件：音文一致、字幕文字和遮挡、混音清晰、来源、真实规格、完整解码，以及所需的正常速度完整审看／审听。无法实际观看或听辨的项目记未验证，不能由波形、ASR、截图或文件名改成通过。用户委托制作也不等于已观看。

程序化动画的实际事件前／中／后与边界、直接跳帧和顺序求值对照，按[确定性检查](sop/04_验收与返修.md#程序化动画的确定性与连续性)记录。检查字体／素材就绪、对象与历史版本、连接及最终屏幕轨迹；无损状态与编码差异分开，不假称通用状态工具已自动完成画面检查。

## 一个 QA 结论源

QA状态表.md 内唯一结构化记录是结论源；表格是生成视图。检查绑定对象、方面、文件摘要、有效摘要、方法、范围、证据和执行者。state 只保存 QA 位置和引用，用户确认仍由 state 管理。结果只有通过、未通过、未验证、不适用；后两种有原因。

可以交付说明缺项的待审文件，但只能标受限交付。正式完成要求当前采用最终对象具备有效最终确认，以及适用的 visual、audio、technical、sources、subtitles 检查；含 MG 时还需当前对象的 visual-design 和 motion 检查，具体绑定与方法见[MG 效果证据](state-contract.md#mg-效果证据)。这两项不替代原有 visual 正常速度审看，也不新增用户审批轮次。静态确认不能代表动态验收，旧 QA 不能放行新文件。

## 只返修实际影响

| 改动 | 重开范围 |
| --- | --- |
| 配音内容、顺序、停顿、时长 | 受影响时基、画面、字幕、声音及接点 |
| 只改增益且时间内容不变 | 音频合成与听感 |
| 主动作、取景、揭示或交接实质变化 | 受影响剧本、状态图／标注、实际画面与声音；总控更新采用与依赖，旧证据按实际影响失效 |
| 仅曲线、材质或局部素材改变，过程不变 | 局部画面及适用声音点，不重画整套设计 |
| 裁切、变速、入出点或时长变化 | 依据实际画面重校动作、声音、字幕及接点；总时基改变时同步下游 |
| 只改字幕字体 | 布局、安全区、遮挡 |
| 文件改名但字节相同 | 核对后重绑路径，保持适用证据 |
| 局部独立对象变化 | 此对象及实际依赖；无稳定对象边界才保守扩大 |

改动前记录实际时段与可见症状，按方案、时间组织、参数或工程归因，明确修改项、保持项和复查范围。“必须保持”只列有用户确认或明确采用记录的内容，并注明出处；未确认的旧实现保留为可改底稿，不因已经存在就锁定。每轮优先解决 1–2 个主要问题，明显硬缺陷及时修，不受数量限制，也不规定返修轮数；用户已有要求直接沿用。保持项写到对象、必要出现时段、叙事作用及相邻接点，避免修节奏时丢掉原有关系或角色作用；不据此要求角色全程出现。同一对象在全景、近景或不同绘制分支出现时，复查受影响的各次出现，不能以一处修好代替整体修好。用户反馈按原话保留真实引用。改完先登记候选，不按修改时间选择采用；内容变化时相关确认和检查按依赖失效。

## 交付与复盘

按实际范围交成片、可编辑工程、采用配置、音频／字幕、素材与来源、生成提示词、复现命令和 QA。交看前按[状态收尾](state-contract.md#恢复与生成视图)更新本段实际进度，再登记受限或正式交付；受限候选不写已验收。外部生成片只承诺可编辑的总装及后期，P0 不补空视频充数。

封面、标题、简介和其他画幅是按需任务，方法见[字幕与封面](experience/字幕与封面.md)。发布独立确认账号、材料和权限；完成不自动授权上传。

规则升级后的实际代表段对照及可选模型对照按[规则效果与模型对照](sop/04_验收与返修.md#规则效果与模型对照)。未做新产物前不承诺效果改善；同输入／约束／迭代预算的对照仅在需要时做，不自动授权额外调用或费用。

用户要求复盘或整期结束时用[复盘模板](../assets/templates/复盘.template.md)。通用方法、系列偏好和本期特例分开；规则升级先明确范围，不把私人素材、用户证据或案例参数自动回传公开包。
