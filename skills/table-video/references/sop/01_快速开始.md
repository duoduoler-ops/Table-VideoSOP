# 快速开始

目标：按[首次引导](../intake.md#首次引导)先接收用户文稿与已有配音，再依次核对画面与角色、参考来源与方向、代表静态，记录 DESIGN 后直接进入分段和文字镜头剧本，扩展设计、制作和验收。已提供的材料直接读取；目标与受众等仅在材料不足且影响下一步时补问，不固定发开场问卷。

## 1. 放好资料并检查环境

Skill 包保存指令、模板与示例代码，用户项目使用独立目录。先读取主入口并接收本轮文稿与已有配音，环境只核对当前步骤所需；不得把 Skill 安装目录当用户制作目录。

成功标志：Agent 列出实际可用工具、缺失项和下一步；本期资料目录已建立；没有把“安装文件存在”当成“环境已验证”。需要安装时先看明确安装方案，再决定是否执行。

已有项目不要直接覆盖规则。让 Agent 将本包资料放入一个独立参考目录，列出与现有规则的冲突和需要接入的链接，确认后只改这些入口。

由实际可用宿主加载主入口；文件在磁盘上不等于已被加载。Codex CLI 已识别项目 Skill；全新电脑的完整安装与触发流程、桌面热加载仍未验证。

## 2. 准备一份稳定输入

将完整稿放到本期 `01_稿件/`。需要建议时用[可选文案检查](05_文案检查_可选.md)；也可以直接使用自己确认的稿件。

本 Skill 不承担文稿创作；现有稿件不必先定稿再提供。已有配音可一并提供，核对内容、顺序、停顿和采用文件；派生字幕需核对专有名词与时间。缺配音先核对文稿，稿件采用明确后，由用户选择外部 TTS 或自己录音。Agent 默认不代生成 TTS 音频，可准备读法、停顿和回传说明，并继续不依赖时间的准备；不能猜正式时间码或开始依赖时基的动画。

成功标志：本期说明记录确认定稿、配音及规格；后续大段表引用准确文件。还没有的文件写待补，不创建空文件冒充输入。

## 3. 先选参考，再做自己的 DESIGN

按[参考入口与转场](../style-and-motion.md#参考入口与转场)逐步推进；已有适用确认直接复用：

1. 已给参考直接查看；没有参考且来源未定时，先选用户提供或 Agent 查找，再实际展示画面并选定借鉴方向。取图失败留在此步；自绘探索须有用户明确选择。
2. 方向或自绘路径明确后，核对代表内容所需角色素材，再制作并审阅完整代表静态。
3. 静态确认后，将已确认外观、拟用运动规则与适用范围写入根目录 `DESIGN.md`，直接进入制作分段；运动由 Agent 按经验和配音设定，在实际片段中检查。
4. 进入具体段落设计后，具体的新对象演化或镜头关系缺少适用的完整过程证据，或有未解决的高返工风险时，在设计阶段做局部完整过程预演；单纯首次制作或没有独立运动样本不自动触发，静态确认后照常进入分段和剧本，不预设前置三档选样。用户主动要求参数比较时再按范围执行。

涉及 IP／角色时，按[角色首次入口](../intake.md#ip-与角色首次入口)先核对身份图来源与采用范围；缺图引导提供，已给候选先说明来源，已采用的不重问，无角色则跳过。Agent 根据实际图片整理[角色说明](../../assets/templates/角色说明.template.md)，不凭名字指定外观。角色身份、整场静态与实际运动的证据分别记录，不继承作者示例的选择。

成功标志：根目录存在记录已确认静态与拟用运动规则的 `DESIGN.md`，能找到采用静图。没有独立动态样本不阻塞规划；运动效果标待实际片段检查。

## 4. 出表并确认

复制[大段表提示词](../planning.md)。重点看每段的声音已提供、画面必须新增、必要上屏文字，以及 Agent 主动列出的审查项和生视频推荐。

本次只确认划段、路线与范围。总控主动指出最需要检查的具体问题，并按[分段协作](03_目录与并行协作.md)建议本对话完成或多对话并行；创建新对话另认实际用户授权。

## 5. 先审文字剧本，再审设计

总控一次交完整镜头剧本，默认展示配音原文、可见过程及具体判断问题，制作细节同源折叠；对象变化、镜头与阅读仍须明确。用户审过这一版后才出设计图，再汇总真实关键帧与运动标注供视觉审查。分段表的“是”不能用于确认尚未展示的剧本。按[过程预演](04_验收与返修.md#完整过程预演与精修)处理新对象／镜头关系及未解高返工风险；同类型且相关风险已解决时复用范例，在首版完整预览核对适配。正式批量动画仍须核对本批授权与跨段衔接；生成仍由用户手动提交。

## 6. 总装与验收

使用[总装提示词](../review-and-repair.md)。先确认全片画面，再按需做[声音制作](06_音效与配乐_可选.md)，完成字幕和最终检查。

最后拿到：成片、适用的 clean 母版与字幕、可编辑源码或工程、素材与授权记录、复现说明、QA 结果。实际未播放检查的部分不会因为导出成功而变成“通过”。

初次填写可对照[两段规划示范](../examples/01_两段演示.md)和[DESIGN 填写示例](../examples/03_DESIGN填写示例.md)。它们演示填写方法；正式时间、视觉参数与采用状态由自己的配音、样本和确认记录决定。
