# S03 风格与动态

首次进入本阶段先按[输入规则](intake.md#进入画面规划前核对路线)核对并回显画面形式；未选则先问，明确要求重新选型则回到该入口。参考收集可以继续，不能用某种风格候选替用户决定制作路线。

代表静态也是视频设计。开始画面方案前先读[镜头推进](experience/镜头推进与转场.md)，涉及 MG 时同时读[连续 MG](experience/视觉叙事与连续MG.md)，再按[理解目标到关键状态](planning.md#从理解目标推导画面)推导内容、空间和观看节奏；已读且未变不重复读取。不等用户指出平淡或提出运镜，也不等进入复杂动画阶段才补这些方法。

先读已有 DESIGN 及确认证据。确认范围适合本次对象、画幅和运动类型时复用；历史文件和示例存在不表示用户已认可。首次建立视觉体系的顺序是：**参考来源与方向选择 → 核对代表内容所需素材 → 完整代表静态 → 记录 DESIGN → 正式制作分段及重点检查 → 用户审文字镜头剧本 → 设计图 → 制作与审片**。静态确认后默认跳过独立动态测试；运动按经验与内容设计，在实际制作片段中检查。用户明确选择自绘探索时，按[参考入口与转场](#参考入口与转场)替代参考获取环节，不跳过完整静态审查。当前阶段不提前批量设计全片；局部过程预演用于新的对象演化／镜头关系缺少适用证据，或具体未解高返工风险；参数对比仅在确有问题或用户要求时开展。

## 测试与复用

进入视频视觉设计时，先简短说明已确认什么、还缺什么、下一份可评估产物。角色身份／外观、完整静态画面、运动行为分别认实际样本；认可角色图不同时认可背景、图形、版式和运动，认可表达过程也不补足这些确认。

由上述证据决定是否首次建立视觉体系，不以“第一轮”、新开对话或交接标题代替判断。缺静态依据时先核对参考入口；参考方向或明确的自绘探索选择已有依据，才进入静态测试。缺运动样本只表示动态效果尚未验证，不阻塞 DESIGN、分段和文字镜头剧本，也不自动触发小样。交接核验的只读约束只在该核验步骤有效；用户明确限定只读、只选参考等范围仍须遵守。

| 当前依据 | 下一步 | 放行范围 |
| --- | --- | --- |
| 只有角色图或口头方向，完整画面参考尚未选定 | 先走[参考入口与转场](#参考入口与转场)，展示实际可见参考并交用户选择；已明确选择自绘探索则按该范围推进 | 参考获取与对齐；不能因取图失败直接交本片静态或角色补图选择 |
| 参考方向或自绘探索路径已明确，角色在代表内容中的表情、姿态、视角或互动缺素材 | 按[角色表演与素材充分性](#角色表演与素材充分性)说明具体缺口、推荐最少补齐项并询问解决方式 | 可继续不依赖缺口的准备；受影响的代表画面等待素材或明确的表演调整 |
| 参考方向已选定或已明确选择自绘探索，尚无适用完整静态依据 | 选本片代表内容做完整静态测试；MG 使用实际可编辑部件绘制 | 当前静态候选及其必要部件；不批量展开全片关键图 |
| 完整静态画面已确认，缺适用运动样本 | 按[默认动作设计基线](#默认动作设计基线)及镜头／连续 MG 经验设定运动规则，写 DESIGN 后直接进入正式分段；MG 沿用该静帧的部件源 | 分段、文字镜头剧本及其审查；动态效果留待实际制作片段检查，不要求先选参数档位 |
| 静态与运动均有适用的已确认范例 | 回显样本及对象、画幅、动作的适用范围，直接复用 | 范例已覆盖的工作；新风险才补测 |
| 新对象演化／镜头关系缺少适用过程证据，或有未解高返工风险 | 在设计阶段用带原声的局部预演验证完整主过程，按[预演规则](sop/04_验收与返修.md#完整过程预演与精修)执行 | 可先于总览；正式批量制作仍认总览确认，不重开完整风格流程 |
| 用户主动要求参数比较，或具体问题确需比较 | 按[按需对比](#默认节奏与按需对比)做最少必要变体 | 只验证所涉问题，不要求先选三档 |
| 用户只要独立静图、提示词或语义草稿 | 完成当前轻量交付 | 不要求动态测试、state 或正式工程 |

运动经验是设计依据，不是实际运动已通过的证明。普通动作由 Agent 直接设定与实现，在实际片段中审看和返修；不让用户为常规入场、展开或跟随逐项选档。静态确认与动态验收仍分开，已有决定不重问。单纯首次制作、换了文案或缺独立参数样本不自动构成新类型。新类型须指出新的对象演化、镜头、互动或空间关系，及尚缺哪段适用的完整过程证据；未解风险须具体到可能失败的关系或实现缺口。同类型只有在相关风险已解决时才复用，用户已指出的问题不能被“同类”豁免。

**完整观看过程先于参数精修。** 同类型且相关风险已解决，在首版完整带原声预览核实本段适配；新类型或未解高返工风险先做局部过程预演。覆盖起因、主变化、结果和交接，不能用静帧轮播、整图轻缩放或光标独动代替。已有同范围有效预览或高清直接复用，不为低清名目重转。阶段与证据细则只在[预演与精修](sop/04_验收与返修.md#完整过程预演与精修)维护。

代表样片围绕尚未解决的主风险选择。在现有方案或运动标注中简记：要排除什么问题、覆盖哪段起止状态与完整取景、改善后应实际看见什么。问题涉及整段语义、运镜或节奏时，窗口须覆盖这些过程及必要衔接，不能只测边框反馈等次要变化。局部测试只证明其覆盖项；已确认且未受影响的部分直接复用，不增设表格或审批。此要求用于新建或返修动态，纯文字修改、提示词准备和独立静态交付不因此触发样片制作。

## 效果基线与适用范围

用户已指定成片、项目或系列经验作为效果标准时，从该实际项目定向选取与本轮理解任务可比的已确认片段，覆盖完整主动作、取景推进和结果阅读；有关联返修记录时，同时核对被否决的问题及确认版怎样解决。不只选择容易复现的内容搬运，也不按题材或单张构图代替可比性。只有候选或确认来源不明时标明证据边界。核对真实采用版本后，将以下内容写入本项目 DESIGN；不因新开对话或换画风丢失标准：

- **风格职责**：负责角色身份、配色、材质或构图方向的参考，各自继承什么。
- **效果职责**：设计前记录范例版本／路径、片段起止、借鉴的主动作／观看推进／节奏及本段实现方式；只写“参考某一期”不构成对标。分析“它如何让观众看懂”，不复制外观、幅度或绝对时长。观看范围、抽帧范围及未验证部分分别记录；完成后在实际预览尺度以 1× 复核同一目标，并连看本段与相邻镜头。
- **采用范围**：本次样本真正覆盖的对象、动作、镜头和关系；局部分类或标题入场样片不能覆盖全片的新空间、角色表演和叙事交接。
- **项目验收线**：用户规定的节奏、静止时长等写明适用范围与检查方法。近静止达到两秒先查具体任务；是否通过认项目运动门禁，用途说明不能抵消已算出的未通过。用户另有更严的本期覆盖时写入本期 DESIGN 并经用户确认，不把该个案秒数强加到全部视频。

未指定效果对标时，先按[完整动作源码](complete-motion.md)匹配关系并定位实际实现，同时用包内[正反过程案例与可播放示意](examples/04_连续MG正反过程.md)建立对象变化、镜头作用和节奏的最低执行依据，再按已选风格与可核查的同类参考确定表现目标；不自动访问作者私人项目。机制示意不是用户确认的风格预设，无法查看动态时须明记边界，不能凭文字声称已看。参考不是必须照搬的布局；外观确认、局部参数选择和全片效果通过分开记录。用户授权“默认同意／选第一方案”只解决制作选择，不能据此伪造观看、取消质量检查或放行已知缺陷。

## 参考图优先对齐静态

### 参考入口与转场

这是首次视觉建立中的独立步骤。先说明“现在选整片画面的参考方向，重点看配色、构图、图形与材质；选定后才制作本片代表静态”，不让用户从已做好的试样倒猜当前阶段。

| 当前依据 | 应做的下一步 |
| --- | --- |
| 用户已给图或链接 | 直接实际查看，按所选路线筛选并说明借鉴范围；未确认的交用户选定，不再问由谁找参考。 |
| 用户已明确自己提供，或已让 Agent 查找 | 承接已选方式，等待所需材料或继续检索；不重复询问来源。 |
| 没有参考且来源未定 | 只问当前选择：“你提供喜欢的参考图／链接，还是我按已选路线查找？”不先画本片静态、选配色或提角色补图方案。 |
| 已有适用的参考方向、完整静态或 DESIGN 确认 | 回显实际对象与范围，直接接续缺少的步骤，不为流程重新获取参考。 |

Agent 检索先按[参考筛选与可实现性](#参考筛选与可实现性)核对路线与能力；用户可用熟悉的网站，不指定必经平台。参考交审展示实际看过的画面，说明借鉴的配色、构图、图形或材质，以及不继承的内容。选择参考只确认方向，不等于本片静态已经完成。

图片打不开、浏览器超时或只有检索摘要，表示参考取证未完成。说明具体缺口后留在参考环节，换可访问来源或请用户提供；不能据此推定用户没有参考、放弃参考或同意自绘。可继续输入核对和技术探针等独立准备，但不能将探针、自绘试样或角色补图问题替换成当前交审内容。

**自绘探索是明确选择的分支。** 用户主动要求，或在了解“用本片可编辑试样来探索方向”后明确同意，才可制作少量真实静态候选；已有同范围授权直接承接。单纯“没有参考”“继续”、工具失败或 Agent 推荐均不构成这一选择。该分支仍须按实际素材核对角色表现，并交完整代表静态审查；不把局部图形试样说成整场通过。参考方向选定或自绘探索路径明确后，才询问代表内容确实需要的角色补图，不提前把多个阶段的决定一起交给用户。

### 参考图本地交审

交审风格参考时，先把实际图像保存到项目本地。已有稳定可打开的本地图直接复用；临时附件复制到项目，已授权查找参考时可保存可访问的原图，或用当前获准工具保存实际页面截图并注明范围。沿用已有参考目录；没有时使用 `03_视觉设计/参考图/`，轻量参考任务使用用户指定工作目录，不为存图初始化整期或 state。

保存后用图像查看工具实际打开，核对画面、尺寸、清晰度与所述来源；下载成功、文件扩展名、格式头检查或网页摘要都不能代替看图。交审同时给本地图片预览和可打开的文件链接，使用宿主支持的本地路径格式；原作页面只作溯源链接，不再依赖远程热链展示。来源、作者、借鉴职责和候选状态写入已有素材来源记录，不把参考选择登记为本片静态或运动通过。

普通失链可换可访问来源；登录要求、明确拒绝访问或平台安全阻断不得换通道绕过。HTML错误页不能改后缀当图片；无法保存或实际打开时明确缺项，不冒称已看，不用自绘替代原作。参考图片留在用户项目，不自动收入分享包或Skill分发。

保存辅助命令及其格式校验边界见[参考图本地交审工具](sop/09_DESIGN建立与校验.md#参考图本地交审)。外部参考仍按下节筛选；本地可打开只解决交审可见性，不证明路线合适。

### 参考筛选与可实现性

先找符合已选制作路线、拟借鉴部分有实现依据的参考，再让用户比较审美。纯 MG 优先从真实 MG 成片或风格帧筛选，检查版式、图形、图标、连线、容器和角色素材如何组成可分层控制的画面；“完整画面”不表示任意完整插画都适合。检索词和候选筛选都应保留 MG／motion graphics 条件，不因主题是小猫、工作台或温暖陪伴而转向一般生活插画、绘本场景或逐帧角色动画。

推荐前实际查看拟展示的画面，核对原作来源和对应的 MG 表现；工作室名气、标签或搜索摘要不能单独证明路线匹配。只有链接、未打开图片或只拿到检索视觉摘要时，保留为待核查线索，换可访问来源，不作为已筛好的可制作参考推荐。静帧仅能支持静态判断，运动特点仍需实际观看。

每个保留候选简记“借鉴什么 → 当前用什么独立部件／已确认素材实现 → 哪些还未验证”，无需让用户审代码或选择技术栈。依据可以是适用的真实输出、现有部件源，或已核对可运行的绘制与预览路径；仅有 Node、FFmpeg 或某个引擎名称不等于能画出参考效果。检索阶段不必为每张图先做完整复刻，但没有关键外观或行为的实现依据时，不承诺“可以照这个做”；需要补素材或新增受控能力的先说明缺口。

普通插画、绘本、复杂手绘场景或依赖逐帧表演的作品，不能仅因配色好看就列为当前可制作的纯 MG 主参考，也不能用“只借画风／构图”绕过筛选。用户明确指定这类作品作配色、材质等辅助参考时，尊重其具体用途，另找 MG 主参考或先做可实现性样本；不要把辅助参考升级成整片效果承诺。MG 也不只限于简单几何块：纹理、层次、角色和复杂构图可在实际素材与可控部件支持下使用，不为方便实现而擅自降低用户选择的外观。

用户说“不喜欢，再找几张”，保持已选路线和已确认角色，只在路线内换配色、版式、图形语言或质感；未说明原因时不推断为否决整类风格。确实找不到匹配且可核查的参考时，按[参考入口与转场](#参考入口与转场)留在参考环节，说明缺口、换来源或请用户提供；只有用户明确选择自绘探索时才准备 MG 试样。不把待核查线索包装成通过，不自动安装、生成素材或改换路线。

分别说明每张参考负责角色身份、画风、构图或其他具体方面，采纳什么、不继承什么。一张图足够时不要求凑齐矩阵；角色图只作身份参考时不能代替完整画面参考，静图也不能提供运动证据。角色用[角色说明模板](../assets/templates/角色说明.template.md)。

静态候选用本期同一内容对比，交实际可见、接近目标外观的画面。MG 从下节的实际绘制源输出；空框、默认几何占位和说明文字不是完成图，不能因“可编辑”降低已选参考的视觉要求。P0 无内置真实视觉预设，不得把[文字参数示例](examples/03_DESIGN填写示例.md)宣传成已验证画风。

所选路线确实需要生成场景、独立图像素材或用户只求外观概念时，才按生成边界准备[手动生成任务](../assets/templates/manual-generation-task.template.md)。生图权限不改变 MG 测试的制作方式；用户确认参考或静态布局只记录已展示方面。

## 角色表演与素材充分性

身份素材来源和采用范围尚未明确时，先按[角色首次入口](intake.md#ip-与角色首次入口)处理；不要凭名字选图，也不把提供候选当作已采用。已有适用身份确认直接进入下面的叙事与表演核对。

有 IP／角色时，先确定它在本段承担什么：操作、观察与反应、引导、陪伴，或仅作身份标识。需要参与叙事的角色，应与画面中的对象和事件建立可见关系；不能因为手头只有一张正面图，就默认全程贴图陪站，省略本应设计的表情、视线、姿态或互动。也不强迫仅作标识的角色表演，或让角色持续抢占主要信息的注意力。

在代表静帧制作前核对一次；后续扩展关键状态或动作时，仅复核新增需求。对照实际文件和已确认适用范围，简记“所需表现 → 可用素材／可控部件 → 缺口”。身份外观已确认、姿态足够和连续运动可实现是三种不同依据；卡片运动通过不能代替角色表演通过。

确有缺口且解决方式尚未确定时，**在制作受影响画面前主动询问是否补生图**。一次说清缺什么、影响哪项表现、推荐最少补齐什么，并给出实际可选方向：补生图／补画、用户提供已有素材、或用户明确选择调整表演。可以这样问：“现有图能确认角色身份，但还缺能表现［具体动作／情绪／视角］的素材。建议补［最少必要内容］。要先补生图，还是你提供现成素材，或把动作调整为现有素材能支持的方案？”实际发送时填入本片内容，不把占位符交给用户；不要把一套表情包、固定三张或六姿态当作通用必需项。

询问只针对尚未解决的缺口。用户已经明确选定补图方式或给过同范围授权时，沿用决定推进对应准备，不再次询问；同一缺口不在每个阶段重复发问。Agent 的补图建议、工具可用或素材预算存在，都不能被当作用户已选择补图。生成提交仍按[制作与素材](production.md#三种外部任务)和当前有效授权、宿主约束执行；本检查不自动扩大生成权限。

等待选择或补图时，可继续语义方案、已具备部件和其他不依赖该素材的工作，受影响部分标待补。不能把同一平面角色的整体平移、旋转、缩放或淡变冒充肢体、表情、转头与接触动作，也不擅自改脸、拉长四肢或降低已选画风来凑动作。若用户选择减少表演，说明保留和放弃的表现，按该范围继续；素材本来已足够时直接复用，不为走流程强制生图。

用户选择补图后，将身份、画风等参考职责、必须保持的特征、最少必要姿态及各自用途、朝向与视线、独立素材规格写入现有[生成任务包](../assets/templates/manual-generation-task.template.md)；可以先用设计表对齐，正式接入仍需可用的独立姿态或部件。收图后核对真实外观、比例、轮廓、表情／动作、视线与互动方向、裁切或遮挡，并凭实际用户决定采用。数张姿态图不自动证明姿态间衔接自然；新增的切换、接触或连续表演仍按当前风险验证，不重做未受影响的已确认部分。

## 静态样本与可动部件

先区分外部风格参考、MG 测试画面与部件源、独立位图素材、生成场景／生视频底图。MG 测试必须画出实际可编辑的场景：需要独立变化的卡片、图标、连线、容器等分别是矢量对象、图层或代码组件，静帧由这些对象在同一构图中输出。可用 SVG、分层绘制源或目标引擎组件；具体形式服从用户工具选择与当前可用能力。输出 PNG 可供审图，但同时保留源文件、对象标识和入口，不能只交一张平面 PNG。

不得新生一张 AI 场景图充当 MG 静态测试，也不得把它贴进 Remotion 后用整图缩放、淡入淡出或切图冒充部件运动。已选 AI 概念图可以是外观参考；采用为 MG 静态依据前，须用实际部件重建并检查真实输出。若目标是 Remotion，应能指出每个需独立运动的对象对应哪个组件／SVG 组／独立素材、可控制哪些参数；一个内嵌整图不算分层。

已确认位图角色可保留原貌，作为场景中的独立素材对象；不要为了“程序绘制”擅自简化毛发或重画角色。其内部肢体、表情和尾巴并未因此可动；相应动作需要实际分层、姿态素材或可验证实现，缺失时先走[角色素材缺口引导](#角色表演与素材充分性)。只有不涉及独立运动的背景或素材可以保持整体，不能把“每个部件独立”扩大成每根毛发都要拆分。

为代表测试只记录必要项：需独立改变的对象及其真实源文件／对象标识、素材来源、关键遮挡或锚点、可控参数、已验证与仍待补的部分。生成静帧前检查对象确实分开，进入动态时在同一套源上验证独立变化；拟定的部件表不能当成已有资产或运动证据。

在制作该测试前核对当前实际可用且获准的绘制／预览工具、部件源与最小输出入口；进入动态再核对目标引擎是否可运行。包内渲染适配器只调用已核实的现有环境，不捆绑运行依赖。目标引擎未就绪时，已有可用的独立绘制源可以先验证静态外观，但须写明尚未验证接入；不能改用整张生图顶替。确无绘制或预览能力时说明具体缺口，继续参考整理、部件设计或实现计划，不自动安装依赖、建正式工程或把纯 MG 换成生视频。

## 默认动作设计基线

静态确认后写 DESIGN 时，直接采用[模板的职责候选与 B3 校准](../assets/templates/DESIGN.template.md#职责曲线与校准)作为制作初值，注明来源与适用范围；Skill 没有默认独立动态测试，实际片段再核验。分享包保留动态风格测试→确认→回填，候选在那里作为测试起点。**空值不等于禁用，进入动画前必须有值并写明来源；不准一条曲线包办所有动作（含镜头）；曲线合规不等于利落。**

| 职责 | 候选曲线 | 包内完整范例路径 | 什么时候不用 |
| --- | --- | --- | --- |
| 出现／到位 | `(0.16,1,0.3,1)` | [B3 完整时间线](../assets/motion/ep05-d06-task-relay/src/timeline.cjs) | 需要读清变形过程时不用快速出现曲线；进退仍须几何／遮罩／路径过程 |
| 转交对象、快速重排或到位 | `(0.22,0.72,0.22,1)`；短距参照 B3 约46f@60fps | [B3 完整过程](../assets/motion/ep05-d06-task-relay/README.md) | 仅在主要任务是辨认去向与落点时起用；需要看清沿途操作时改用过程曲线与相应窗口 |
| 预备／蓄力 | B3 短、可读的预备，`ease-in-out-cubic`，参照24f@60fps | [B3 事件与状态](../assets/motion/ep05-d06-task-relay/src/timeline.cjs) | 无预备语义可省；不能把主位移整段归作预备 |
| 路径或变化本身承担含义：搜索、拖动、剥离、擦写、展开 | `ease-in-out-cubic` 作为可读过程候选；按实际动作调整 | [B3 事件与状态](../assets/motion/ep05-d06-task-relay/src/timeline.cjs) | 位移和尺度也可承担过程；不因属性叫 position／scale 就强套 travel，不为展示曲线拖长无意义过程 |
| 揭示／重构图／拉开 | 空间路径与时间分离，按认知窗口分配屏幕路程 | [共用空间相机](../assets/motion/production-core/README.md) | Z 起伏须揭示关系；平面阅读仍可固定，旧 ep07 缩放只适用其二维职责 |
| 主体绑定跟随 | 最终主体变换＋屏幕锚点反算，无独立曲线 | [ep07 入场与跟拍](../assets/motion/ep07-entry-follow-v8/README.md) | 需要看固定整体关系时另选取景，不让对象与镜头互相抵消观看推进 |
| 稳定阅读／局部微调 | 阅读固定；微调用到位候选并短促停稳 | [ep07 相机收势](../assets/motion/ep07-entry-follow-v8/src/camera.cjs) | 不用长慢尾耗阅读；情绪性慢镜只在表达需要时另记理由 |

同是位移，物件快速归位主要读落点，沿贴纸边缘剥离则必须读路径和接触；按观看任务选择曲线与时长。跨屏指示动作核对实际路程和前段速度集中，短窗口里的数学缓动也可能只剩闪现。历史源码的迁移边界见[完整过程源码复用](experience/视觉叙事与连续MG.md#完整过程源码复用)。

B3 帧数、幅度与比例只认模板同一校准字段，是手感参照；项目约束按 DESIGN 的 `motion.gates` 测量。设计动作的步骤统一见[对象与部件过程](planning.md#从理解目标推导画面)，进退／替换及例外按[默认动作语言](experience/视觉叙事与连续MG.md#默认进出场与替换)，不在实现阶段重写一套动作依据。

按[十二原则](../assets/templates/DESIGN.template.md#动画原则检查)选择适用演出：刚性部件可保持形状，预备、受力、附属响应及接收反馈须有动作意图或连接依据；直线可表达机械约束。部件身份和结果变化由本段过程决定，不按动作数量、延迟或微动幅度认定表现通过。

主体与镜头共同排时，核对合成后的屏幕位移、可见尺度和注意力接管。过程或预算不成立先回[原因层](self-diagnosis.md#先按原因决定改哪层)，曲线只调整已有窗口内的运动疏密；经过关键点不自动归零。

## 默认节奏与按需对比

默认以利落、清楚、有落点的运动作为起点：预备短而可读，主动作及时推进，长减速尾段不造成悬停等待，关联动作适度接力；接触或到位后按观看任务转交注意力，需要阅读的对象及时稳定。轻量刚性 MG 保持形状；有必要时用浅弧、小幅单次回正和延迟承接表达动作，不默认漂浮、多次弹跳或拖长停顿。慢动作、重量感、情绪表演或复杂变化需要更长时间时按内容处理；十二原则仍按适用性设计。

先给主变化、实际阅读和交接分配时间，再安排指示动作与装饰。阅读从完整清晰、无遮挡、达到可读大小时计；比较保留共同可辨窗口。指针绑定目标最终位置，以完整接近、操作、释放和离开过程服务理解；没有操作职责可不用，不在每个动作窗口重建一个光标。初值按路程和辨认需求决定，不让用户逐项选参数。

用户主动要求比较，或一个具体未解决风险确实需要比较方案时，才做局部对比：

- 先说明要解决的可见问题。若问题在剧情、空间或时间预算，先改方案，不用参数比较代替。
- 参数比较保持同一内容、动作、路径、取景与起止状态，只改能影响该问题的一个数值或有明确因果关系的小参数组。版本数以回答问题为限，不强制三档，也不排列全部参数组合。
- 使用同一套可编辑部件，给真实可播放片段、实际参数及单位；保留完整动作与结果阅读，不用整体变速冒充单项比较。
- 三档或多档都沿用同一个失败的表达过程时，不能因对比齐全而通过；返回过程或时间组织。各版本按下节检查，给简短推荐与理由。用户的选择只覆盖展示的参数和范围，记录在已有 DESIGN／运动标注，不重开整个视觉流程。

## 动态必须实际看

本节检查实际制作片段，以及按需产生的局部小样；不是恢复前置动态测试。MG 沿用静帧的绘制源与部件标识，检查实际对象变化、完整主动作和结果阅读。标题入场不证明复杂对象交接可用；未产生真实片段时只能记录计划与待验证项。

交付动态候选前，分别检查实现与运动观感：抽帧、对象轨迹和解码可核对身份、造型、层级、落点及连续性的局部证据；正常速度完整连续观看当前动作，才能检查预备是否读得出、时间与间距、注意力交接、阶段衔接和停稳节奏。需要跨镜衔接时连看相邻镜头。不能用关键帧通过或工具成功替代连续观看。

当前工具不能连续观看时，仍先按[动态自检方法](motion-check-method.md)检查整段时间、近静止区间和关键动作密集帧，核对真实取景与剧本，并交审前算出运动门禁。已证实的空等、缺失镜头、遮挡、关系断裂或门禁未通过记未通过并返修；不能以“整体未验证”掩盖这些缺陷。修复后如实记录已检查范围，把尚不能判断的整体手感留为未验证；仅交付明确标注缺口的可播放候选，不能宣称运动已通过。用户不满意时保留未受影响的已采用静态，按真实反馈重查受影响动作、空间和时间预算，不把否决仅当作调慢或增大回弹的指令。

正式配音对点仍依据实际核对的句界／词点；无对齐依据的独立运动试验须说明尚未验证音画同步，不能编造秒点。前期测试已覆盖的风险在制作阶段复用，不再机械追加同类样片。

用户可自然语言描述“慢一点”“少回弹”。先定位对象、方面与作用范围；时长调整保护已采用配音、结果阅读和全片时间预算。发生冲突先重排预备／动作／阅读或减少不必要变化，不能偷偷加速配音。参数有单位，正式渲染时按实际 fps 换算。

看着突然先查过程、辨认需求与总时间，再查预备和停稳，最后才调曲线。持续运动不自动产生语义，固定镜头也不自动失败。阅读、比较、妥协或反问可有意停住，不要求整场持续运动；这不能抵消运动门禁已算出的未通过。

## 记录采用

静态确认后建立 DESIGN，使用[DESIGN 模板](../assets/templates/DESIGN.template.md)和[建立方法](sop/09_DESIGN建立与校验.md)。记录已确认外观、拟用运动规则及其经验依据、适用对象与范围；Agent 拟定的参数标为制作初值，动态证据暂缺时留空并注明待实际片段检查，不伪造样片、参数选档或用户确认。缺动态证据不阻塞此时的 DESIGN 采用和规划。

随后简短告知“外观已定，下一步按配音划分制作段；运动按既定经验设计，在片段中检查”，转入[规划](planning.md)。正式分段、文字镜头剧本和设计图各按对应审查范围推进。制作前补齐当前会用到的具体数值与单位；系列共性只在 DESIGN，镜头例外只在对应配置，工程参数从它们派生。实际调用须能追到参数来源；如方案区分传递、落下、镜头三类曲线，而工程统一使用一个通用插值器，先核对是否漏接或经验证合并，不能仅凭配置已写齐放行。

实际片段或按需小样产生后，补充文件、参数、检查结果与真实确认范围。经验依据、制作初值、已检查实现和用户已确认效果分别记录，不能把一个卡片动作外推为全片角色或镜头的统一数值。

具体新对象演化／镜头关系缺适用过程证据，或复杂动作、接触关系、部件实现存在尚未解决的高返工风险时，在正式 state 中使用现有 risk、pilot、依赖和确认机制，见[状态契约](state-contract.md#设计期预演与正式制作的状态边界)。未建正式项目时保留当前交互依据，不为局部试验初始化整期；首次制作或没有样本本身不是风险依据。
