# 比较可读期间回接：v3 → v4

本例是同一设计的局部动作修复：建议引发拆开检查，两个候选共同可辨时，接收载体先回接，按钮让位、计时下落与统计合回交叠接续，最后保留未决反问。用户对v4反馈“这次好多了”。认可范围仅为这次局部改善，不是通用视觉预设或其它题材的通过结论。

## 何时用

- 同一载体拆出若干对象，比较后须回收到原载体；主要缺陷是比较前后反复全停。
- 继承可辨比较、接收准备和分批回收的关系，不复制题材、构图、对象数或秒数。
- 需要固定精读、反问或等待真实完成事件时保留停顿；不得为交叠提前演出结果。没有这类关系时另设计，不强套收纸动作。

## 修了什么

v3在源21.250–22.000秒有0.750秒全场固定；前后的减速与缓入让停顿感更长。v4保持原设计、结果和片段时长，把载体回接放到比较仍在继续时，再逐项让位、归回。各主位移保持原有利落特征，没有靠拉长慢滑、装饰漂浮或常驻运镜消除检测。

全局时基为60fps，来源区间为`[F1036,F1540)`，共504帧／8.4秒。包内API与Composition从局部0开始；全局帧 = 1036 + 局部帧。以下仅为这份源代码的事件，不是新项目时间要求，也不冒充精确词起音听校。

| 动作 | 源全局秒 | 本例局部秒 |
| --- | --- | --- |
| 纸面回接，候选位置补偿后仍可辨 | 21.050–21.650 | 3.783–4.383 |
| 按钮让位 | 21.500–21.950 | 4.233–4.683 |
| 计时下落 | 21.800–22.300 | 4.533–5.033 |
| 统计合回 | 22.200–23.000 | 4.933–5.733 |
| 原未决反馈开始接入 | 22.500 | 5.233 |
| 原计时横向归槽开始 | 23.150 | 5.883 |
| 原反问固定窗口保留 | 24.600–25.550 | 7.333–8.283 |

载体与候选各有一份纯函数状态。回接时用同一时刻的最终变换补偿候选世界位置，再接归位路径；相机局部调整为按钮留出可读边界。源21.050之前、23.450之后与v3一致，原反问和首尾保留。局部提前没有新增后段固定区间；这项数值事实不替代整段观看判断。

## 从哪些源码看起

- [局部时基入口](src/state.cjs)：`atFrame(localFrame, 'v4')`、`atSeconds(localSeconds, 'v4')`；`events()`同时返回源秒和局部秒，跨片段边界的事件保留原范围。帧504仅为结束接点，正常渲染帧为0–503。
- [v3反例](src/timeline-v3.cjs)与[v4修法](src/timeline-v4.cjs)：同一对象、不同的接续时序和相机路径；`v3`不是推荐采用版。
- [共享场景](src/scene.cjs)和[配色常量](src/design.cjs)：内部尺寸和对象身份保持。原始时间线依赖保存在`src/original/`，只用于求本片段上下文，不作为其它区间的设计范例。
- [Composition入口](src/entry.jsx)：`RelayReceiveV3`、`RelayReceiveV4`，1920×1080、60fps、504帧。
- [来源与移植差异](provenance.json)、[时基清单](manifest.json)、[行为回归](verify.cjs)。

场景源码原字节保留；时间线仅调整包内依赖路径。配色读取改为相同常量，避免依赖作者机器的配置文件。回归锁定实际来源摘要；不携带原声、私人媒体、字体或运行依赖。默认无字幕；可通过`captions: [[局部起秒,局部止秒,文字], …]`传入本次已采用字幕。字体仍为系统`Microsoft YaHei, sans-serif`，换环境须核对字形及尺寸。

## 检查与渲染

从SOP或Skill包根执行纯状态回归，无需安装依赖：

```text
node assets/motion/relay-receive-v4/verify.cjs
```

该回归核对独立跳帧、源锁、范围外一致、比较对象在画内且互不遮挡、世界位置补偿、接点速度和未新增固定区间。来源记录保留交付原字节摘要；跨系统回归只统一CRLF／LF后核对另存摘要，以兼容Git换行转换，不忽略其它内容。断言里的秒数、像素及容差只锁本例，不能拿去评分新内容。回归通过不证明正常速度观感、阅读或配音对点。

已有Remotion与浏览器环境时，先复制源码到项目，再用现有适配器；以下从SOP或Skill包根执行，路径占位替换为实际已有路径：

```text
node scripts/render-motion-example.mjs --runtime <已有node_modules> --browser <已有Chrome> --entry assets/motion/relay-receive-v4/src/entry.jsx --composition RelayReceiveV4 --out <项目内新输出目录> --mode video --scale 1
```

对照时将Composition改为`RelayReceiveV3`并使用另一个新输出目录。适配器输出无声视频，之后按本项目采用时基合入原声；不自动安装依赖或下载浏览器。本次源码迁移完成纯状态／SVG对照，未在另一环境完成Remotion渲染或新的1×听看验证。
