# D04 原处改稿与配音交接过程

来自第 05 期 D04 实际采用的 `dyn-20260925`，用于“同一对象在检查中暴露具体阻碍，原处修改后解除阻碍，再交给下游”的过程。这里保留实际源码、内部关系、时间分配、曲线及相机，不能只取结束构图或 easing。

这是 **MG 过程摘编**，不是原 1228 帧整段的像素复刻。原片含 G02 视频和章卡角色图片，本包不含图片、音频、视频或字体文件。原文案及 400 个波形峰值、237 个字幕起止数值保留；峰值只提供图形数据，不构成可播放声音。字幕正文、媒体 URI 和输入绝对路径已去除。原稿里的工具与频道文字是历史演示内容，不是本包对当前工具能力的推荐或保证。

## 两个入口

| Composition | 原 D04 局部帧，0 起算 | 本入口 | 保留过程 |
|---|---|---|---|
| `EP05D04Process` | `[564,1142)` | 60fps，578 帧，9.633333 秒 | 完整读稿 → 长句变慢 → 波形打结 → 圈句近读 → 原处改短 → 波形接通 → 稿纸缩小让位 → 配音/字幕结果落定 |
| `EP05D04PaperUnfold` | `[0,166)` | 60fps，166 帧，2.766667 秒 | 稿纸落格 → 接收底座受力 → 同一张纸向下展开 → 推近 |

**不拼接两个入口。** 原 f165 的相机约为 `Z2.30/CY667`，f564 为 `Z1.50/CY791`，中间原本有 G02 媒体承接。删去后存在景别跳变；本包不补造转场或冻结占位，也不声称已继承原片前置情绪过程。主入口自行完整包含读稿的起因、卡住、修改和结果交接；附带落格是另一个完整动作。

以下保留原源码秒点；新入口秒点为源秒点减 `9.400`，按 60fps 求帧。词点来自原工程自动候选，未在本次重新听校。

## 运行

使用已有 Node、React/Remotion 和 Chrome，不安装依赖，不下载浏览器。在 Skill 根目录用 PowerShell 7 设置本机现有环境路径后运行（环境值只对当前进程使用）：

```powershell
$env:REMOTION_NODE_MODULES = '现有 node_modules 的绝对路径'
$env:CHROME_BIN = '现有 Chrome 可执行文件的绝对路径'
node ./scripts/render-motion-example.mjs --runtime $env:REMOTION_NODE_MODULES --browser $env:CHROME_BIN --entry ./assets/motion/ep05-d04-revision-process/entry.jsx --composition EP05D04Process --mode video --scale 0.6666666666666666 --out 'Skill目录之外的新输出目录'
```

附带动作只需改 `--composition EP05D04PaperUnfold`，并使用另一个新输出目录。`--mode stills --frames 0,326,350,402,507,577` 可取主入口代表状态。所有帧均按所选入口的局部帧解释。

无渲染的事实导出：

```powershell
node ./assets/motion/ep05-d04-revision-process/timeline.cjs
```

`stateAtFrame()` 支持独立求帧；`events()` 同时导出源时间与本入口时间。`source-timeline.cjs` 是原时间表的完整字节副本，包含本摘编未使用的 G02/章卡事件；消费方应使用 `timeline.cjs` 的过滤接口。

## 文件与验证边界

- `Scene.jsx`：实际 DOM/SVG 场景；移除 G02、图片角色和范围外章卡，过程组件保持。
- `model.cjs`：从原组件逐段提取的纯函数，实际画面与机测接口共同使用，避免两套动作值。
- `source-timeline.cjs`：原执行时间表；`timeline.cjs`：两个入口的帧映射、事件及状态导出。
- `source-data.json`：原纸面内容、设计值和数值波形/字幕时点的最小集合。
- `entry.jsx`：适配已有 Remotion 的两个 Composition。
- `provenance.json`：实际来源文件 SHA256、中央采用记录、适配边界。

随附 verification.json 记录提取阶段的源码与语法检查，未计入后续渲染。使用者每次调用的渲染、静帧、1× 审看和审听须另以该次实际产物及检查为准；本例不附感知通过结论。源码同源和帧数正确不等于新包画面/观感已通过。系统字体实际排版可能随环境变化，不承诺像素复刻。改内容时须保留朗读位置、圈句、改短、下文回流与波形接续的对应关系，再按新内容重新分配时间和取景。
