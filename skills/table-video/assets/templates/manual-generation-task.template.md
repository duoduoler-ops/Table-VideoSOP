# 手动图片／视频任务包

复制到本期素材目录后填写。Agent 准备并检查完整任务；用户手动提交生成或重抽。模板中的方括号是项目输入位，不是已批准值。实际发送前补齐必要项；没有依据的精确词点写待核对。

本模板用于已选生成路线、外观概念或独立图像素材。MG 的代表静态测试须按[可动部件要求](../../references/style-and-motion.md#静态样本与可动部件)由可编辑绘制源输出，不使用本模板生成整张场景来替代。

## 用户操作步骤

1. 打开你已经可用且获准使用的工具：[工具名；不知道时写待选，不自动安装或登录]。
2. 核对界面实际可用的模型、输入模式、时长档、画幅、音频选项和本次费用：[实际值与核对日期]。付费与账户决定未解决时先停在材料准备。
3. 按下表职责上传参考，粘贴下一节完整提示词。结果核对图不自动作为尾帧。
4. 生成后保存原始候选，不覆盖之前版本；回传到：[项目内目标目录或已批准接收方式]。
5. 同时回传可见模型／参数、候选文件对应关系及是否已有容器原声。不要回传凭据、cookie 或无关账号信息。

## 可直接粘贴的静图提示词

```text
用途：[所属段落与画面任务，不暴露私人信息]。
画面只表达：[唯一判断]。
参考分工：[逐张列出上传编号、采用与排除职责]。
主体身份与数量：[完整可见特征；没有角色则描述实际对象]。
场景、道具与相对位置：[起始关系、归属、接触距离]。
状态：[必须看见的动作前状态／结果状态]。
构图、视角、留白：[服务后期与叙事的要求]。
文字：[无字／逐字白名单、数量、位置；后期文字区另说明]。
风格与材质：[上述已确认设计依据的适用要求；早期补图只继承已确认的身份与参考方向]。
禁止：[会改变身份、语义、参考职责的具体错误]。
输出：[已确认画幅和实际工具支持规格]。
核对：[关系可见、身份准确、文字正确、无多余对象]。
```

静图通过身份、语义、文字和风格后，再进入依赖它的视频任务。静图失败不能指望视频提示词修复。

## 可直接粘贴的视频提示词

```text
输入模式：[实际可用的文本／首帧／首尾帧／多参考；各图职责]。
本镜头表达：[唯一画面判断]。
主体与起始关系：[数量、归属、位置、接触距离]。
目标时长：[来自实际配音窗口与裁切余量；选当前工具支持档位]。
镜头：[观察方式、叙事作用、起止构图、揭示与焦点交接]。
动作合同（本镜头从00:00.000开始）：
[逐项填触发、开始、接触、状态变化、结束及停稳；未知点写待核对，不使用猜测正式时间]。
终态与接棒：[下一镜头需延续的对象、方向、状态]。
文字：[逐字保持的短标签／后期叠加留白；跟踪标注所需依据]。
声音：[需要且工具支持时保留与画面同步的环境声和动作拟音；排除未计划旁白、对白、口型和BGM；本次明确采用的其他声音单列]。
关键声事件：[精确秒点或区间、声源与对应动作；均为计划，收片后按实际重新校准]。
禁止：[无因果动作、身份漂移、错字、多余主体、无用途微动]。
```

## 收片记录与分层返修

- 原件路径／文件 SHA-256：[实际收到后计算]
- 实际内容与候选编号：[看内容登记，文件名不代表采用]
- 实际可用源区间：[入点、出点、单位与帧率]
- 实际动作与音效锚点：[绑定采用画面重新记录]
- 文字处理：[保留／后期／需修正]
- 原声策略：[保留／静音／区间混音；抽取独立轨则关闭容器重复音轨]
- 检查方法、范围、结果和未验证项：[技术／实际观看／实际审听分别写]
- 建议：[候选采用／底图层修正／视频层修正／仅声音后期／入出点裁切]
- 用户实际决定：[引用真实交互；没有决定保持候选]

画面合格而声音失败时优先保留画面；仅进出点不合适时先看现有余量。不要为了修声音要求用户重生成整条画面。
