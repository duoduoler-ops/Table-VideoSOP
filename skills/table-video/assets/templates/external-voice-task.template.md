# 外部配音／自己录音任务

本流程默认不代生成 TTS 音频；Agent 根据用户已采用的文稿准备读法、停顿、试音和回传说明，不另写文稿。用户使用外部 TTS 或自己录音，回传真实音频；已有其他来源的配音直接走收音核对。P0 本身没有自动 TTS 接入。以下字段由 Agent 按已知内容填齐，稿件缺少采用决定时先处理采用；不把模板整份交给用户重复填写。

## 输入与声音决定

- 任务 ID：[填写]
- 已确认稿件：[路径、ID、摘要与真实确认引用]
- 文本范围：[完整正文或明确区间；不擅删改]
- 配音方式：[自己录音／用户在外部工具生成]
- 音色、语言、语速和情绪：[已有偏好直接沿用；未定给少量推荐]
- 专有名词读法：[逐个词、音读依据与用户指定]
- 停顿与重音：[本次明确要求；未定不伪造毫秒边界]
- 录制规格：[当前工具支持且本次适用的格式／采样率；没有交付要求不硬定数值]
- 实际工具、模型、费用及授权：[用户实测填写；不记录账号凭据]

## 先试代表内容

代表文本：[从正文选择覆盖术语、长句、重音的真实内容，不只一句问候]。

用户操作：粘贴代表文本或按稿试读 → 导出真实试音 → 保存到[回传位置] → 说明可见设置。Agent 核对错读、风格与读法，提交可审听候选。用户决定只覆盖该试音与后续采用范围，不表示全文已核对。

## 全文回传

采用试音后用相同已确认设置生成／录制完整文本，保留原始录音与可用分轨，不把未剪辑视频替代确认纯人声。回传：[全文位置]、实际工具设置、是否有裁切／降噪／速度处理、已知错句和可编辑工程（可得时）。

Agent 核对完整范围、顺序、重复／缺句、停顿与音文一致性。有差异列出稿件原文、实际声音、位置与推荐处理，由用户决定以哪份为准；不自行修改立场或删段。

## 对齐材料

使用[对齐模板](alignment-record.template.md)绑定本次真实音频摘要与稿件版本。用户可回传经核对编辑器时间、人工锚点或对齐结果。只有时长、旧字幕或未经核对 ASR 时，精确对点保持待定。

- 音频原件／SHA-256：[实际文件]
- 音文核对范围与方法：[实际完成部分]
- 采用决定与证据：[真实回复引用，未确认保持候选]
- 未解决项：[句子范围、影响哪些制作、可先做什么]

音频内容或停顿更新后，旧锚点不能继续放行正式对点；只改增益且内容时间未变时说明依据，重查实际音频效果。
