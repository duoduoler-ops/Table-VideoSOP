# 正文镜头剧本

> 大段方案确认后、出设计图前，把每个制作大段“观众怎么看”写成简明配音对照，让用户一次审完；详细制作依据在同一小节折叠。每期一份，放在 `03_视觉设计/正文镜头剧本.md`。它不替代制作大段表、设计图、运动标注或动作标记。静态及 DESIGN 依据已齐备时，剧本确认后进入设计；运动依经验规划、在实际片段中检查，不要求先有独立动态测试。具体未解决风险按[测试与复用](../../references/style-and-motion.md#测试与复用)处理。

交审时展示同一正文的简明配音对照和具体判断问题，制作细节可展开，确认后才登记 storyboard 方面；分段表摘要及对其回复不能代替本剧本确认。

模板中的方法链接指向 Skill 包内资料。实例化到用户项目时，把需要保留的方法引用改为本次实际可访问的 Skill 文件路径，不原样复制会失效的相对链接；本期制作文件按项目实际位置引用，不复制方法正文。

## 谁写、何时审

- 总控在大段方案确认后一次写完需要画面设计的全部大段；单独打磨的段落（如开场）可按系列约定除外。用户审一次，分段任务书引用对应小节。
- 分段开工时本段还没有小节：回报总控补写并交审；任务书明确委托本段补写时，只写自己一节，仍先交审再绘图。
- 动态实作若实质改变主动作、取景、揭示或交接，须同步受影响小节、状态图／标注，由总控更新 state 采用指针；旧图不继续冒充当前依据。仅调曲线或材质且过程不变时不重画全套，复查范围按验收规则执行。不另建版本台账。

## 写法

- 只写观众能看到的：起初知道什么、什么依据何时出现、哪个部件因而怎样变、由此多懂了什么；取景、阅读、情绪与接棒按本段需要描述，不套统一步骤。组件参数和帧号留在制作依据与动作标记。
- 以完整配音为单位，一句或一组相邻语义一行。检查实际状态带来的理解，不要求画面独立复述整句；删解释性标签用于诊断，必要文字、证据与情绪按其职责保留。
- **对标须落实到局部完整关系**：涉及程序化 MG 时，先按[源码索引](../../references/examples/05_完整过程源码.md)匹配接收、处理、交接、比较等关系，再读取命中区间的实际实现；不以整段题材不同跳过。写明来源函数／区间、本段对应对象与实现方式；无适用关系或新做法只记录具体未解风险，按验收规则决定是否样片，不把“新类型”扩大到整段已验证部分。非程序化部分按实际素材区间与剪辑／处理过程对标，不要求源码函数。
- 需要正反诊断时，按任务读取[连续 MG 正反过程](../../references/examples/04_连续MG正反过程.md)对应案例；写出采用的机制与本段差异。静态风格统一只规定视觉语言，不把全段锁成同一完整正面构图。

## 图旁的配音与审阅重点

- 每组设计图／运动标注的图旁或页边直接显示：段号与当前图版本、采用配音版本、覆盖的完整原文；每张图高亮对应词句，标明经过态或停留态及用途。跨句共享状态就列明覆盖句，不用段号、SRT 编号或文件名代替原文。
- 已核对对齐时给段内时间范围，已知全片入点时同时提供全片定位；尚未对齐只用句子锚点并注明未对点，不从字幕显示时间猜逐词起音。无配音任务注明无配音，按已确认叙事任务或声音事件定位。
- 运动标注把“说到哪个词／发生哪个事件 → 谁怎样变 → 何时交给下一动作”写在对应图旁。进入制作前，精确动作与音效秒点仍按原标记要求记录；不能以简明图注代替动作合同。
- 每组只提出与实际状态有关的具体判断问题，例如“是否看懂只取第一步”，不写泛泛的“检查效果”。原声可用时提供对应区间播放入口；尚无可播放配音就明示，不能暗示已听过或已验证节奏。
- 图注及箭头只属于审阅层；保留干净设计图，不进入成片。图数按关键变化覆盖，状态可共享，不规定一句一镜或每句三图；静图不证明速度曲线、接力和 1× 观感通过。

设计阶段在本节已有运动标注写一行：**空间适配：候选／采用／不用＋观看收益、阅读或比较代价、素材条件**。信息层级或场景物理纵深均须判断，详见[空间镜头](../../references/experience/镜头推进与转场.md#空间镜头)。部件动作随[画面推导](../../references/planning.md#从理解目标推导画面)在设计时确定；实现前补实际事件和精确秒点，不另建逐镜表。

## 关键状态覆盖

**每个已确认的关键变化必须有可核对的状态证据；图数由覆盖需要决定。** 先从已确认剧本找变化，再按下表取状态，不按每 N 秒、每句话或每段固定张数凑图。

| 变化类型 | 最少覆盖什么 |
| --- | --- |
| 构图或观察范围改变 | 起点、终点取景；同一主对象与新增可见内容可追踪 |
| 变形、拆分、合并或用途改变 | 变化前、至少一个能解释转换机制的过程态、变化后 |
| 重要接触、交接或遮挡 | 发生前、事件发生、发生后；双方、连接及前后层关系可辨 |
| 首现、末现、同节点内容替换 | 源物当前最终位置、新物首现；旧内容末现、可见替换机制、新内容首现；退场去向及末现前后。按[默认动作语言](../../references/experience/视觉叙事与连续MG.md#默认进出场与替换)和本期 DESIGN 例外检查 |
| 简单平移、阅读保持、结果展示或现成视频 | 适用的端点／取景，或实际素材区间；稳定状态可共用一张图 |

相邻变化可共用状态，从同一可编辑源取帧，不逐张重画。在原有状态说明中标明“经过”或“停留及用途”；实现由动作与交接时段驱动，不能因图号更换就给主体、辅助物和相机统一重启缓动。过程态不要求停顿或切镜；任取 50% 帧、仅改颜色／光标或微移不能代替机制。不得把已确认的多次变化临时合并成“持续讲解”来规避覆盖。按时间抽样的联系表只用于查漏，不是设计图配额。

这些状态首先用于挑战设计：相邻关键状态带来什么新发现、因果发展或观察任务变化；同一对象是否可追踪，近读与拉开是否在实际主体尺度和内容上成立。换标签、小幅挪动或重复放大已读完的内容不能代替推进；有具体用途的铺垫、复看、妥协、情绪和阅读保留。先解决机制和构图，再展开动画；需要动态才能判清的问题并入现有预演或首版预览，不另加审批。

## 排时间：给变化留足时间

主过程、下一步启动／接管、前一步收势和必要阅读共同排时，具体步骤见[画面推导](../../references/planning.md#从理解目标推导画面)。阅读从完整、清晰、无遮挡且达到可读大小时算；比较保留共同可辨窗口，不把整句配音拉成一段慢移。放不下先去重复动作，保护采用原声；精确标记引用同版本文件。需要动态判清的问题并入现有预演或首版完整片，不增审批。

## 写完自查

- 按[画面推导](../../references/planning.md#从理解目标推导画面)检查目标、内部过程、取景与时间是否相互支持，状态覆盖是否能看清关键变化；有目的的复看、稳定阅读与情绪停顿保留。
- 实现后按[承诺核对](../../references/production.md#剧本承诺落到实际画面)查漏做与假实现，实际结果写原 QA；不靠加图、微动或改词放行。
- 成片文字只写给观众，版本和待验证说明留在审阅层。上屏风险提前核对：完整外链、联系方式、二维码、社媒账号；平台、品牌或 IP 按系列约定，讲解必需的名称可保留。
